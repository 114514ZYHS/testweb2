方法 · 近似 · 偏差来源

没有用屏幕空间畸变、极坐标扭曲、有效折射率或几何光学近似：每像素都在积分 d²l/dσ² = J²l/(l²+b₀²)²， dψ/dσ = J/(l²+b₀²) （RK4 + 自适应步长 + 第一积分投影）。

近似 1（数值） RK4 定步长积分，误差 O(h⁵) 每步； 步长滑块即此项的控制量。每步后用第一积分 (dl/dσ)² + J²/r² = 1 做投影，消除振幅漂移，只留相位误差。 自检面板用 h 与 h/2 跑同一条光线，直接给出渐近方向的角偏差。

近似 2（截断） 光线在 r > r_esc = 200 b₀ 处被判定"逃逸"， 取该处方向作为渐近方向，方向误差 O((b₀/r_esc)²) ≈ 2.5×10⁻⁵ rad（约 0.02 像素）。

近似 3（步数上限） 步数耗尽的光线按"未解出"渲染成近黑色。 该区域在方向空间只有 ~10⁻⁷·b₀ 宽（自检面板给出采样中的最大步数佐证）。

近似 4（星场贴图） 开启烘焙后，星场来自 2048²/面（视 显存上限而定）的立方体贴图，角分辨率 ≈ 0.77 mrad（1080p、60° 视场下一个像素约 1.0 mrad， 故纹素比像素更细）； 自检面板给出「贴图 vs 程序化」的平均绝对差（当前约 0.006，主要是星点的相位差）。

星点尺寸 星点角半径统一压到 0.90–1.15 像素（真实点源 就是衍射极限点，亮度不该改变角尺寸），亮度全部由峰值承担。之前亮星层半径达 2.6 mrad ≈ 3.6 像素、再乘 1.35 倍亮度因子，直径近 9 像素，看着就是一团糊。 代价是移动时星点更容易闪烁（没有运动模糊；静态时靠 TAA 累积消除）。

星场密度 默认 0.35× ≈ 5.4 万颗（全天），比肉眼夜空（约 9 千颗） 密约 6 倍，是为了让喉部窗口与爱因斯坦环在静帧里可辨认；滑到 0.15× 左右即接近真实 肉眼密度，代价是缠绕结构变得很难看出。全天星数由生成器解析计数给出（自检面板第 8 项）， 不是估计值。

两侧差异 面板里 5 个滑块控制 A / B 两侧的星场"性格"： 密度比（默认 0.55×）、色温参数（0 = 红矮星为主 2600–5200 K， 1 = 蓝巨星为主 8000–20000 K）、星云形态（0 = 大团块 + 宽银河带， 1 = 细丝 + 窄带）。只换哈希种子的话两侧只是"同一种星空的两次抽样"， 人眼记不住随机星场，所以穿越时感觉不到换地方；改成统计特征不同（疏密、 色相、结构）才真正一眼可辨。这些参数只在烘焙时生效，运行时零成本。

速度剖面 自动穿越在两端各留一段 ramp，用 smoothstep 把 |v| 平滑压到 0 再反向。原先是恒速 + 瞬时反号，需要无穷大加速度，会让 D⁴ 前灯效应 （0.95c 时迎面/背向相差 230 万倍）在端点处跳变；现在 v 连续过 0 ⇒ D 连续过 1。 现实里更慢：0.95c 下 1g 减速要约一年。

A 平滑转身（自动穿越，可开关） 亮度因子 D = γ(1+v·cosθ) 里， 端点翻转的是 v 的符号，而**穿喉部时翻转的是 cosθ**——相机"盯着喉部看"， 而喉部是极小曲面，径向方向在此反向，于是视线在 l=0 处会瞬间转身 180°。 开启时让相机绕视线的切向轴平滑转过 θ(l) = π(1−tanh(l/λ))/2（λ = 0.45 b₀）： D 连续经过 γ(1+v) → γ → γ(1−v)，亮度不再跳变；关掉则全程朝前看，不转身。

B 朝前看（自由飞行，可开关） 开启时相机基存在 ∂_l 系里 （而不是渐近平坦系），物理视线方向穿过喉部时是连续的：一直朝前飞、朝前看， 喉部从身后掠过，对面世界在前方打开——cosθ 根本不会翻转。关掉则回到"始终面向喉部" 的行为（在 ê_r 意义下），穿喉部时会翻 180°（这里用 0.25 s 一阶跟踪做了缓冲）。

C 自动曝光（自动穿越，可开关） 对 1/D_center⁴ 做 τ = 0.45 s 一阶低通后乘进场景辐射亮度，模拟相机自动光圈 / 人眼亮适应。它只改显示映射 （增益在泛光阈值提取之前施加，所以泛光也跟着适应），不改物理亮度；自由模式下 增益平滑回到 1。

参照天体 4 个有限距离的小球体（半径 0.14–0.45 b₀，分布在 l = +4.2 … −6.0、离轴 17°–30°），不是画在天空上的贴纸：它们参与逐像素的 测地线积分，光线在平面内与球体做真实相交测试，因此会被虫洞正常透镜—— 掠过喉部时同一个天体可能出现多重像，靠近时因视差迅速变大，这就是"感知穿越"的 参照物。它们同样受 D⁴ 前灯效应影响。代价是每步多了 4 次球体测试（约 +20% 开销）， 不需要时可用复选框关掉。

近似 5（TAA） 静止时用 Halton 亚像素抖动累积多帧做运行平均 （在线性 HDR 空间，浮点靶下无量化损失）。运动时也继续累积：历史帧在 resolve pass 里被本帧 3×3 邻域的颜色范围钳制，alpha 固定 0.12（≈6 帧平均）—— 没有运动矢量、不做重投影，所以靠邻域钳制来抑制拖影，代价是快速平移时高对比 边缘可能有轻微重影。只有参数变化和相机跳跃（位移 > 0.4b₀ / 转身 > 5.7° / 朝向变化 > 2.9°）才硬重置。对饱和区不敏感。

后处理 场景以线性 HDR 写入 RGBA16F（无 EXT_color_buffer_float 时回退 RGBA8 并按 ×1/4 压缩存储）， 再做亮度阈值提取 → 1/2·1/4·1/8 三级可分离高斯模糊 → ACES 色调映射。 这一层只影响显示，不参与任何光线计算。

不是近似 Φ ≡ 0 时 dt = dσ，零测地线的空间投影严格是空间度规 h 的测地线（Fermat 原理），且 h 球对称 ⇒ 测地线严格落在过原点的平面内。所以 "平面化 + 空间测地线"是精确性质，不是简化。

能量条件 本度规要求 ρ = −b₀²/(8πr⁴) < 0，径向零矢量下 ρ + p_r = −b₀²/(4πr⁴) < 0 —— NEC 被处处违反。这是纯理论构造， 没有任何观测证据支持负能量密度物质；详见自检面板第 6 项。

未建模 星场是程序化生成的（非真实星表）；星云的谱型未建模， 其多普勒色温偏移用参考黑体近似；无引力透镜时间延迟可视化（Φ ≡ 0 也无引力红移）。
