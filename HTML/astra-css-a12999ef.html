THE PROCESS

从像素，到 CSS 轮廓。

不是手工拼接几何形状。这个页面是一个浏览器内构建器：读取真实透明像素、提取颜色区域，再把轮廓交给 CSS 绘制。点击「导出 HTML」获得无需原图、SVG、Canvas 或 JavaScript 的成品。

  1. 01

    读取原图，检查透明通道

    下载透明 PNG，保留原始文件。脱离页面的 Canvas 仅用于构建时读取 RGBA；透明像素不参加颜色聚类，不将白色当作背景删除。

  2. 02

    颜色量化，保留局部对比

    使用加权颜色直方图、方差优先的中位切分和两轮聚类精炼。只合并低对比的孤立像素，不直接删除眼部高光与细小配饰。Alpha 独立分级。

  3. 03

    追踪边界，处理孔洞

    沿有向像素边界闭合轮廓，以右转优先分离对角连接。外轮廓使用 evenodd；色层保留相反的内外绕向，用 nonzero 避免接缝补偿后同色色区重叠产生错误孔洞。

  4. 04

    用 HTML 与 CSS 重建

    相同颜色与透明度共用一个元素，按透明度与面积排序。每层只使用背景色和 clip-path: path(...)，外部透明轮廓统一裁剪。所有坐标在同一原生尺寸内按比例缩放。
