模式说明 · TY-SIM v1.0 简化物理框架

  
本系统是理想化的动力—统计混合台风模式：路径与强度由用户给定的环境场实时计算，无任何预设轨迹。以下说明所采用的方程、参数化方案与关键假设。


  
1. 网格与坐标

  
    
    
  • 计算域 99°E–171°E，0°–51°N；诊断场网格 288×204（Δ=0.25°）；环境场在 73×53（Δ≈1°）粗网格上求解后双线性插值到细网格。
    • 
    
  • 可视化采用 Mercator 投影（保形），物理量之间的距离一律使用球面局地度量 dx=111.32·cosφ·dλ km，dy=110.57·dφ km。
    • 
    
  • 科氏参数 f=2Ω·sinφ，为避免赤道奇异，取 |f|≥2Ω·sin(5°)。
    • 
  


  
2. 环境高度场与引导气流（路径核心）

  
500 hPa 位势高度场由四个可解释的分量叠加：

  
    
    
  • 副热带高压：可旋转椭圆距平 H=A·exp[-(x'/a)²-(y'/b)²]，a、b 为经/纬半轴，倾角控制"块状/带状/西伸"形态。
    • 
    
  • 季风槽：东西向 elongated 负距平，其南侧产生西南季风气流。
    • 
    
  • 中纬度西风槽：H=A_w·sin[2π(λ-λ_T-ct)/L]·exp[-((φ-φ_T)/w)²]，以相速 c 东移；槽前西南气流是台风转向的直接原因。
    • 
    
  • 大陆热低压（可选）：季风环流的次级贡献。
    • 
  

  
引导气流取该高度场的地转风 u_g=-(g/f)·∂H/∂y，v_g=(g/f)·∂H/∂x，再以台风为中心做 500 km 半径的高斯加权平均（近似深层平均引导流），最后叠加：

  
    
    
  • β 漂移：西北向分量，量级 1–3 m/s，随涡旋尺度 R34 增大而增大；
    • 
    
  • 地形绕流偏转：靠近中央山脉、吕宋科迪勒拉等地形时出现小尺度偏折与"打转"倾向；
    • 
    
  • 随机涡旋扰动：一阶自回归（OU）过程，24 h 去相关，用于集合发散。
    • 
  


  
3. 强度方程

  
采用向潜在强度松弛的一阶方程：dV/dt = (V_pot·Πf_i − V)/τ，τ 在增强 / 减弱阶段取不同值。

  

    
过程参数化物理含义

    
潜在强度 V_pot(SST)78·((SST−22)/8)^0.9，上限 85 m/sEmanuel PI 的 SST 单因子经验拟合

    
风切变通风 Π_shrexp[−(SHR/12)²]10–12 m/s 为显著抑制阈值

    
中层干空气 Π_rhclamp((RH−40)/30, 0.25, 1.12)600–700 hPa 相对湿度对对流的影响

    
冷尾流（海洋反馈）dT/dt = −c·(V/50)³·(50/OHC)·(1+0.8e^(−Vt/3))，240 h 恢复海洋热容量越小、移速越慢，降温越强

    
登陆 / 地形摩擦Π_land = exp(−2.0·F_land)，F_land 为内核陆地覆盖率；山区额外加速衰减地表摩擦切断焓通量、增加边界层耗散

    
高层流出修正 τ 与 Π_shr 的等效阈值良好流出可缓解切变抑制

    
眼墙置换（ERC）V>45 m/s 时准周期振荡，12 h 窗口内 V_pot 下调 18%，R34/RMW 先扩张后收缩成熟台风强度的自然振荡

  

  
风压关系（Atkinson–Holliday 型）：Δp = (V/4.12)^1.553，p_c = p_env − Δp，下限 872 hPa。模式输出的中心气压与最大风速始终满足该关系。


  
4. 结构场（可视化数据由同一套状态解析生成）

  
    
    
  • 气压廓线：Holland (1980) 型 p(r)=p_c+Δp·exp[−(R_mw/r)^B]，与环境气压场平滑衔接，B 由强度与纬度估计。
    • 
    
  • 风廓线：Holland 梯度风 V_g=√[B/ρ·(R_mw/r)^B·Δp·e^{−(R_mw/r)^B}+(rf/2)²]−rf/2，再整体归一化使峰值等于模式 V_max；因此风场与气压场满足梯度风平衡（仅差一个随时间的整体缩放）。
    • 
    
  • 非对称：叠加移速矢量（风场加 0.5×移速）、切变造成的 wavenumber-1 对流不对称（北半球最大对流位于顺切变左前象限）、摩擦入流角（海面 22°，陆面 32°）。
    • 
    
  • 螺旋雨带：对数螺线 θ = ln(r/R_mw)/tanα（α≈18°），叠加 1–3 波数分量；眼区对流闭合、眼墙最强、外围按 e 折衰减。
    • 
    
  • 反射率 / 雨强 / 云顶：由对流强度诊断 dBZ=8+62·C^0.8，R=75·C^1.6 mm/h，云顶高度 1.2+14·C^0.7 km。
    • 
  


  
5. 集合与确定性

  
所有随机数来自 mulberry32(seed) 确定性伪随机流，分为「初始扰动 / 引导涡旋 / 对流噪声 / 粒子播种」四条独立流。同一组参数 + 同一种子，逐位复现；不同种子给出统计上合理的路径发散（典型 72 h 位置离散度 150–400 km）。


  
6. 关键假设与已知局限（务必知悉）

  
    
    
  • 环境场是给定的、不预报的：副高、西风槽按用户设定做缓慢演变（可设相速），模式自身不求解大尺度演变方程。
    • 
    
  • 无完整原始方程热力学：边界层、积云对流、云微物理均为诊断/参数化，不能再现眼墙中小尺度过程。
    • 
    
  • 海洋是"冷尾流"一维柱模型，无海洋环流、无温跃层显式结构。
    • 
    
  • 地形为参数化高斯山体 + 简化海岸线多边形（约 0.3° 精度），不解析真实地形高度场。
    • 
    
  • 涡旋始终假定为轴对称基态 + 一/二波数扰动，不考虑多涡旋相互作用、藤原效应。
    • 
    
  • 本系统用于教学演示与机制理解，不可用于业务预报。
    • 
  


  
7. 操作提示

  
    
    
  • 左键拖拽旋转视角，滚轮缩放，右键 / 中键拖拽平移；单击（未拖动）任意位置读取该点气象要素。
    • 
    
  • 底部时间轴可回放已模拟过程；回放通过从 t=0 确定性重算实现，结果与原过程完全一致。
    • 
    
  • 所有参数修改后即时生效（无需重启）；仅"随机种子"改变需点击 ↺ 重置以保证可复现。
