霓虹节奏工作台

NEON SEQUENCER · 网页步进音序器
  • 16 步 × 6 轨网格：底鼓 / 军鼓 / 踩镲 / 拍手 / 贝斯 / 主奏，点击单元格编写节奏。
  • 贝斯与主奏为旋律轨：循环点击切换单元格音高（C 小调五声音阶），右键清除。
  • 全部音色由 Web Audio API 实时合成，无任何采样与外部资源。
  • 内置「合成波 / 嘻哈 / 浩室 / 随机」预设，一键获得律动；点击轨道名可静音。
  • 点击「开始」启动音频引擎，并自动播放示例节奏。
