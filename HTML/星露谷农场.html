怎么玩

用锄头翻地 → 选中种子播种 → 用水壶浇水（水壶要去池塘边补水）→ 每天浇水，作物按阶段生长 → 成熟后空手走过去按空格收获 → 把收获物丢进屋前的出货箱，睡觉后自动结算金钱。
农场右侧出口通往小镇：皮埃尔杂货店买种子/卖东西/升级工具；小镇北边是矿洞，用镐挖石头找矿石与宝石、坐梯子往下走。水边装备钓竿可以钓鱼。
钓鱼：面朝水面按空格抛竿 → 出现 ! 时立刻再按一次提竿 → 之后按住空格让绿条上升、松开下落，把绿条罩住鱼的图标，右侧金条涨满就钓上来了。
体力耗尽会累倒；凌晨 2:00 前必须回屋上床空格睡觉，睡觉即存档。商店里可以升级工具（铜/钢）和背包。
合成（R）：50 木头做箱子（放在地上，走过去按空格开箱存 24 组物品）；还能做木栅栏、火把、随身零食、洒水器（4 铜矿+1 铁矿，每天自动浇周围 4 格）、稻草人。木头来自砍树，纤维来自割草，树脂来自砍树掉落。
存档：共 3 个存档位。Esc → SAVE GAME 选位保存，LOAD GAME 读取，DELETE 需点两次确认；每晚上床睡觉也会自动存到当前存档位（可在设置里关闭）。C 是快速存到当前位。
设置（Esc → OPTIONS，标题界面也有）：音乐/音效音量、时间流速（慢/普通/快）、像素缩放（自动/2x/3x/4x）、画面震动、天气特效、自动存档、全屏，以及「清空全部存档」。设置会被记住。
进度与设置保存在浏览器 localStorage 中（换浏览器或清缓存会丢失）。
