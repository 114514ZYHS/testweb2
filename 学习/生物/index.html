人教版高中生物必修一是《分子与细胞》，必修二是《遗传与进化》。 生物这科的特点是概念多、图多、文字表述要求准——答题时用词不准确是要扣分的。
一、细胞的分子组成

四大类有机物

  • 糖类——主要能源物质。单糖（葡萄糖、果糖、核糖）、二糖（蔗糖、麦芽糖、乳糖）、多糖（淀粉、纤维素、糖原）
  • 脂质——储能物质（脂肪）、构成膜（磷脂）、调节（固醇类，如性激素、胆固醇）
  • 蛋白质——生命活动的主要承担者。基本单位是氨基酸，约 20 种
  • 核酸——遗传信息的携带者。DNA 和 RNA，基本单位是核苷酸

蛋白质的计算

肽键数 = 氨基酸数 - 肽链数 脱去的水分子数 = 肽键数 蛋白质相对分子质量 = 氨基酸总数×平均分子量 - 脱水数×18

注意环状肽：如果是环状，肽键数 = 氨基酸数（没有"减肽链数"这一步）。

检测实验的颜色反应

  • 还原糖 + 斐林试剂 → 水浴加热后出现砖红色沉淀
  • 蛋白质 + 双缩脲试剂 → 出现紫色（不需加热）
  • 脂肪 + 苏丹Ⅲ染液 → 出现橘黄色（用显微镜观察）
  • DNA + 甲基绿 → 绿色；RNA + 吡罗红 → 红色
两个易错点： ①斐林试剂要现配现用、混合后使用，且需要水浴加热； ②双缩脲试剂是先加 A 液（NaOH）再加 B 液（CuSO₄），不能混合，不需要加热。这两个试剂的用法完全不同，考试常考。
二、细胞的结构

细胞器的分工

  • 线粒体——有氧呼吸的主要场所（"动力车间"）
  • 叶绿体——光合作用的场所（"养料制造车间"）
  • 内质网——蛋白质加工、脂质合成
  • 高尔基体——动物细胞里加工分泌蛋白；植物细胞里与细胞壁形成有关
  • 核糖体——蛋白质合成的场所（"生产蛋白质的机器"）
  • 溶酶体——含多种水解酶，能分解衰老、损伤的细胞器（"消化车间"）
  • 液泡——植物细胞特有，维持细胞形态，储存物质
  • 中心体——动物细胞和低等植物细胞有，与有丝分裂有关

分泌蛋白的合成路径

这是必考的一条线，顺序不能错：

核糖体（合成肽链） ↓ 内质网（初步加工、折叠） ↓ 高尔基体（进一步加工、分类包装） ↓ 细胞膜（胞吐分泌到细胞外） 全程由线粒体提供能量。

膜的转化：内质网膜 → 高尔基体膜 → 细胞膜，所以内质网膜面积减小，细胞膜面积增大。

三、细胞代谢

呼吸作用

有氧呼吸（三个阶段）： 第一阶段（细胞质基质）：C₆H₁₂O₆ → 2丙酮酸 + 4[H] + 少量能量 第二阶段（线粒体基质）：丙酮酸 + H₂O → CO₂ + [H] + 少量能量 第三阶段（线粒体内膜）：[H] + O₂ → H₂O + 大量能量 无氧呼吸： 生成酒精：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ + 少量能量 生成乳酸：C₆H₁₂O₆ → 2C₃H₆O₃ + 少量能量

关键对比：有氧呼吸产生二氧化碳的场所在线粒体（第二阶段）；产生水的场所在线粒体内膜（第三阶段）。这两个别搞混。

光合作用

光反应（类囊体薄膜上）： 水的光解：2H₂O → 4[H] + O₂ ATP 的合成：ADP + Pi → ATP 暗反应（叶绿体基质中）： CO₂ 的固定：CO₂ + C₅ → 2C₃ C₃ 的还原：C₃ + [H] + ATP → (CH₂O) + C₅

光反应给暗反应提供的是 [H] 和 ATP，暗反应给光反应提供 ADP、Pi 和 NADP⁺。两者互相依存。

突然停止光照时：C₃ 增多，C₅ 减少（因为 [H] 和 ATP 没了，C₃ 还原不了；而 C₅ 还在被消耗）。突然停止供应 CO₂ 时：C₃ 减少，C₅ 增多。这两个方向刚好相反，是常考的判断。

四、遗传与进化（必修二）

孟德尔定律

分离定律：一对等位基因在形成配子时彼此分离，分别进入不同的配子。

自由组合定律：控制不同性状的遗传因子在形成配子时自由组合。

两个定律都成立的前提是：不同对的基因位于非同源染色体上。如果位于同一对染色体（连锁），就不遵循自由组合。

遗传题的基本方法

  1. 先判断显隐性："有中生无为显性，无中生有为隐性"（双亲有病，子女有正常 → 该病为显性）
  2. 再判断是常染色体还是性染色体：隐性遗传中"母病子必病"是伴 X 的特点
  3. 写出亲本基因型，画配子，组合出子代比例

DNA 的复制与表达

复制：DNA → DNA（半保留复制） 转录：DNA → mRNA（在细胞核内） 翻译：mRNA → 蛋白质（在核糖体上） 碱基配对：A-T、G-C（DNA 中）；A-U、G-C（RNA 中） DNA 双链碱基数 = 2 × mRNA 碱基数 = 6 × 氨基酸数

三个数之间的关系要记牢：DNA 上 6 个碱基 → mRNA 上 3 个碱基（一个密码子）→ 对应 1 个氨基酸。

答题技巧：生物大题的文字表述要用课本原话。 比如问"为什么细胞不能无限长大"，标准答案是"细胞体积越大，相对表面积越小，物质运输效率越低"—— 不能写成"细胞太大了营养运不进去"。意思对但用词不对，是要扣分的。
