第 3 章 体液调节

人教版选择性必修第一册 · 3.1 – 3.3
体液调节 = 靠化学物质调节。

最主要的是激素调节。它和神经调节正好互补：
·神经调节——快、准、短，作用范围小；
·体液调节——慢、广、久，作用范围大。

本章的核心是「分级调节 + 反馈调节」这个模型， 尤其是甲状腺激素的分级调节。

3.1 激素与内分泌系统

激素调节的特点

① 微量高效 —— 激素含量极低，但作用显著 ② 通过体液运输 —— 靠血液运输到全身 ③ 作用于靶器官、靶细胞 —— 只对特定细胞起作用 （因为只有靶细胞上有特异性受体） 关系：激素 → 体液运输 → 靶细胞受体 → 调节作用

人体主要内分泌腺与激素

下丘脑 —— 促甲状腺激素释放激素（TRH） 促性腺激素释放激素 抗利尿激素（ADH，由垂体释放） 垂体 —— 促甲状腺激素（TSH） 生长激素 促性腺激素 甲状腺 —— 甲状腺激素（含碘，促进代谢、促进发育） 胰岛 —— 胰岛 B 细胞：胰岛素（降血糖） 胰岛 A 细胞：胰高血糖素（升血糖） 肾上腺 —— 肾上腺素（升血糖、心率加快） 性腺 —— 性激素（促性腺器官发育、维持第二性征）
几个常考的「对应关系」：
·下丘脑——既是神经中枢，又分泌激素， 是「神经调节和体液调节的联系枢纽」；
·抗利尿激素由下丘脑合成、垂体释放—— 这个「合成和释放不同」是考点；
·胰岛素是人体内唯一能降血糖的激素， 而升血糖的有胰高血糖素和肾上腺素；
·甲状腺激素含碘，所以缺碘会导致甲状腺肿大（大脖子病）。

3.2 血糖调节

血糖的来源与去路

血糖的来源： ①食物中糖类的消化吸收（主要） ②肝糖原分解 ③非糖物质（脂肪、氨基酸）转化 血糖的去路： ①氧化分解供能（主要） ②合成肝糖原、肌糖原 ③转化为脂肪、某些氨基酸 正常人体血糖浓度：3.9 – 6.1 mmol/L

两种激素的拮抗作用

血糖升高时： 胰岛 B 细胞分泌胰岛素增多 胰岛素促进：血糖进入细胞氧化分解、 合成肝糖原、转化为脂肪 → 血糖降低 血糖降低时： 胰岛 A 细胞分泌胰高血糖素增多 胰高血糖素促进：肝糖原分解、非糖物质转化 → 血糖升高 两者是拮抗关系，共同维持血糖稳定。
关于血糖调节的三个关键点：
①肌糖原不能直接分解成葡萄糖——它只能氧化分解供肌肉自己用， 所以「肝糖原分解」才是升血糖的途径， 肌糖原分解不升血糖；
②胰岛素还能促进葡萄糖进入细胞， 这是它降血糖的重要机制（相当于「开门」）；
③胰高血糖素只能促进肝糖原分解，不能促进肌糖原分解。

糖尿病

1 型糖尿病：胰岛 B 细胞受损，胰岛素分泌不足。
2 型糖尿病：胰岛素分泌正常甚至偏多， 但靶细胞对胰岛素不敏感（胰岛素抵抗）。

共同表现：血糖过高，超过肾糖阈后， 尿中出现葡萄糖，同时带走大量水分 → 多尿、多饮、多食、体重减轻（「三多一少」）。

3.3 甲状腺激素的分级调节

分级调节模型

下丘脑 ↓ 分泌 TRH（促甲状腺激素释放激素） 垂体 ↓ 分泌 TSH（促甲状腺激素） 甲状腺 ↓ 分泌甲状腺激素 ↓ 作用于全身细胞：促进新陈代谢、促进生长发育、 提高神经系统兴奋性 负反馈： 甲状腺激素过多 → 抑制下丘脑和垂体 → TRH 和 TSH 分泌减少 → 甲状腺激素分泌减少
这个「下丘脑—垂体—甲状腺」的三级模型必须背熟， 它是所有分级调节的模板。
同样的结构还出现在：
·下丘脑—垂体—性腺（调节性激素）；
·下丘脑—垂体—肾上腺皮质（调节肾上腺皮质激素）。

负反馈的方向要记准： 终产物（甲状腺激素）过多 → 反过来抑制上两级。 所以甲状腺激素少，TRH 和 TSH 反而多。

甲状腺激素的异常

甲状腺激素过多（甲亢）： 代谢加快、怕热多汗、心跳加快、 情绪易激动、体重减轻 甲状腺激素过少： 代谢减慢、怕冷、心跳慢、 反应迟钝、体重增加 幼年时缺乏会导致呆小症（智力低下、身材矮小） 碘是合成甲状腺激素的原料： 缺碘 → 甲状腺激素合成不足 → 通过负反馈使 TSH 增多 → 刺激甲状腺增生肿大（大脖子病）
「呆小症」和「侏儒症」的区别（常考）：
呆小症——幼年时甲状腺激素不足， 表现为身材矮小且智力低下；
侏儒症——幼年时生长激素不足， 表现为身材矮小但智力正常。

区别就在智力上。一个是「呆」，一个是「不呆」。

激素调节与神经调节的关系

① 神经调节支配激素分泌 例如：寒冷刺激 → 下丘脑 → 促甲状腺激素释放激素 → 垂体 → TSH → 甲状腺 → 甲状腺激素增多 → 产热增多，抵御寒冷 ② 激素也能影响神经系统的发育和功能 例如：甲状腺激素能提高神经系统的兴奋性 （所以甲亢病人容易激动） 结论：两者相互联系、相互影响， 但神经调节占主导地位。
例 1

给正常小鼠注射大剂量的甲状腺激素，一段时间后， 小鼠血液中 TSH（促甲状腺激素）含量的变化是（　）

A. 增多　　B. 减少　　C. 不变　　D. 先增多后减少

解：这是负反馈调节的分析。

注射甲状腺激素 → 血液中甲状腺激素浓度升高 →

通过负反馈作用于下丘脑和垂体 →

抑制 TRH 和 TSH 的分泌 →

所以血液中 TSH 含量减少。

答案：B。

推理要点：负反馈的方向是「多了就压」。 甲状腺激素多了，就要抑制上游的 TRH 和 TSH， 否则会越来越多。这是维持稳态的基本机制。

3.4 水盐平衡与体温调节

水盐平衡

细胞外液渗透压升高（缺水）时： 下丘脑渗透压感受器受到刺激 → 垂体释放抗利尿激素增多 → 肾小管和集合管对水的重吸收增多 → 尿量减少 → 同时大脑皮层产生渴觉，主动饮水 细胞外液渗透压降低（水多）时： 抗利尿激素分泌减少 → 尿量增多

体温调节

寒冷环境： 皮肤冷觉感受器 → 下丘脑体温调节中枢 → ①皮肤血管收缩，血流量减少（减少散热） → ②骨骼肌战栗（增加产热） → ③甲状腺激素、肾上腺素分泌增多（促进代谢产热） → 体温维持 炎热环境： 皮肤温觉感受器 → 下丘脑 → ①皮肤血管舒张，血流量增加（增加散热） → ②汗腺分泌增多，汗液蒸发散热 → 体温维持
水盐调节和体温调节的两个共同点：
①调节中枢都在下丘脑—— 所以下丘脑被称为「内分泌活动的枢纽」；
②都是神经—体液共同调节—— 有神经参与（感受器、中枢），也有激素参与（ADH、甲状腺激素）。

特别注意：体温调节中，产热和散热必须相等才能维持体温。 寒冷时是「产热增多 + 散热减少」双向调节， 不是只增加产热。
本章的核心记忆点：
①激素三个特点：微量高效、体液运输、作用于靶细胞；
②胰岛素是唯一降血糖的激素；
③肌糖原不能分解升血糖；
④下丘脑—垂体—甲状腺三级分级调节 + 负反馈；
⑤呆小症缺甲状腺激素（呆），侏儒症缺生长激素（不呆）；
⑥下丘脑是血糖、体温、水盐的调节中枢。
