细胞工程

选择性必修三 第 2 章 · 植物细胞工程与动物细胞工程

一、细胞的全能性
细胞全能性：已经分化的细胞，仍然具有发育成完整个体的潜能。 判断是否「体现了全能性」的唯一标准是：最终有没有得到完整的个体。
「植物组织培养得到愈伤组织」没有体现全能性—— 愈伤组织只是「未分化的细胞团」，不是完整个体。 必须培养到再生植株才算体现全能性。 「动物克隆得到克隆羊」体现了——因为得到完整个体。 「干细胞分化为多种细胞」没有体现全能性，那只是「多能性」。

全能性大小的一般规律：受精卵 > 生殖细胞 > 体细胞； 植物细胞 > 动物细胞。动物体细胞的全能性受到限制， 但细胞核仍具有全能性——这是克隆技术的基础。

二、植物组织培养技术

原理是细胞的全能性。过程：

外植体 → 脱分化 → 愈伤组织 → 再分化 → 芽、根 → 植株

脱分化：让已分化的细胞失去特有的结构和功能， 转变成未分化的愈伤组织。需要避光。

再分化：愈伤组织重新分化出芽和根等器官。需要光照， 因为芽的形成和叶绿素的合成需要光。

脱分化避光、再分化需光——这个对应关系是必考细节。 原因是脱分化阶段不需要叶绿素，光照反而会抑制愈伤组织形成； 而再分化出芽后需要光合作用为生长提供有机营养。

培养基的激素配比是关键变量：

生长素多、细胞分裂素少
有利于生根。
细胞分裂素多、生长素少
有利于生芽。
两者比例适中
有利于形成愈伤组织（只增殖不分化）。

口诀：「高生长素生根，高分裂素生芽」。

三、植物体细胞杂交

目的是克服远缘杂交不亲和的障碍，把两个不同物种的优点结合起来。

关键步骤：利用纤维素酶和果胶酶去除细胞壁，得到原生质体； 然后诱导原生质体融合；融合完成的标志是再生出新的细胞壁。

「去壁用什么酶」是超高频考点：纤维素酶 + 果胶酶。 不能用蛋白酶（细胞壁的主要成分是纤维素和果胶，不含蛋白质）。 而判断融合成功的标志不是「原生质体靠近」， 而是「再生出细胞壁」。这两个细节几乎每年都考。

得到的杂种植株染色体数为两个亲本之和。 例如「番茄（2N=24）+ 马铃薯（2N=48）」的杂种植株， 染色体数为 24+48 = 72 条，是异源四倍体。

植物体细胞杂交的优点是打破了生殖隔离； 局限是杂种后代可能出现「不协调」—— 如番茄—马铃薯杂种植株虽然地上结番茄、地下结马铃薯的设想很美好， 但实际往往产量低、性状不理想。

四、动物细胞培养

原理是细胞增殖（不是全能性——动物细胞培养只到细胞层面， 不形成个体）。

过程：取组织 → 胰蛋白酶（或胶原蛋白酶）处理分散成单个细胞 → 制成细胞悬液 → 原代培养 → 传代培养。

动物细胞培养用胰蛋白酶，不用胃蛋白酶，因为培养液的 pH 约为 7.2~7.4，呈弱碱性，胃蛋白酶的最适 pH 是 1.8 左右， 在这个环境里会失活。这是区分动物与植物细胞处理酶的关键。

培养条件：

营养（葡萄糖、氨基酸、无机盐、维生素、血清）； 温度 36.5 ± 0.5 ℃；pH 7.2~7.4； 气体环境为 95% 空气 + 5% CO₂。

CO₂ 的作用是维持培养液的 pH，不是「供细胞利用」。 细胞呼吸用的是 O₂，CO₂ 是用来调节 pH 的——这一条几乎每年都出现在选择题里。 另外，通常需要加入血清（提供生长因子等未知成分）， 合成培养基目前无法完全替代。

原代培养与传代培养：原代培养是初次培养， 传代培养是原代培养的细胞继续传代。 正常动物细胞在体外培养到 10~50 代后会出现接触抑制消失、 增殖停滞、核型改变等现象，最终衰老死亡—— 但癌细胞没有接触抑制，可以无限传代。

五、动物细胞融合与单克隆抗体

动物细胞融合与植物体细胞杂交的区别：动物细胞融合不需要去壁， 因为动物细胞本来就没有细胞壁。诱导融合的方法有 灭活的病毒（动物细胞特有）、聚乙二醇（PEG）、电激。

单克隆抗体制备是本章最重要的应用，流程如下：

给小鼠注射抗原 → 从小鼠体内取出已免疫的 B 淋巴细胞（能产生抗体但不能无限增殖） → 与骨髓瘤细胞（能无限增殖但不能产生抗体）融合 → 用选择培养基筛选出杂交瘤细胞（既产生抗体又无限增殖） → 克隆化培养与抗体检测 → 提取单克隆抗体。

两次筛选的目的不同，这是本题型最大的坑：
第一次筛选——筛选出杂交瘤细胞（用选择培养基， 淘汰未融合的细胞和同种细胞融合的产物）。
第二次筛选——从杂交瘤细胞中筛选出 能产生专一性抗体的细胞群（用抗原—抗体杂交法等）。 如果把两次筛选的目的写反，整题不得分。

单克隆抗体的优点：特异性强、灵敏度高、可大量制备。 应用：作为「生物导弹」的载体（连接药物或放射性同位素）、 疾病的诊断试剂、治疗癌症。

例 1

关于单克隆抗体制备，下列叙述错误的是（　）

A. 融合前需要用胰蛋白酶处理以获得单个细胞
B. 融合得到的细胞需经两次筛选才能获得目标细胞
C. B 淋巴细胞和骨髓瘤细胞融合时可用灭活的病毒诱导
D. 单克隆抗体可用于制备「生物导弹」

答案 A。

A 错：动物细胞融合不需要去壁。胰蛋白酶用于「动物细胞培养」 中分散组织块获得单个细胞，用于「制备单克隆抗体」的融合过程则不需要， 这是个常见的概念混淆——制备单克隆抗体时取的是已游离的 B 淋巴细胞， 本身已是单个细胞，无需用胰蛋白酶处理。
B 对：第一次筛杂交瘤细胞，第二次筛产抗体的克隆。
C 对：灭活病毒是动物细胞融合特有的诱导方法。
D 对：作为载体把药物定向带到肿瘤细胞。

六、核移植技术

过程：供体细胞核（来自体细胞）→ 移入去核的卵母细胞 （通常用 MⅡ 期卵母细胞）→ 重组细胞 → 早期胚胎 → 胚胎移植 → 克隆动物。

核移植得到的克隆动物的遗传物质主要来自供体细胞核， 但不是全部——因为细胞质（线粒体 DNA）来自去核的卵母细胞， 所以克隆动物的性状并不与核供体 100% 一致。 题目说「克隆动物的所有遗传物质都来自供体」是错的。

与「试管婴儿」的区别：试管婴儿是体外受精 + 胚胎移植， 属于有性生殖；克隆是核移植，属于无性生殖。 判断依据是「有没有两性配子的结合」。

七、胚胎工程要点

体外受精需要：卵母细胞培养到减数第二次分裂中期（MⅡ）才具备受精能力； 精子需要获能处理（用培养液或化学诱导法）。

胚胎移植是「借腹怀胎」。 要点：供体和受体母畜需要同期发情处理（用激素）， 使两者生殖器官的生理状态一致，为胚胎提供相同的发育环境。 受体不需要与供体有亲缘关系，也不需要优良性状—— 受体只是「提供子宫」。

胚胎分割：用机械方法（显微操作仪）将早期胚胎切成多份， 要注意将内细胞团均等分割，否则会出现发育不均的问题。 得到的后代基因型完全相同，是「同卵多胞胎」的类比。

胚胎干细胞（ES 细胞）：来源于囊胚的内细胞团或原始性腺， 在体外可以无限增殖且保持未分化状态，在适当条件下可被诱导分化为各种细胞。 这是再生医学（如修复受损心肌、治疗糖尿病）的重要材料来源。

八、易错点速查

其一，「试管牛」与「克隆牛」的区别见上文； 「试管牛」可以有多个父亲吗？不能，但试管牛与代孕母牛之间没有血缘关系。

其二，动物细胞培养、核移植、胚胎移植， 三个技术的生殖方式不同：培养是细胞增殖（不涉及个体生殖）， 核移植是无性生殖，胚胎移植是（配套体外受精时的）有性生殖产物。

其三，「同种动物的细胞融合」不属于细胞工程范畴的技术应用， 而属于动物细胞融合的中间环节。
