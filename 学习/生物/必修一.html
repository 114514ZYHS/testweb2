分子与细胞

必修一 · 细胞的分子组成、结构、代谢与生命历程

一、细胞的分子组成

元素与化合物

组成细胞的基本元素是 C、H、O、N，其中 C 是最基本的元素（因为生物大分子都以碳链为骨架）， O 是含量最多的元素（占细胞鲜重比例最高）。

注意出现频率很高的两组对比：

鲜重中含量最多的化合物是水，最多的有机物是蛋白质； 干重中含量最多的化合物是蛋白质，最多的元素是 C。 「鲜重看水，干重看蛋白质」——这一句话能解决一大类题。

四大类有机物

糖类
主要能源物质。单糖（葡萄糖、果糖、核糖、脱氧核糖）、 二糖（蔗糖、麦芽糖、乳糖）、多糖（淀粉、纤维素、糖原）。
所有糖类的组成元素只有 C、H、O。
脂质
分三类：脂肪（储能）、磷脂（构成膜）、 固醇（调节，如性激素、胆固醇、维生素 D）。
脂肪的 C、H 比例高，所以氧化分解时耗氧多、产能多。
蛋白质
生命活动的主要承担者。基本单位是氨基酸， 约 20 种。
组成元素一定含 C、H、O、N， 很多还含 S（如半胱氨酸）。
核酸
遗传信息的携带者。DNA 与 RNA， 基本单位是核苷酸。组成元素 C、H、O、N、P。

「必含元素」的记忆要点：「蛋白质必有 N（可能有 S），核酸必有 P，糖类和脂肪只有 C、H、O」。 看到检测出 P 就直接排除蛋白质和糖类。

蛋白质的计算

肽键数 = 氨基酸数 − 肽链数
脱去的水分子数 = 肽键数
蛋白质相对分子质量 = 氨基酸总数 × 平均分子量 − 脱水数 × 18
环状肽是特例：如果肽链首尾相连成环， 则肽键数 = 氨基酸数，没有「减肽链数」这一步。 很多题故意给一条环状多肽，按链状算就错了。

游离基团的计算：一条肽链至少含 1 个游离的氨基（—NH₂） 和 1 个游离的羧基（—COOH）—— 分别来自肽链的两端；再加上 R 基上带的。

游离氨基数 ≥ 肽链数
游离羧基数 ≥ 肽链数

检测实验的颜色反应

还原糖 + 斐林试剂
水浴加热后出现砖红色沉淀。 试剂须现配现用、甲液乙液等量混合后加入。
蛋白质 + 双缩脲试剂
出现紫色，不需要加热。 用法是先加 A 液（NaOH）摇匀，再加 B 液（CuSO₄），不能混合后加。
脂肪 + 苏丹Ⅲ
出现橘黄色（苏丹Ⅳ 则呈红色）。 需要用显微镜观察，切片要薄。
DNA / RNA 染色
甲基绿使 DNA 呈绿色， 吡罗红使 RNA 呈红色。注意是「甲基绿—吡罗红混合染色剂」同时使用。
斐林试剂与双缩脲试剂的成分相同（都是 NaOH 和 CuSO₄），但 浓度、用法、是否加热全都不一样，这是教材中最经典的对比考点。
记法：斐林要「混合、加热」，双缩脲要「分开、不加热」。 另外，斐林试剂检测的是还原糖（葡萄糖、果糖、麦芽糖）， 蔗糖不是还原糖，所以蔗糖溶液加斐林试剂不会变色。
二、细胞的结构

细胞膜

细胞膜以磷脂双分子层为基本骨架， 蛋白质镶嵌、贯穿或覆盖其中，外侧还有糖蛋白（糖被）。

三个功能：将细胞与外界环境分隔开、控制物质进出细胞、 进行细胞间的信息交流。

结构特点是具有一定的流动性（因为磷脂和蛋白质能运动）， 功能特点是选择透过性。两者常被互换来设陷阱——「流动性」是结构特点， 「选择透过性」是功能特点。

细胞器的分工

线粒体
有氧呼吸的主要场所，「动力车间」。 有双层膜，内膜向内折叠形成嵴，扩大膜面积。 内含少量 DNA 和 RNA。
叶绿体
光合作用的场所，「养料制造车间」。 双层膜，内有类囊体堆叠成的基粒， 类囊体薄膜上分布着色素和光反应所需的酶。
内质网
单层膜，与蛋白质加工（粗面，附有核糖体） 和脂质合成（滑面）有关。
高尔基体
单层膜。动物细胞中加工分泌蛋白， 植物细胞中与细胞壁的形成有关。
核糖体
蛋白质合成的场所，「生产蛋白质的机器」。 无膜结构，由 rRNA 和蛋白质组成。
溶酶体
单层膜，含多种水解酶， 能分解衰老、损伤的细胞器及侵入的病原体，「消化车间」。
液泡
单层膜，植物细胞特有（成熟植物细胞中有大液泡）， 内含细胞液，与细胞的吸水和失水、维持细胞形态有关。
中心体
无膜结构，由两个互相垂直的中心粒组成。 见于动物细胞和低等植物细胞，与有丝分裂纺锤体的形成有关。
按「膜的层数」分类是高频考点：
双层膜——线粒体、叶绿体（细胞核也是双层膜）。
单层膜——内质网、高尔基体、溶酶体、液泡。
无膜——核糖体、中心体。
切记：核糖体是无膜的，这是最常见的错误点。

分泌蛋白的合成路径

核糖体 → 内质网 → 高尔基体 → 细胞膜（胞吐）

全程由线粒体提供能量。膜的转化方向是 「内质网膜 → 高尔基体膜 → 细胞膜」， 所以结果是内质网膜面积减小，细胞膜面积增大，高尔基体膜面积基本不变。

「基本不变」的原因：高尔基体一边接受内质网的膜，一边把自己的膜通过囊泡送给细胞膜， 进和出大致相等。如果题目问「高尔基体膜面积变化」，答案应写「基本不变」， 不能写「增大」或「减小」。

细胞核

结构：核膜（双层膜，上有核孔）、核仁、染色质。

核孔是大分子物质（如 mRNA、蛋白质）进出细胞核的通道， 但 DNA 不能通过核孔。 核仁与某种 RNA（rRNA）的合成以及核糖体的形成有关。

染色质与染色体是同一种物质在细胞不同时期的两种存在状态： 分裂间期是细丝状的染色质，分裂期螺旋缠绕成染色体。

三、物质的输入和输出

三种跨膜运输方式

自由扩散
高浓度 → 低浓度，不需要载体、不消耗能量。 如 O₂、CO₂、水、甘油、乙醇、苯。
协助扩散
高浓度 → 低浓度，需要载体蛋白（或通道蛋白）， 不消耗能量。如红细胞吸收葡萄糖。
主动运输
低浓度 → 高浓度（可逆浓度梯度）， 需要载体、需要消耗能量。如小肠上皮细胞吸收葡萄糖和氨基酸、 根细胞吸收无机盐离子。
判断运输方式的唯一可靠依据是「是否耗能」—— 耗能的一定是主动运输，不耗能的看是否逆浓度梯度。 另外，主动运输的「逆浓度」不是绝对要求： 若顺浓度但载体被饱和并耗能，也可能判为主动运输。 所以最稳的判据是「需要载体 + 消耗能量 = 主动运输」。

质壁分离与复原

条件是：活的成熟植物细胞（有大液泡）+ 外界溶液浓度大于细胞液浓度。

现象：原生质层与细胞壁分离（细胞壁伸缩性小，原生质层伸缩性大， 所以是原生质层先缩）。质壁分离的内因是原生质层的伸缩性大于细胞壁， 外因是外界溶液浓度大于细胞液浓度。

质壁分离实验可用来判断细胞的死活： 只有活细胞才能发生质壁分离及复原，死细胞的原生质层变成了全透性，不会分离。 而「细胞壁是全透性的」——所以硝酸钾等能进入细胞的溶液， 会发生「先分离后自动复原」（因为离子进入细胞使细胞液浓度升高）。
四、细胞代谢

酶

酶是活细胞产生的具有催化作用的有机物，绝大多数是蛋白质， 少数是 RNA。三个特性：高效性、专一性、作用条件较温和。

酶促反应速率受温度和 pH 影响， 都表现为「有最适值，过高或过低都使活性下降」。

低温与高温对酶的影响不同——这是必考区别：
低温抑制酶活性，但空间结构没有被破坏， 温度回升后活性可恢复；
高温、过酸、过碱则使酶的空间结构被破坏（变性）， 活性不可恢复。
所以保存酶要在低温下（不是高温「灭活保存」）。

ATP

ATP 的结构简式是 A—P~P~P， 其中 A 代表腺苷，P 代表磷酸基团，「~」代表高能磷酸键。 远离 A 的那个高能磷酸键最容易断裂、也最容易重新形成。

ATP ⇄ ADP + Pi + 能量
ATP 与 ADP 的相互转化不是可逆反应， 因为两者的酶不同、能量来源和去路不同、反应场所也不同。 ATP 水解的场所是「需要能量的地方」，合成的场所是细胞质基质、线粒体、叶绿体。 「同一个反应的两个方向」是错误说法。

呼吸作用

第一阶段（细胞质基质）：C₆H₁₂O₆ → 2 丙酮酸 + 4[H] + 少量能量
第二阶段（线粒体基质）：丙酮酸 + H₂O → CO₂ + [H] + 少量能量
第三阶段（线粒体内膜）：[H] + O₂ → H₂O + 大量能量

无氧呼吸两条路线（都在细胞质基质中完成）：

生成酒精：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ + 少量能量
生成乳酸：C₆H₁₂O₆ → 2C₃H₆O₃ + 少量能量
产生 CO₂ 的场所在线粒体基质（第二阶段），产生水的场所在线粒体内膜（第三阶段）。 这两个位置经常互换来设错。
另外，只有第一阶段产生少量 ATP， 无氧呼吸的两个阶段中，只有第一阶段释放能量—— 第二阶段是「不释放能量的丙酮酸转化」。

关于气体交换的判读：

若 CO₂ 释放量 = O₂ 消耗量，说明只进行有氧呼吸 （或同时进行有氧呼吸与「产乳酸的无氧呼吸」）； 若 CO₂ 释放量 > O₂ 消耗量， 说明同时进行有氧呼吸和产酒精的无氧呼吸。

光合作用

光反应（类囊体薄膜）：2H₂O → 4[H] + O₂；ADP + Pi → ATP
暗反应（叶绿体基质）：CO₂ + C₅ → 2C₃；C₃ + [H] + ATP → (CH₂O) + C₅

光反应给暗反应提供 [H] 和 ATP； 暗反应给光反应提供 ADP、Pi 和 NADP⁺。两者互相依存。

经典条件变化判断：

突然停止光照：光反应停 → [H] 和 ATP 减少 → C₃ 还原受阻 → C₃ 增多、C₅ 减少。

突然停止供应 CO₂：CO₂ 固定受阻 → C₃ 生成减少、C₅ 消耗减少 → 但 C₃ 还在被还原 → C₃ 减少、C₅ 增多。

这两个方向刚好相反，是选择题的高频对照点。记法： 「停光看还原，碳三反着动；停碳看固定，碳三跟着降」—— 更简单的记法是「谁断了，谁的下游产物就减少，而上游产物就堆积」。 停光时 [H]/ATP 断，C₃ 是它的「下游被还原物」所以堆积、C₅ 是被消耗的「上游」所以减少。

光合作用总反应式（注意要写条件与场所）：

6CO₂ + 12H₂O →(光能、叶绿体) C₆H₁₂O₆ + 6O₂ + 6H₂O

式中 O₂ 全部来自水（由鲁宾和卡门用同位素标记法证明）， 这是常考的结论，不要误以为是来自 CO₂。

五、细胞的增殖、分化、衰老、凋亡与癌变

有丝分裂

各时期特征（以植物细胞为例）：

间期——完成 DNA 复制和有关蛋白质的合成， 是分裂中最长的阶段。染色体数目不变，但每条染色体含两条姐妹染色单体。

前期——核膜、核仁消失；染色质螺旋缠绕成染色体； 纺锤体形成。

中期——染色体的着丝点排列在赤道板上。 这是观察染色体形态和数目的最佳时期。

后期——着丝点分裂，姐妹染色单体分开， 成为两条子染色体，被纺锤丝拉向细胞两极。 此时细胞内染色体数目加倍（暂时性）。

末期——染色体解螺旋成染色质；核膜、核仁重现； 植物细胞在赤道板位置出现细胞板，最终形成细胞壁。

三个「数目关系」的判读是必考：
有姐妹染色单体时，染色体数 : 染色单体数 : DNA 数 = 1 : 2 : 2；
着丝点分裂后（后期），没有染色单体， 此时 染色体数 : DNA 数 = 1 : 1。
做图题时，「染色单体数」的曲线在后期会掉到 0 并保持 0—— 这是识别后期的最直观标志。

细胞分化、衰老、凋亡与癌变

细胞分化
结果是细胞种类增多， 遗传物质不变（只是基因的选择性表达）。 分化是不可逆的。
细胞衰老
特征：水分减少、酶活性降低（如酪氨酸酶降低→头发变白）、 色素积累（老年斑）、细胞膜通透性改变、细胞核体积增大。
细胞凋亡
由基因决定的程序性死亡， 如蝌蚪尾巴消失、人手指间隙的形成。 是主动的、对机体有利的过程。
细胞坏死
由外界不利因素（如创伤、缺氧）引起的 被动死亡，会引起炎症反应。与凋亡的区别就在「主动/被动」。

癌细胞的特征：能无限增殖（有丝分裂失控）、 形态结构发生显著变化、细胞膜上糖蛋白减少导致黏着性降低， 所以容易在体内扩散转移。

致癌因子分三类：物理致癌因子（紫外线、电离辐射）、 化学致癌因子（亚硝胺、黄曲霉素）、 病毒致癌因子（某些 RNA 病毒）。

「细胞衰老时细胞核体积增大」很违反直觉，但确实是教材结论—— 因为细胞整体缩小，核相对变大，同时染色质固缩、染色加深。 而「细胞膜通透性改变」是指物质运输功能降低， 不是「通透性变大」，做题要看清。
六、答题技巧

生物大题的文字表述要用课本原话。举几个典型例子：

问「为什么细胞不能无限长大」，标准答案是 「细胞体积越大，其相对表面积越小，物质运输效率越低」—— 不能写成「细胞太大了营养运不进去」。

问「为什么细胞膜具有选择透过性」，要答 「细胞膜上载体蛋白的种类和数量不同」， 而不是「细胞膜自己会选择」。

问「为什么酶具有专一性」，标准答案是 「一种酶只能催化一种或一类物质的反应，因为酶的空间结构只与特定底物互补」。

意思对但用词不对，是要扣分的。这是生物与物理最大的不同点： 物理看推导，生物看表述。
