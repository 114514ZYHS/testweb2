第 2 章 分子结构与性质

人教版选择性必修第二册 · 2.1 – 2.3
本章要回答：原子之间靠什么「粘」在一起（化学键）， 分子为什么有特定的形状，以及分子的形状和结构为什么会让物质表现出不同的性质。

这一章是从「原子」走向「宏观性质」的桥梁。

2.1 共价键

本质与类型

共价键的本质：原子间通过共用电子对形成的相互作用。

饱和性：一个原子有几个未成对电子，就能形成几个共价键。 （所以 H 只能形成 1 个键，O 能形成 2 个，N 能形成 3 个）

方向性：共价键要沿着原子轨道重叠程度最大的方向形成—— 这直接决定了分子的空间构型。

σ 键与 π 键

σ 键（sigma）： 原子轨道「头碰头」重叠，重叠程度大，键能大，比较稳定 可以绕键轴旋转 π 键（pi）： 原子轨道「肩并肩」重叠，重叠程度小，键能较小 不能绕键轴旋转（旋转会破坏重叠） 判断规则（很实用）： 单键 → 1 个 σ 键 双键 → 1 个 σ 键 + 1 个 π 键 三键 → 1 个 σ 键 + 2 个 π 键
数 σ 键和 π 键的题很常见，方法很简单：
σ 键数 = 单键数 + 双键数 + 三键数（因为每根键都含 1 个 σ）
π 键数 = 双键数 × 1 + 三键数 × 2

例子：乙烯 CH₂=CH₂ 有 5 个 σ 键（4 个 C−H + 1 个 C−C） 和 1 个 π 键。
乙炔 CH≡CH 有 3 个 σ 键（2 个 C−H + 1 个 C−C）和 2 个 π 键。

键参数

键能：断开 1 mol 化学键所需的能量（kJ/mol） 键能越大，化学键越牢固，分子越稳定 键长：成键两原子核间的平均距离 键长越短，键能一般越大 键角：分子中相邻两个化学键之间的夹角 键角决定分子的空间构型

2.2 分子的空间构型

价层电子对互斥理论（VSEPR）

核心思想：分子中的价层电子对（成键电子对 + 孤对电子对） 由于相互排斥，总是趋向于彼此远离， 从而使分子采取能量最低的构型。

斥力大小顺序： 孤对—孤对 > 孤对—成键 > 成键—成键
所以孤对电子越多，键角被压得越小。
中心原子价层电子对数 = σ 键数 + 孤对电子对数 孤对电子对数 = (a − xb) / 2 a = 中心原子的价电子数 x = 与中心原子结合的原子数 b = 每个配位原子需要的电子数 （H 和卤素取 1，O 和 S 取 2，N 取 3） 电子对数与构型： 2 对 → 直线形（键角 180°） 3 对 → 平面三角形（120°） 4 对 → 四面体形（109.5°）

常见分子的构型

价层电子对数 4 时的四种情形（重点）： 电子对数 成键对数 孤对对数 空间构型 实例 4 4 0 正四面体 CH₄ 4 3 1 三角锥形 NH₃ 4 2 2 V 形（角形） H₂O 价层电子对数 3 时的情形： 3 3 0 平面三角形 BF₃ 3 2 1 V 形 SO₂ 价层电子对数 2： 2 2 0 直线形 BeCl₂、CO₂
键角的比较（常考）：
CH₄（109.5°）> NH₃（107°）> H₂O（104.5°）

为什么越来越小：因为孤对电子依次增多， 孤对电子的斥力大于成键电子对，把键角压小了。
·CH₄ 没有孤对 → 109.5°
·NH₃ 有 1 对孤对 → 压到 107°
·H₂O 有 2 对孤对 → 压到 104.5°

这个递减的规律理解了，就不用死记数字。

2.3 杂化轨道理论

为什么要杂化

问题的来源：碳原子基态是 1s²2s²2p²，只有 2 个未成对电子， 按理只能形成 2 个键。但甲烷有 4 个完全等同的 C−H 键， 且键角都是 109.5°。

解释：成键时，1 个 2s 轨道和 3 个 2p 轨道混合， 重新组合成 4 个能量相同、方向指向四面体顶点的新轨道—— 这就是 sp³ 杂化轨道。
杂化类型与空间构型： sp 杂化 → 2 个杂化轨道 → 直线形，键角 180° 例：BeCl₂、C₂H₂（乙炔）、CO₂ sp² 杂化 → 3 个杂化轨道 → 平面三角形，键角 120° 例：BF₃、C₂H₄（乙烯）、苯 sp³ 杂化 → 4 个杂化轨道 → 四面体形，键角 109.5° 例：CH₄、NH₃、H₂O、NH₄⁺
怎么快速判断杂化类型——数「价层电子对数」就行：
·价层电子对数 = 2 → sp 杂化
·价层电子对数 = 3 → sp² 杂化
·价层电子对数 = 4 → sp³ 杂化

注意：孤对电子也占据杂化轨道。 所以 NH₃（3 个 σ 键 + 1 对孤对）仍然是 sp³ 杂化，只是空间构型变成三角锥形而不是四面体。
「杂化类型看电子对数，空间构型看成键数」——这两件事要分开判断。

不同类型杂化的对比

以三种含碳分子为例： CH₄（甲烷）：sp³ 杂化，正四面体，所有键角 109.5° C₂H₄（乙烯）：sp² 杂化，平面结构 两个碳各用 sp² 形成 C=C 的 σ 键 未参与杂化的 2p 轨道「肩并肩」形成 π 键 所以乙烯是平面的，不能绕 C=C 自由旋转 C₂H₂（乙炔）：sp 杂化，直线形 两个碳各用 sp 形成 C−C 的 σ 键 每个碳剩 2 个未杂化 2p 轨道，形成 2 个 π 键 所以乙炔是直线形的
例 1

判断 H₂O 分子中氧原子的杂化类型，并说明分子的空间构型和键角。

解：

第一步，算价层电子对数。

O 有 2 个 σ 键（与 2 个 H 成键）

孤对电子数 = (6 − 2×1) / 2 = 2 对

价层电子对数 = 2 + 2 = 4 对

第二步，判断杂化类型。4 对电子 → sp³ 杂化。

第三步，判断空间构型。4 对电子中有 2 对是孤对， 只考虑原子的位置，是 V 形（角形）。

键角：因为有两对孤对电子的强排斥，键角被压缩到约 104.5°（小于 109.5°）。

答案：氧原子 sp³ 杂化，分子呈 V 形，键角约 104.5°。

2.4 分子间作用力与分子的性质

分子间作用力的三种类型

① 范德华力——普遍存在于分子之间。 比化学键弱得多（约 1–2 个数量级）， 主要影响物质的熔沸点。

② 氢键——比范德华力强，但比化学键弱。 形成条件：与 N、O、F 相连的 H，与另一个 N、O、F 之间形成。 X−H···Y（X、Y 是 N、O、F）

③ 分子内 / 分子间氢键——氢键可以在分子之间，也可以在分子内部。
氢键对性质的影响——这是高频考点：
① 熔沸点升高：H₂O、HF、NH₃ 的沸点远高于同族其他氢化物， 就是因为有分子间氢键。
② 溶解性：能与水形成氢键的物质易溶于水（如乙醇、氨）。
③ 密度反常：冰的密度小于水—— 因为冰中氢键把水分子按一定方向排列，形成空旷的结构。所以冰能浮在水面上。
④ 分子内氢键会使熔沸点降低（因为分子间不再互相吸引）。

分子的极性

极性分子：正负电荷中心不重合，有偶极矩。
非极性分子：正负电荷中心重合，偶极矩为零。

判断方法：
①看键的极性——同种原子成键（H₂、O₂）是非极性键； 不同种原子成键（HCl）是极性键；
②看分子构型是否对称——对称的分子即使有极性键， 各键的极性也会相互抵消，整体是非极性分子。
常见判断结果： 非极性分子： H₂、O₂、N₂、Cl₂ （同种原子，非极性键） CO₂ （直线形，对称，键的极性抵消） CH₄ （正四面体，对称） BF₃ （平面三角形，对称） CCl₄ （正四面体，对称） 苯 C₆H₆ （平面正六边形，对称） 极性分子： HCl、HBr、H₂O、NH₃、SO₂、CHCl₃、CH₃Cl 关键例子对比： CO₂（非极性）vs SO₂（极性）—— 都是 AB₂ 型，但 CO₂ 是直线形（对称），SO₂ 是 V 形（不对称）
CO₂ 和 SO₂ 的对比是本节的经典陷阱。
两者都由 1 个中心原子 + 2 个氧原子构成， 但构型不同导致极性不同：
·CO₂ 中 C 没有孤对电子 → 直线形 → 对称 → 非极性
·SO₂ 中 S 有 1 对孤对电子 → V 形 → 不对称 → 极性

所以判断分子极性不能只看组成，必须看构型。

溶解性规律

「相似相溶」原理：
极性分子易溶于极性溶剂（如水）， 非极性分子易溶于非极性溶剂（如苯、CCl₄）。

解释：极性分子之间可以靠静电引力相互吸引； 非极性分子与极性溶剂之间作用力小，不容易被「拉开」。
本章的核心记忆点：
①单键中 1 个 σ 键；双键中 1σ + 1π；三键中 1σ + 2π；
②价层电子对数决定杂化类型，成键对数决定空间构型；
③孤对电子越多，键角越小（CH₄ > NH₃ > H₂O）；
④氢键让熔沸点反常升高，让冰的密度小于水；
⑤有极性键的分子不一定有极性，要看构型是否对称。
