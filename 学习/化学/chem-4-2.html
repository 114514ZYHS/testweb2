第 2 章 水溶液中的离子平衡

人教版选择性必修第一册 · 2.1 – 2.4
本章的主线：上一章讲的平衡是「分子层面」的（N₂ + H₂ ⇌ NH₃）， 这一章讲的是「离子层面」的——弱电解质的电离、水的电离、盐的水解、沉淀的溶解。

这四种平衡本质都是化学平衡，所以勒夏特列原理照样适用。 抓住这一点，本章就不需要重新学一套逻辑。

2.1 弱电解质的电离

强电解质与弱电解质

强电解质：在水溶液中完全电离。包括强酸（HCl、H₂SO₄、HNO₃）、 强碱（NaOH、KOH、Ba(OH)₂）、大多数盐。
弱电解质：在水溶液中部分电离，存在电离平衡。 包括弱酸（CH₃COOH、H₂CO₃、HClO、HF）、弱碱（NH₃·H₂O）、水。

判断依据看「是不是完全电离」，不看「溶解度大小」。 BaSO₄ 难溶，但它是强电解质（溶解的那部分完全电离）。

电离平衡与电离常数

以醋酸为例： CH₃COOH ⇌ CH₃COO⁻ + H⁺ 电离常数： Ka = [CH₃COO⁻][H⁺] / [CH₃COOH] （Ka 越大，酸性越强；Ka 只与温度有关，升温促进电离，Ka 增大）
三个高频结论：
①越稀越电离——加水稀释，电离程度增大，但离子浓度减小；
②升温促进电离（电离是吸热的）；
③加入同离子抑制电离——往醋酸里加醋酸钠，CH₃COO⁻ 增多， 平衡逆向移动，电离程度减小。

注意①里「电离程度增大但离子浓度减小」这一对矛盾——程度和浓度是两回事， 这是最容易混的。

强弱电解质的比较

相同浓度、相同体积的一元酸： 强酸：完全电离，c(H⁺) = c(酸) 弱酸：部分电离，c(H⁺) < c(酸) 所以同浓度时：强酸的 pH 更小、导电性更强、 与金属反应速率更快（但最终产生 H₂ 的量相同）
「反应速率不同但产气量相同」这个对比很重要。
因为 H₂ 的量由酸的物质的量决定，与强弱无关； 而速率由 H⁺ 浓度决定，强酸 H⁺ 多所以快。
这个结论常用来判断哪个是强酸哪个是弱酸。

2.2 水的电离与溶液的 pH

水的离子积

H₂O ⇌ H⁺ + OH⁻ 25 ℃ 时： Kw = [H⁺][OH⁻] = 1.0×10⁻¹⁴ 纯水中 [H⁺] = [OH⁻] = 1.0×10⁻⁷ mol/L 注意：Kw 只与温度有关，升温 Kw 增大。
pH 的定义： pH = −lg[H⁺]
25 ℃ 时的判断标准：
pH < 7 → 酸性；pH = 7 → 中性；pH > 7 → 碱性

但要注意：pH = 7 只在 25 ℃ 时才是中性。 100 ℃ 时 Kw ≈ 1×10⁻¹²，中性时 pH = 6。 判断酸碱性要看 [H⁺] 和 [OH⁻] 的大小关系，不能只背 pH = 7。
例 1

25 ℃ 时，某溶液的 [H⁺] = 1.0×10⁻³ mol/L。求该溶液的 pH 和 [OH⁻]。

解：

pH = −lg[H⁺] = −lg(1.0×10⁻³) = 3

由 Kw = [H⁺][OH⁻] = 1.0×10⁻¹⁴：

[OH⁻] = 1.0×10⁻¹⁴ / 1.0×10⁻³ = 1.0×10⁻¹¹ mol/L

答案：pH = 3，[OH⁻] = 1.0×10⁻¹¹ mol/L。

验算：[H⁺] > [OH⁻]（10⁻³ > 10⁻¹¹），溶液呈酸性，与 pH = 3 < 7 一致。

影响水电离的因素

  • 加酸或加碱——都抑制水的电离（H⁺ 或 OH⁻ 增大，平衡逆向移动）
  • 加能水解的盐——促进水的电离
  • 升温——促进水的电离（水的电离是吸热的）
  • 加活泼金属（如 Na）——与 H⁺ 反应，促进水的电离
「由水电离出的 [H⁺]」这类题怎么算：
先看溶液里有什么——是酸、碱，还是能水解的盐。
·酸或碱溶液中，水电离被抑制，水电离出的 c(H⁺) = 溶液中的 c(OH⁻)；
·能水解的盐溶液中，水电离被促进，水电离出的 c(H⁺) = 溶液中的 c(H⁺)（酸性）或 c(OH⁻)（碱性）。
关键：水电离出的 H⁺ 和 OH⁻ 永远相等（因为来源只有水）。

2.3 盐类的水解

水解的规律

盐类水解的本质：盐电离出的离子与水电离出的 H⁺ 或 OH⁻ 结合生成弱电解质， 从而促进水的电离。 以醋酸钠为例： CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻ （醋酸根结合 H⁺，使溶液呈碱性）
口诀：有弱才水解，无弱不水解； 谁弱谁水解，谁强显谁性。 具体判断： 强酸强碱盐（NaCl）→ 不水解，中性 强酸弱碱盐（NH₄Cl）→ 阳离子水解，酸性 弱酸强碱盐（CH₃COONa）→ 阴离子水解，碱性 弱酸弱碱盐（CH₃COONH₄）→ 双水解，酸碱性看强弱
水解的三个重要规律：
①越弱越水解——对应的酸（或碱）越弱，该离子的水解程度越大。 所以酸性 CH₃COOH > HClO，则 NaClO 的水解程度 > CH₃COONa， 碱性 NaClO > CH₃COONa；
②越稀越水解——加水稀释促进水解；
③升温促进水解（水解是吸热的）。

影响水解的因素

  • 温度——升温促进水解。所以热纯碱溶液去油污效果更好。
  • 浓度——加水稀释促进水解。
  • 酸碱——加酸抑制阳离子水解、促进阴离子水解；加碱相反。

水解的应用

  • 配制 FeCl₃ 溶液要加盐酸——抑制 Fe³⁺ 水解，防止产生 Fe(OH)₃ 沉淀。
  • 用热的纯碱溶液洗涤油污——升温促进 CO₃²⁻ 水解，碱性增强，去污效果更好。
  • 泡沫灭火器——利用 Al³⁺ 和 HCO₃⁻ 的双水解，产生大量 CO₂。
  • 铵态氮肥不能与草木灰（含 K₂CO₃）混用——双水解使 NH₄⁺ 变成 NH₃ 跑掉，肥效降低。
  • 制备无机盐时要考虑水解——如需在 HCl 气氛中加热 MgCl₂·6H₂O 制无水 MgCl₂。
双水解要特别注意：两种能水解的离子混合时， 如果水解程度都很大，会互相促进，水解到底（完全水解）。
常见的完全双水解组合：
Al³⁺ 与 HCO₃⁻/CO₃²⁻/AlO₂⁻/S²⁻， Fe³⁺ 与 HCO₃⁻/CO₃²⁻/AlO₂⁻， NH₄⁺ 与 AlO₂⁻/SiO₃²⁻。
这些离子不能大量共存。

2.4 沉淀溶解平衡

溶度积

对于难溶电解质 AₘBₙ： AₘBₙ(s) ⇌ mA^(n+) + nB^(m−) 溶度积： Ksp = [A^(n+)]^m · [B^(m−)]^n （Ksp 只与温度有关）
判断沉淀生成与溶解：
设浓度商 Q = 各离子浓度的幂之积（与 Ksp 同形式）
·Q > Ksp → 有沉淀析出（过饱和）
·Q = Ksp → 恰好饱和，处于平衡
·Q < Ksp → 未饱和，沉淀溶解

沉淀的转化

规律：溶解度大的沉淀容易转化为溶解度小的沉淀。

原因：转化后体系中离子浓度降低，更「稳定」。
典型例子： AgCl + KI → AgI + KCl （AgI 比 AgCl 更难溶，所以能转化） 应用：锅炉除垢（CaSO₄ 转化为 CaCO₃ 再用酸洗）、 重晶石（BaSO₄）不溶于酸， 但可转化为更难溶的 BaCO₃ 后用酸溶解。
关于 Ksp 的两个易错点：
①Ksp 小的不一定先沉淀——还要看离子的初始浓度。 如果某种离子浓度极低，即使 Ksp 大也可能不沉淀；
②不同组成的难溶物不能直接比 Ksp 判断溶解度—— 必须是同类型（如都是 AB 型或都是 AB₂ 型）才能直接比。 不同类型的要先换算成溶解度再比。

沉淀溶解平衡的应用

  • 洗涤沉淀——用冷水（减少溶解损失）、或用含同离子的溶液洗涤。
  • 除去杂质离子——加入沉淀剂使杂质离子转化为沉淀。
  • 工业废水处理——使重金属离子（Pb²⁺、Hg²⁺ 等）转化为硫化物沉淀。
  • 牙齿保护——含氟牙膏让牙釉质转化为更难溶的氟磷酸钙，抗酸蚀能力增强。
例 2

已知 25 ℃ 时 Ksp(AgCl) = 1.8×10⁻¹⁰。向 0.1 mol/L 的 NaCl 溶液中滴加 AgNO₃ 溶液， 当 AgCl 开始沉淀时，溶液中的 [Ag⁺] 约为多少？

解：AgCl 开始沉淀的条件是 Q = Ksp。

Ksp = [Ag⁺][Cl⁻]

此时 [Cl⁻] ≈ 0.1 mol/L（AgNO₃ 加入量很少，Cl⁻ 浓度几乎不变）

[Ag⁺] = Ksp / [Cl⁻] = 1.8×10⁻¹⁰ / 0.1 = 1.8×10⁻⁹ mol/L

答案：[Ag⁺] 需要达到约 1.8×10⁻⁹ mol/L 才能开始沉淀。

注意这个数量级很小——说明在 Cl⁻ 浓度较高时， 极微量的 Ag⁺ 就能形成沉淀，这正是用 AgNO₃ 检验 Cl⁻ 灵敏度高的原因。

2.5 离子浓度大小比较（综合题型）

比较离子浓度大小的通用思路：
第一步——判断溶液的酸碱性（谁水解、显什么性）；
第二步——找出「主要离子」和「次要离子」（水解程度通常很小）；
第三步——用三大守恒检查结论是否合理： 电荷守恒：溶液中阳离子所带正电荷总数 = 阴离子所带负电荷总数 元素（物料）守恒：某元素的各形态浓度之和 = 起始浓度 质子守恒：得失质子数相等
以 0.1 mol/L 的 CH₃COONa 溶液为例，这个顺序要记住：
[Na⁺] > [CH₃COO⁻] > [OH⁻] > [H⁺]

为什么：
Na⁺ 不水解，浓度就是 0.1；CH₃COO⁻ 水解掉一小部分，所以略低于 0.1； OH⁻ 来自水解，数量少；H⁺ 来自水，数量最少（因为水解产生的 OH⁻ 抑制了水的电离）。

检查电荷守恒：[Na⁺] + [H⁺] = [CH₃COO⁻] + [OH⁻]， 把数值代入：0.1 + 极小 = 0.099… + 稍大，两边大致相等，合理。
本章的核心记忆点：
①有弱才水解，谁强显谁性；
②越弱越水解、越稀越水解、升温促进水解；
③Kw 和 Ksp 都只与温度有关；
④酸和碱抑制水电离，能水解的盐促进水电离；
⑤比较离子浓度先定主次，再用三大守恒验收。
