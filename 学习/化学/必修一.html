必修一 元素与反应基础

人教版必修第一册 · 元素与反应基础
必修一讲的是元素化合物——钠、铝、铁、氯、硫、氮这些元素 各自有什么性质、能发生什么反应。

它的核心工具是「物质的量」，贯穿全书； 它的核心思想是氧化还原反应，用来解释所有电子转移。

一、物质的量（必修一的钥匙）

n = m / M 质量与物质的量 n = N / Nₐ 微粒数与物质的量（Nₐ ≈ 6.02×10²³ /mol） n = V / Vm 气体体积（标准状况 Vm = 22.4 L/mol） c = n / V 物质的量浓度

使用这些公式的三个坑：

  • 22.4 L/mol 只适用于标准状况下的气体。常温常压不行，液体固体也不行。
  • "标准状况"是指 0 ℃、101 kPa，不是 25 ℃。
  • 浓度和体积是两个独立量——从 1 L 溶液里取出 100 mL，浓度不变，溶质的物质的量变成 1/10。
再补两个常考的坑：
①物质的状态要在标准状况下是气态才能用 22.4 L/mol。 比如标况下 H₂O 是液体，不能用这个数算；
②阿伏伽德罗常数题的常见陷阱——考查「是否标况」「是否气态」 「是否真的完全电离/反应」「有没有忽略溶剂中的原子」。

二、离子方程式

必须拆和不拆的

  • 要拆成离子的：强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶性盐
  • 不拆的：弱酸（CH₃COOH、H₂CO₃、HClO）、弱碱（NH₃·H₂O）、难溶物（BaSO₄、AgCl、CaCO₃）、氧化物、单质、水

常考的离子方程式

碳酸钙与盐酸：CaCO₃ + 2H⁺ → Ca²⁺ + H₂O + CO₂↑ 氢氧化钡与硫酸：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + 2H₂O 氯化铁与氢氧化钠：Fe³⁺ + 3OH⁻ → Fe(OH)₃↓ 铁与稀盐酸：Fe + 2H⁺ → Fe²⁺ + H₂↑ （注意生成 Fe²⁺不是 Fe³⁺）

检查离子方程式的两件事：①电荷是否守恒（左右两边电荷数要相等）；②原子是否守恒。

最常见错误：铁与稀盐酸、稀硫酸反应生成 Fe²⁺，不是 Fe³⁺； 但铁与氯气、硝酸反应生成 Fe³⁺。 因为盐酸的氧化性来自 H⁺，只能把铁氧化到 +2；氯气、硝酸氧化性强，直接到 +3。

三、氧化还原反应

本质与判断

本质：电子的转移（得失或偏移）。

判断依据：元素化合价是否发生变化。 化合价升高 = 失电子 = 被氧化 = 作还原剂； 化合价降低 = 得电子 = 被还原 = 作氧化剂。
口诀：「升失氧、降得还，剂性一致」 升（化合价升高）失（失电子）氧（被氧化）—— 是还原剂 降（化合价降低）得（得电子）还（被还原）—— 是氧化剂 注意区分「剂」和「被…」： 还原剂 —— 本身被氧化（它去还原别人） 氧化剂 —— 本身被还原（它去氧化别人） 记忆：「还（剂）被氧（化），氧（剂）被还（原）」
这一对关系最容易绕晕，用一句话固定下来：
还原剂失去电子，自己被氧化；氧化剂得到电子，自己被还原。
也就是说，名字里的「还」和「氧」说的是它对别人做的事， 而它自己身上发生的是相反的。

配平

配平方程式的一般顺序： ① 先配化合价变化的元素（氧化还原反应） ② 再配金属原子 ③ 再配非金属原子 ④ 最后配氢，用氧来验算 氧化还原配平的核心：得失电子总数必须相等

四、元素化合物

钠及其化合物

2Na + 2H₂O → 2NaOH + H₂↑ 2Na + O₂ --点燃--> Na₂O₂ （黄色火焰，生成淡黄色固体） 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ 2NaHCO₃ --加热--> Na₂CO₃ + H₂O + CO₂↑

钠与水的现象记五个字：浮、熔、游、响、红。浮（密度比水小）、熔（反应放热熔成小球）、游（产生气体推动）、响（发出嘶嘶声）、红（加酚酞变红，说明生成碱）。

碳酸钠与碳酸氢钠的区分：加热能分解的是 NaHCO₃；与盐酸反应更快放出气体的是 NaHCO₃；溶解度更大的是 Na₂CO₃。

铝的两性

2Al + 6HCl → 2AlCl₃ + 3H₂↑ 2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑ Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O Al(OH)₃ + NaOH → NaAlO₂ + 2H₂O

铝、氧化铝、氢氧化铝既能与酸反应又能与碱反应，这叫两性。氧化铝的熔点很高，所以铝制餐具不宜长时间盛放酸性或碱性食物。

铁的三价与二价

Fe³⁺ 的检验：加 KSCN 溶液变血红色 Fe²⁺ 的检验：加 KSCN 不变色，再加氯水变血红色 2Fe³⁺ + Fe → 3Fe²⁺ （三价铁被铁单质还原） 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ （二价铁被氯气氧化）

氯及其化合物

Cl₂ + H₂O ⇌ HCl + HClO （氯气溶于水，生成盐酸和次氯酸） Cl₂ + 2NaOH → NaCl + NaClO + H₂O （这是尾气处理的方法，用 NaOH 吸收多余的氯气） 2Fe + 3Cl₂ --点燃--> 2FeCl₃
次氯酸（HClO）的三个性质要记住：
①强氧化性——能杀菌消毒、漂白（把有色物质氧化掉，是永久性漂白）；
②弱酸性——酸性比碳酸还弱；
③不稳定——光照会分解：2HClO --光照--> 2HCl + O₂↑ ，所以氯水要现用现配、避光保存。

漂白原理的区分（常考）：
·HClO、Na₂O₂、O₃——氧化型漂白，永久性，不能复原；
·SO₂——化合型漂白，暂时性，加热可变回原色。

五、常见气体的实验室制法

O₂：加热 KMnO₄ 或 KClO₃（MnO₂ 催化） Cl₂：MnO₂ + 4HCl(浓) --加热--> MnCl₂ + Cl₂↑ + 2H₂O CO₂：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ NH₃：2NH₄Cl + Ca(OH)₂ --加热--> CaCl₂ + 2NH₃↑ + 2H₂O SO₂：Na₂SO₃ + H₂SO₄ → Na₂SO₄ + H₂O + SO₂↑
气体的收集方法要按性质选：
·向上排空气法——密度比空气大的（Cl₂、CO₂、SO₂）；
·向下排空气法——密度比空气小的（H₂、NH₃）；
·排水法——不溶于水且不与水反应的（O₂、H₂）；
·NH₃ 不能用排水法（极易溶于水）， 且要用向下排空气法，收集时试管口塞棉花（防止对流）。
例 1

标准状况下，将 2.24 L CO₂ 气体通入足量的 NaOH 溶液中，求生成的 Na₂CO₃ 的质量。

解：

第一步，求 CO₂ 的物质的量。

n(CO₂) = V / Vm = 2.24 / 22.4 = 0.1 mol

第二步，写方程式找关系。

CO₂ + 2NaOH → Na₂CO₃ + H₂O

CO₂ 与 Na₂CO₃ 的计量数之比是 1:1，所以：

n(Na₂CO₃) = 0.1 mol

第三步，求质量。M(Na₂CO₃) = 23×2 + 12 + 16×3 = 106 g/mol

m = n·M = 0.1 × 106 = 10.6 g

答案：生成 10.6 g Na₂CO₃。

注意：CO₂ 过量时会生成 NaHCO₃，所以「足量 NaOH」这个条件很关键—— 它保证了产物是正盐而不是酸式盐。

必修一的复习建议：
这一册信息量最大，但结构清楚：
·物质的量——所有计算的工具；
·离子方程式——水溶液中反应的统一表示；
·氧化还原——电子转移的统一解释；
·元素化合物——具体物质的性质（钠、铝、铁、氯是重点）。
前三个是「方法」，第四个是「素材」。方法吃透了，素材才记得住。
