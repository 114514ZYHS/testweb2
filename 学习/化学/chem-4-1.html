第 1 章 化学反应速率与化学平衡

人教版选择性必修第一册 · 1.1 – 1.3
本章要回答两个问题：
①「反应有多快」——化学反应速率，以及怎么让它变快变慢；
②「反应能进行到什么程度」——化学平衡，以及怎么让平衡往想要的方向移动。

这两件事是化工生产的两条腿：既要有速度，又要有产率。

1.1 化学反应速率

定义与计算

v = Δc / Δt 单位：mol/(L·s) 或 mol/(L·min) 对反应 aA + bB → cC + dD，各物质的速率之比等于化学计量数之比： v(A) : v(B) : v(C) : v(D) = a : b : c : d
比较反应速率大小时必须先换算成同一物质。
题目给的是「用 A 表示是 0.5 mol/(L·s)，用 B 表示是 0.9 mol/(L·s)」， 不能直接比大小，要先按计量数比换算到同一个物质。

另外注意：固体和纯液体的浓度视为常数， 不能用它们表示反应速率。

影响速率的因素

影响速率的外界因素及原因（本质要理解）：

  • 浓度——增大反应物浓度，单位体积内分子数增多，有效碰撞次数增多，速率加快。
  • 压强——对气体反应，增大压强相当于减小体积、增大浓度，速率加快。 注意：只有涉及气体的反应才有影响；对固体、液体加压没影响。
  • 温度——升高温度，分子运动加快，活化分子数增多，速率加快。 温度对速率的影响最显著——通常每升高 10 ℃，速率约增到 2–4 倍。
  • 催化剂——降低反应活化能，让更多分子成为活化分子，速率加快。 催化剂只改变速率，不影响平衡转化率。
  • 表面积——固体颗粒越小，接触面积越大，速率越快。
活化分子与有效碰撞（理解速率的钥匙）：
只有能量足够高的分子（活化分子）相互碰撞，且方向合适，才能发生反应（有效碰撞）。

活化能：普通分子变成活化分子所需的最小能量。
催化剂的作用就是降低活化能，让更多分子能达到这个门槛。
关于压强的一个常见误解：
「增大压强」必须真正改变浓度才有效。
恒温恒容时充入「惰性气体」，虽然总压增大，但各反应物浓度没变， 反应速率不变。
同样，恒温恒压充入惰性气体，体积增大，反应物浓度减小， 速率反而减慢。这一正一反是选择题最爱考的。

1.2 化学平衡状态

什么叫化学平衡

化学平衡状态：在一定条件下的可逆反应里， 正反应速率与逆反应速率相等，反应混合物中各组分浓度保持不变的状态。

平衡的三大特征：
①逆——只可能发生在可逆反应中；
②等——v正 = v逆（这是本质）；
③动——是动态平衡，反应并没有停止，只是正逆速率相等。

如何判断到达平衡

「变量不变」就是判据——这是判断平衡的通用思路。
选一个在反应过程中会发生变化的量，如果它不再变了，就说明平衡了。

可以判断平衡的量：
·各组分浓度、物质的量、质量分数不再变化；
·有颜色的物质颜色不再变化；
·有气体的反应，总压（恒容）、总体积（恒压）、平均相对分子质量不再变化；
·正逆反应速率相等（或某物质消耗速率 = 生成速率）。

不能判断平衡的量：
·那些在整个过程中始终不变的量。 例如反应前后气体分子数相等的反应（如 H₂+I₂⇌2HI）， 总压和平均相对分子质量始终不变，就不能作为判据。

1.3 化学平衡的移动

勒夏特列原理

勒夏特列原理：如果改变影响平衡的一个条件（浓度、压强、温度）， 平衡将向着能够减弱这种改变的方向移动。

关键理解「减弱」不是「抵消」。 比如增大反应物浓度，平衡会向正反应方向移动（消耗掉一部分）， 但新平衡时该反应物的浓度仍比原来高——只是比刚加入时低了。

各种条件的影响

增大反应物浓度 → 平衡向正反应（消耗反应物）方向移动 减小生成物浓度 → 平衡向正反应（生成生成物）方向移动 增大压强 → 平衡向气体分子数减少的方向移动 减小压强 → 平衡向气体分子数增多的方向移动 （气体分子数不变的反应，压强无影响） 升高温度 → 平衡向吸热方向移动 降低温度 → 平衡向放热方向移动 催化剂 → 不影响平衡移动，只缩短到达平衡所需的时间
三条最容易记错的地方：
①「向气体分子数减少的方向」要看方程式两边气体计量数之和， 如果有固体或液体参与，它们不计入；
②催化剂不能让平衡移动——它只是让正逆反应都加快， 到达平衡更快，但平衡位置不变；
③温度改变一定影响平衡（因为会改变 K）， 而浓度、压强改变不改变 K 值，只是改变了浓度商 Q 与 K 的关系。

平衡常数

对于反应 aA + bB ⇌ cC + dD K = [C]^c · [D]^d / ([A]^a · [B]^b) （固体和纯液体不写入表达式） 判断平衡移动方向： Q < K → 正向进行 Q = K → 已达平衡 Q > K → 逆向进行
K 的意义（考频很高）：
①K 只与温度有关——温度不变，K 就不变，无论怎么改浓度或压强；
②K 越大，反应进行得越完全，反应物转化率越高；
③K 是常数，所以「改变浓度后 K 不变」这句话永远是对的。
例 1

对于反应 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)（正反应放热）。判断下列操作对平衡的影响：

（1）增大压强；（2）升高温度；（3）加入催化剂。

解：

（1）增大压强。反应前气体分子数 = 1 + 3 = 4，反应后 = 2。 正反应方向气体分子数减少，所以平衡向正反应方向移动（有利于生成氨）。

（2）升高温度。正反应放热，即逆反应吸热。 升高温度平衡向吸热方向移动，所以平衡向逆反应方向移动（氨的产率下降）。

（3）加入催化剂。平衡不移动。 催化剂同等程度加快正逆反应，只缩短到达平衡的时间，不改变平衡位置和转化率。

工业上的启示：要得到高氨产率需要高压、低温， 但低温下反应太慢，所以要权衡——实际用 400–500 ℃ 和 10–30 MPa， 并用铁触媒加快反应。这就是「既要快又要多」的典型例子。

转化率的相关计算

转化率 α = (已转化的量 / 起始的量) × 100% 三段式计算法（最基本的方法）： A + B ⇌ C 起始： a b 0 变化： x x x 平衡： a − x b − x x 把「平衡浓度」代入 K 的表达式求解。
三段式的两个要点：
①「变化量」必须按化学计量数的比例写，这是最容易错的地方；
②列的是浓度（如果给的是物质的量，要除以体积）。

另外记住一个规律：恒温恒容下增大一种反应物的浓度， 能提高另一种反应物的转化率，但自己本身的转化率会下降。

1.4 等效平衡与工业应用

等效平衡

等效平衡：一定条件下，对于同一可逆反应， 如果按不同方式投料，最后达到的平衡状态中各组分含量（百分含量）相同， 这些平衡就互为等效平衡。

判断方法：把投料量按化学计量数折算成同一边（都折成反应物或都折成生成物）， 如果折算后各物质的量相同，就是等效平衡（恒温恒容时）。

工业合成氨的条件选择（经典案例）

N₂(g) + 3H₂(g) ⇌ 2NH₃(g) ΔH < 0（放热） 理论上的最优条件： 高压 + 低温 → 平衡转化率高 实际采用的工业条件： 压强 10–30 MPa（高压但不到极限） 温度 400–500 ℃（并不低） 使用铁触媒作催化剂 及时分离出液氨
为什么理论和实际不一致——这是本章最值得体会的地方：
低温虽然平衡转化率高，但反应速率太慢，到达平衡要很久，工业上不划算。
所以选 400–500 ℃：牺牲一点转化率，换取足够快的反应速率。
用催化剂也是同样的考虑——它不改变平衡，但能大幅加快反应。
工业生产的核心是「综合权衡」，不是单看某一项指标最优。
例 2

在恒容密闭容器中，反应 H₂(g) + I₂(g) ⇌ 2HI(g) 在某温度下达到平衡。 已知起始时 H₂ 和 I₂ 的浓度均为 1.0 mol/L，平衡时 HI 的浓度为 1.6 mol/L。求该温度下的平衡常数 K。

解：用三段式。

H₂ 的变化量 = HI 的变化量 / 2 = 1.6 / 2 = 0.8 mol/L

平衡时：

[H₂] = 1.0 − 0.8 = 0.2 mol/L

[I₂] = 1.0 − 0.8 = 0.2 mol/L

[HI] = 1.6 mol/L

代入 K 的表达式：

K = [HI]² / ([H₂][I₂]) = 1.6² / (0.2 × 0.2)

= 2.56 / 0.04 = 64

答案：K = 64。

注意：这个反应前后气体分子数相等， 所以改变压强平衡不移动，K 也不变。

本章的核心记忆点：
①速率看「快慢」，平衡看「多少」——两者是两回事；
②催化剂加快速率，但不移动平衡；
③K 只与温度有关；
④勒夏特列原理是「减弱」不是「抵消」；
⑤比较速率必须先换算到同一物质。
