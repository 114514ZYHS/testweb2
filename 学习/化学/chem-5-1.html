第 1 章 原子结构与性质

人教版选择性必修第二册 · 1.1 – 1.2
本章要回答的一个问题：为什么元素的性质会呈现周期性？

答案是——因为原子的电子排布呈现周期性。 这一章就是把「电子怎么排」讲清楚，然后由排布推出性质。

1.1 能层、能级与原子轨道

能层与能级

能层（用 n 表示）：K、L、M、N、O、P、Q 对应 n = 1、2、3、4、5、6、7 每个能层的能级数 = 该能层的序号： 第 1 能层（K）只有 1 个能级：1s 第 2 能层（L）有 2 个能级：2s、2p 第 3 能层（M）有 3 个能级：3s、3p、3d 第 4 能层（N）有 4 个能级：4s、4p、4d、4f 各能级最多容纳的电子数： s 能级：1 个轨道 × 2 = 2 个电子 p 能级：3 个轨道 × 2 = 6 个电子 d 能级：5 个轨道 × 2 = 10 个电子 f 能级：7 个轨道 × 2 = 14 个电子
原子轨道：电子在核外空间出现的概率分布的图形化描述。
一个轨道最多容纳 2 个电子，且这两个电子的自旋方向相反 （这叫泡利原理）。

轨道形状：s 轨道是球形，p 轨道是哑铃形（有 3 个相互垂直的方向 p_x、p_y、p_z）。

1.2 核外电子排布规律

三条基本原理

① 能量最低原理——电子总是优先占据能量最低的轨道。

② 泡利不相容原理——一个原子轨道最多容纳 2 个电子，且自旋相反。

③ 洪特规则——在同一能级的等价轨道上，电子总是优先单独占据不同轨道， 且自旋方向相同。

构造原理（填充顺序）

1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p → 7s → 5f → 6d → 7p 记忆口诀（按能级组排）： 1s | 2s 2p | 3s 3p | 4s 3d 4p | 5s 4d 5p | 6s 4f 5d 6p | ... 注意：4s 的能量低于 3d，所以先填 4s。 （这叫「能级交错」，是常考的点）
这一部分最容易错的三处：
①4s 先于 3d 填充——但失去电子时，先失 4s 上的。 比如 Fe 的电子排布是 [Ar]3d⁶4s²，但 Fe²⁺ 是 [Ar]3d⁶（4s 先失）；
②洪特规则的特例——等价轨道处于全充满（p⁶、d¹⁰）、 半充满（p³、d⁵）、全空状态时能量较低、更稳定。 所以 Cr 是 [Ar]3d⁵4s¹（而不是 3d⁴4s²），Cu 是 [Ar]3d¹⁰4s¹（而不是 3d⁹4s²）；
③电子排布式要按能层顺序写——写成 [Ar]3d⁶4s²，不是把 4s 写在前面。

四种表示方法

以铁（Fe，Z = 26）为例，已有 [Ar] 3d⁶ 4s² ① 电子排布式： 1s²2s²2p⁶3s²3p⁶3d⁶4s² 或简写为： [Ar]3d⁶4s² ② 简化电子排布式： [Ar]3d⁶4s² ③ 电子排布图（轨道表示式）：用方框和箭头画出每个轨道及电子 ④ 价电子排布式： 3d⁶4s² （价电子 = 最外层电子 + 参与成键的次外层电子）
价电子排布要特别注意主族和副族的差别：
主族元素——价电子只在最外层（ns、np）；
副族元素（过渡元素）——价电子包括最外层 s 和次外层 d， 所以写成 (n−1)d + ns。

例子：
Na（Z=11）：3s¹
Cl（Z=17）：3s²3p⁵
Fe（Z=26）：3d⁶4s²
Cu（Z=29）：3d¹⁰4s¹

1.3 元素周期律

原子结构与位置的关系

周期数 = 电子层数 = 最高能层序数 族序数： 主族（A）——族序数 = 最外层电子数 = 价电子数 副族（B）——由 (n−1)d + ns 的电子数决定 常见对应： ⅠA 族：ns¹ ⅦA 族：ns²np⁵ 0 族（稀有气体）：ns²np⁶（He 是 1s²）

周期性递变规律

同周期（从左到右）： 电子层数相同，但核电荷数增大，原子半径减小 → 金属性减弱，非金属性增强 → 最高价氧化物对应水化物的碱性减弱、酸性增强 → 第一电离能总体增大（但有反常） 同主族（从上到下）： 电子层数增大，原子半径增大 → 金属性增强，非金属性减弱 → 第一电离能减小，电负性减小
第一电离能的「两个反常」必须记住（常考）：
反常一：同一周期中，第 ⅡA 族 > 第 ⅢA 族 （如 Be > B、Mg > Al）
原因：ⅡA 族是 ns² 全充满，比较稳定，难失电子。

反常二：同一周期中，第 ⅤA 族 > 第 ⅥA 族 （如 N > O、P > S）
原因：ⅤA 族是 ns²np³ 半充满，比较稳定。

这两个反常是洪特规则特例在电离能上的体现。

电负性

电负性：元素的原子在化合物中吸引电子的能力。

规律：周期表从左到右递增，从上到下递减。
最大的是 F（4.0），其次是 O（3.5）。

两个常用判断：
①电负性差 > 1.7 → 一般形成离子键；
②电负性差 < 1.7 → 一般形成共价键。
电负性的两个应用： ① 判断金属性、非金属性 电负性越大 → 非金属性越强 电负性越小 → 金属性越强 ② 判断化合物中元素的化合价 电负性大的元素显负价，电负性小的显正价 例：在 HCl 中，Cl 电负性大，显 −1 价；H 显 +1 价
例 1

比较 Na、Mg、Al 三种元素的第一电离能大小，并说明原因。

解：三种元素都在第三周期，从左到右依次排列。

第一电离能：Na < Mg < Al？——不对，需要检查反常。

Mg 是 ⅡA 族（3s²），是全充满结构，特别稳定， 失电子比 Al（3s²3p¹）更难。

所以正确顺序是：

Na（3s¹）< Al（3s²3p¹）< Mg（3s²）

答案：Na < Al < Mg。

结论：第一电离能不是简单递增， 遇到 ⅡA、ⅤA 族时要留意反常。这题的陷阱就在 Al 和 Mg 的顺序上。

本章的核心记忆点：
①4s 先填，但先失（填充顺序和失电子顺序要分清）；
②Cr 和 Cu 是特例（半充满、全充满更稳定）；
③第一电离能的两个反常（ⅡA 和 ⅤA 偏高）；
④电负性最大是 F，1.7 是离子键与共价键的分界；
⑤价电子里主族只看最外层，副族要带上次外层 d。
