第 3 章 电化学

人教版选择性必修第一册 · 3.1 – 3.4
本章的核心就是一对相反的过程：
原电池——化学能 → 电能（自发的氧化还原反应，用来发电）
电解池——电能 → 化学能（被迫的氧化还原反应，用来制备）

两者是逆过程。抓住这个对称性，很多东西就不需要分别背了。

3.1 原电池

构成条件

构成原电池的四个条件（缺一不可）：
①有两个活泼性不同的电极；
②有电解质溶液；
③形成闭合回路；
④能自发进行的氧化还原反应。

本质：把氧化反应和还原反应「分开」在两个电极上进行， 让电子必须走外电路，从而产生电流。

电极判断与反应

负极：较活泼的金属，发生氧化反应（失电子） e⁻ 从负极经外电路流向正极 正极：较不活泼的电极，发生还原反应（得电子） 电流方向：正极 → 外电路 → 负极（与电子方向相反） 电解质溶液中：阳离子移向正极，阴离子移向负极
三句记忆口诀，做题够用：
①「负极失电子被氧化」——负、失、氧，三个字连在一起记；
②电子只在导线上跑，不进入溶液——所以写电极反应时不要出现 e⁻ 在溶液里移动；
③阳离子向正极移动（阳正、阴负，方向对应）。
例 1

铜锌原电池，电解质溶液为稀硫酸。写出两个电极的反应式和总反应式。

解：Zn 比 Cu 活泼，所以 Zn 是负极。

负极（Zn，氧化反应）：

Zn − 2e⁻ → Zn²⁺

正极（Cu，还原反应）：溶液中的 H⁺ 得电子

2H⁺ + 2e⁻ → H₂↑

总反应：把两式相加，消去电子

Zn + 2H⁺ → Zn²⁺ + H₂↑

答案如上。

现象：锌片逐渐溶解，铜片上有气泡冒出（H₂），电流计指针偏转。

常见的化学电源

  • 一次电池——用完就丢。如干电池（锌锰电池）。
  • 二次电池（蓄电池）——可充放电。如铅蓄电池。 放电时是原电池，充电时是电解池，这是常考的转换。
  • 燃料电池——燃料和氧化剂分别通入，持续供电。 如氢氧燃料电池，产物只有水，清洁高效。
关于铅蓄电池的重点：
放电（原电池）：Pb 是负极，PbO₂ 是正极，电解质是稀 H₂SO₄。 放电过程中消耗硫酸，硫酸浓度降低。
充电（电解池）：与外电源相接， 原电池的负极接外电源的负极，正极接正极—— 所以叫「正接正、负接负」。
充电时硫酸浓度回升，这是判断充电进度的依据。

3.2 电解池

构成与原理

电解池的三个条件：
①有外接直流电源；②有电极；③有电解质溶液或熔融电解质。

核心：外电源强迫电子流动，使本来不能自发进行的反应发生。
与外电源负极相连的电极 → 阴极 → 发生还原反应（得电子） 与外电源正极相连的电极 → 阳极 → 发生氧化反应（失电子） 记忆：阴（极）还（原），阳（极）氧（化） 「阴还阳氧」
这一点和原电池是相反的，是最大的坑：
原电池：负极 = 氧化反应，正极 = 还原反应
电解池：阴极 = 还原反应，阳极 = 氧化反应

注意区分「负极/正极」和「阴极/阳极」这两套名字—— 原电池用正负极，电解池用阴阳极，不能混用。

放电顺序（选择题的核心）

阴极（还原反应）——阳离子得电子，按氧化性从强到弱排队： Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺(酸) > Fe²⁺ > Zn²⁺ > H⁺(水) > Al³⁺ > Mg²⁺ > Na⁺ 越靠前的越容易在阴极放电。 阳极（氧化反应）——分两种情况： ① 惰性电极（Pt、石墨）：溶液中阴离子按还原性排队 S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根(SO₄²⁻、NO₃⁻等) ② 活性电极（Cu、Ag 等金属）：电极本身溶解，比溶液中的离子更容易失电子 所以活性电极阳极时，阳极是电极材料被氧化
「阳极看电极材料，阴极看离子顺序」这句话是解题关键。
·阳极如果是活性金属，那阳极就是这块金属溶解，不管溶液里有什么离子；
·阳极如果是惰性电极（石墨、铂），才轮到溶液中的阴离子放电；
·阴极永远看溶液中的阳离子，按顺序排。阴极本身不参与反应。

另外注意：含氧酸根（SO₄²⁻、NO₃⁻）在水中很难放电， 因为对应的还原性极弱。所以稀硫酸电解时，阳极实际是 OH⁻ 放电产生 O₂。
例 2

用石墨电极电解 CuCl₂ 溶液。写出两极反应和总反应。

解：石墨是惰性电极，所以阳极看溶液中的阴离子。

溶液中有 Cu²⁺ 和 Cl⁻。

阴极：阳离子中 Cu²⁺ 比 H⁺ 容易放电（Cu²⁺ 在 H⁺ 前面）

Cu²⁺ + 2e⁻ → Cu

阳极：阴离子中只有 Cl⁻ 和 OH⁻， Cl⁻ 的还原性比 OH⁻ 强，所以 Cl⁻ 先放电

2Cl⁻ − 2e⁻ → Cl₂↑

总反应：

Cu²⁺ + 2Cl⁻ --电解--> Cu + Cl₂↑

现象：阴极上析出红色铜，阳极上产生黄绿色气体（Cl₂）， 溶液中蓝色逐渐变浅（Cu²⁺ 被消耗）。

电解的应用

  • 电解饱和食盐水（氯碱工业）—— 阳极 Cl⁻ 放电产 Cl₂，阴极 H⁺ 放电产 H₂，同时产生 NaOH。
  • 电解精炼铜——粗铜作阳极，纯铜作阴极， 电解质是 CuSO₄ 溶液。杂质中比铜活泼的溶解，比铜不活泼的成为阳极泥。
  • 电镀——镀层金属作阳极，待镀件作阴极， 电解质含镀层金属离子。电镀时电解质溶液浓度基本不变。
  • 电解冶炼活泼金属——Na、Mg、Al 等不能用水溶液电解 （因为 H₂O 中的 H⁺ 会比它们先放电），必须用熔融盐。
电镀和电解精炼的区别（容易混）：
电镀：阳极是镀层金属，阴极是待镀件，溶液中含同种金属离子 → 溶液浓度不变（阳极溶解多少，阴极就析出多少）。
电解精炼铜：阳极是粗铜（含杂质），阴极是纯铜 → 因为杂质的存在，溶液中的 Cu²⁺ 浓度会略有变化。

3.3 金属腐蚀与防护

两种腐蚀

化学腐蚀：金属与接触到的物质直接发生化学反应。 如铁在高温下与氧气反应。没有电流产生。

电化学腐蚀：金属与接触的电解质溶液接触，发生原电池反应。 钢铁在大气中的腐蚀主要属于这一类，比化学腐蚀更普遍、更严重。
钢铁的两种电化学腐蚀： ① 析氢腐蚀（酸性较强环境） 负极：Fe − 2e⁻ → Fe²⁺ 正极：2H⁺ + 2e⁻ → H₂↑ ② 吸氧腐蚀（中性或弱酸性环境，更常见） 负极：Fe − 2e⁻ → Fe²⁺ 正极：O₂ + 2H₂O + 4e⁻ → 4OH⁻
吸氧腐蚀是钢铁腐蚀的主要形式——因为大多数自然环境是中性或弱酸性的。 判断用哪种：看环境是较强酸性（析氢）还是中性/弱酸性（吸氧）。

金属防护的方法

  • 外加保护层——涂漆、涂油、电镀、搪瓷、塑料覆盖。
  • 改变金属内部结构——制成合金，如不锈钢。
  • 电化学保护法： ①牺牲阳极法——接一块活泼金属（Zn、Mg），让它先被腐蚀， 被保护的金属作正极。轮船船体上焊的锌块就是。 ②外加电流法——把被保护金属接外电源负极，作阴极； 另用一块惰性电极作阳极。用于大型设备、地下管道。
关键点：无论哪种电化学保护，被保护的金属都必须是「正极」或「阴极」。
因为正极（阴极）是得电子的，金属不会失去电子被氧化。
保护金属 = 让它当正极/阴极 = 让它不失去电子。
这一条理解了，牺牲阳极和外加电流两种方法就不用分别背了。

电化学计算

电子守恒是计算的核心： 串联的电解池中，各电极上转移的电子数相等。 常用关系（以转移 1 mol e⁻ 计）： 析出 1 mol Ag （Ag⁺ + e⁻ → Ag） 析出 0.5 mol Cu （Cu²⁺ + 2e⁻ → Cu） 产生 0.5 mol H₂ （2H⁺ + 2e⁻ → H₂） 产生 0.5 mol Cl₂ （2Cl⁻ − 2e⁻ → Cl₂） 产生 0.25 mol O₂ （4OH⁻ − 4e⁻ → O₂ + 2H₂O）
例 3

用石墨电极电解 CuSO₄ 溶液，当阴极析出 0.32 g 铜时，阳极产生标准状况下气体的体积是多少？ （Cu 的相对原子质量为 64）

解：

第一步，求转移的电子的物质的量。

n(Cu) = 0.32 / 64 = 0.005 mol

由 Cu²⁺ + 2e⁻ → Cu，转移电子：

n(e⁻) = 0.005 × 2 = 0.01 mol

第二步，阳极反应。阳极是 OH⁻ 放电（SO₄²⁻ 不放电）：

4OH⁻ − 4e⁻ → O₂↑ + 2H₂O

即转移 4 mol 电子产生 1 mol O₂。

n(O₂) = 0.01 / 4 = 0.0025 mol

第三步，求体积。标准状况下 Vm = 22.4 L/mol。

V = 0.0025 × 22.4 = 0.056 L = 56 mL

答案：阳极产生 56 mL 氧气（标准状况）。

验算思路：用电子守恒——阴极得 0.01 mol 电子， 阳极必须失 0.01 mol 电子，这条线索把两极连起来， 是电化学计算的通用思路。

本章的核心记忆点：
①原电池：负氧正还；电解池：阴还阳氧；
②阳极看电极材料，阴极看离子顺序；
③电子只在导线上流动；溶液中阳离子向正极/阴极移动；
④保护金属就让它当正极（阴极）；
⑤电化学计算一律用电子守恒串联两极。
