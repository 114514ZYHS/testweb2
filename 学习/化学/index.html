化学

人教版 · 必修第一、二册 · 元素与反应原理
人教版化学必修第一册讲元素化合物，第二册讲元素周期律、有机基础、化学反应与能量。 化学的难点不在理解而在记准——方程式配平、反应条件、现象描述，错一点就丢分。
一、物质的量（必修一的钥匙）
n = m / M 质量与物质的量 n = N / Nₐ 微粒数与物质的量（Nₐ ≈ 6.02×10²³ /mol） n = V / Vm 气体体积（标准状况 Vm = 22.4 L/mol） c = n / V 物质的量浓度

使用这些公式的三个坑：

  • 22.4 L/mol 只适用于标准状况下的气体。常温常压不行，液体固体也不行。
  • "标准状况"是指 0 ℃、101 kPa，不是 25 ℃。
  • 浓度和体积是两个独立量——从 1 L 溶液里取出 100 mL，浓度不变，溶质的物质的量变成 1/10。

配平方程式的一般顺序

  1. 先配化合价变化的元素（氧化还原反应）
  2. 再配金属原子
  3. 再配非金属原子
  4. 最后配氢，用氧来验算
二、离子方程式

必须拆和不拆的

  • 要拆成离子的：强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶性盐
  • 不拆的：弱酸（CH₃COOH、H₂CO₃、HClO）、弱碱（NH₃·H₂O）、难溶物（BaSO₄、AgCl、CaCO₃）、氧化物、单质、水

常考的离子方程式

碳酸钙与盐酸：CaCO₃ + 2H⁺ → Ca²⁺ + H₂O + CO₂↑ 氢氧化钡与硫酸：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + 2H₂O 氯化铁与氢氧化钠：Fe³⁺ + 3OH⁻ → Fe(OH)₃↓ 铁与稀盐酸：Fe + 2H⁺ → Fe²⁺ + H₂↑ （注意生成 Fe²⁺不是 Fe³⁺）

检查离子方程式的两件事：①电荷是否守恒（左右两边电荷数要相等）；②原子是否守恒。

最常见错误：铁与稀盐酸、稀硫酸反应生成 Fe²⁺，不是 Fe³⁺；但铁与氯气、硝酸反应生成 Fe³⁺。 因为盐酸的氧化性来自 H⁺，只能把铁氧化到 +2；氯气、硝酸氧化性强，直接到 +3。
三、元素化合物

钠及其化合物

2Na + 2H₂O → 2NaOH + H₂↑ 2Na + O₂ --点燃--> Na₂O₂ （黄色火焰，生成淡黄色固体） 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ 2NaHCO₃ --加热--> Na₂CO₃ + H₂O + CO₂↑

钠与水的现象记五个字：浮、熔、游、响、红。浮（密度比水小）、熔（反应放热熔成小球）、游（产生气体推动）、响（发出嘶嘶声）、红（加酚酞变红，说明生成碱）。

碳酸钠与碳酸氢钠的区分：加热能分解的是 NaHCO₃；与盐酸反应更快放出气体的是 NaHCO₃；溶解度更大的是 Na₂CO₃。

铝的两性

2Al + 6HCl → 2AlCl₃ + 3H₂↑ 2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑ Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O Al(OH)₃ + NaOH → NaAlO₂ + 2H₂O

铝、氧化铝、氢氧化铝既能与酸反应又能与碱反应，这叫两性。氧化铝的熔点很高，所以铝制餐具不宜长时间盛放酸性或碱性食物。

铁的三价与二价

Fe³⁺ 的检验：加 KSCN 溶液变血红色 Fe²⁺ 的检验：加 KSCN 不变色，再加氯水变血红色 2Fe³⁺ + Fe → 3Fe²⁺ （三价铁被铁单质还原） 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ （二价铁被氯气氧化）
四、元素周期律

同周期从左到右：原子半径减小、金属性减弱、非金属性增强。

同主族从上到下：原子半径增大、金属性增强、非金属性减弱。

判断金属性强弱的实验依据：与水或酸反应置换氢的难易、最高价氧化物对应水化物的碱性强弱、能否把另一种金属从其盐溶液中置换出来。

五、化学反应与能量

放热与吸热

判断依据是反应物和生成物的总能量高低，不是"要不要加热"。

  • 放热反应：燃烧、中和、金属与酸、大多数化合反应
  • 吸热反应：大多数分解反应、Ba(OH)₂·8H₂O 与 NH₄Cl、C 与 CO₂、C 与 H₂O

注意：需要加热的反应不一定是吸热反应。比如碳燃烧需要点燃，但它是放热的。

原电池

构成条件：两个活泼性不同的电极、电解质溶液、形成闭合回路、能自发进行的氧化还原反应。

以铜锌原电池（稀硫酸）为例：

负极（Zn，较活泼）：Zn - 2e⁻ → Zn²⁺ 发生氧化反应 正极（Cu）：2H⁺ + 2e⁻ → H₂↑ 发生还原反应 总反应：Zn + 2H⁺ → Zn²⁺ + H₂↑

记法：负极失电子被氧化，正极得电子被还原。电子从负极经外电路流向正极。
