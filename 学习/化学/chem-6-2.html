第 2 章 烃

人教版选择性必修第三册 · 2.1 – 2.4
「烃」是什么：只由碳和氢两种元素组成的有机物。

烃是有机化学的骨架，其他有机物基本都可以看成 「烃 + 官能团」。
本章按「饱和度」依次推进：烷烃 → 烯烃 → 炔烃 → 芳香烃。

2.1 烷烃

结构与通式

通式： CₙH₂ₙ₊₂ 碳碳之间全是单键（σ 键），是饱和烃。 碳原子的杂化方式：sp³ 性质特点： ①不能发生加成反应（已经饱和了） ②主要反应是取代（与卤素在光照下）和燃烧 ③随着碳数增加，熔沸点升高

典型反应：取代

甲烷与氯气的取代（需要光照）： CH₄ + Cl₂ --光照--> CH₃Cl + HCl CH₃Cl + Cl₂ --光照--> CH₂Cl₂ + HCl CH₂Cl₂ + Cl₂ --光照--> CHCl₃ + HCl CHCl₃ + Cl₂ --光照--> CCl₄ + HCl 注意：反应是分步进行的，产物是四种氯代物的混合物， 所以工业上不能用来制取纯净的氯代物。
甲烷取代反应的现象（实验考点）：
①气体颜色逐渐变浅——Cl₂ 被消耗了；
②试管内壁出现油状液滴——CH₂Cl₂、CHCl₃、CCl₄ 不溶于水且是油状液体；
③液面上升——气体总物质的量减少；
④有白雾出现——生成的 HCl 溶于水（遇水蒸气形成盐酸小液滴）。

关键条件：必须光照（漫射光，不能直射，否则爆炸）， 不能是水溶液（氯水不行，要纯氯气）。

2.2 烯烃

结构与通式

通式： CₙH₂ₙ （n ≥ 2，含一个 C=C） 碳碳双键：1 个 σ 键 + 1 个 π 键 碳原子的杂化方式：sp² 分子是平面结构（双键碳及其相连的 4 个原子共平面） 性质特点： C=C 是不饱和键，能发生加成反应（这是烯烃的标志反应）

典型反应：加成

① 与卤素加成（使溴水褪色）： CH₂=CH₂ + Br₂ → CH₂BrCH₂Br 这个反应用来鉴别烯烃——溴水褪色 ② 与 H₂ 加成（催化加氢）： CH₂=CH₂ + H₂ --Ni,加热--> CH₃CH₃ ③ 与 HX 加成（马氏规则）： CH₂=CH₂ + HCl → CH₃CH₂Cl ④ 与水加成（工业制乙醇）： CH₂=CH₂ + H₂O --催化剂--> CH₃CH₂OH ⑤ 加聚反应： nCH₂=CH₂ --催化剂--> [CH₂−CH₂]ₙ（聚乙烯）
马氏规则（不对称烯烃的加成取向）：
不对称烯烃与 HX 加成时，氢原子加到含氢较多的双键碳上。

例：CH₃−CH=CH₂ + HCl → CH₃−CHCl−CH₃（主要产物）
而不是 CH₃−CH₂−CH₂Cl。

这个规则高中阶段一般是「知道结论」即可，能判断加成产物就行。
鉴别烯烃和烷烃的方法（必考）：
用溴水——烯烃能使溴水褪色（发生加成），烷烃不能（只能萃取，现象不同）。
或用酸性 KMnO₄ 溶液——烯烃能使它褪色（被氧化），烷烃不能。

注意两者的区别：
·溴水褪色是因为发生了加成反应（溴被消耗）；
·酸性 KMnO₄ 褪色是因为发生了氧化反应（Mn 从 +7 价降到 +2 价）。
两者机理不同，别混为一谈。

2.3 炔烃

结构与通式

通式： CₙH₂ₙ₋₂ （含一个 C≡C） 碳碳三键：1 个 σ 键 + 2 个 π 键 碳原子的杂化方式：sp 分子是直线形（三键碳及其相连的 2 个原子在同一直线上） 典型代表：乙炔 CH≡CH（俗称电石气）

乙炔的制备

实验室制法： CaC₂ + 2H₂O → Ca(OH)₂ + CH≡CH↑ （电石 CaC₂ 与水反应，非常剧烈）
制乙炔的实验注意事项：
①用饱和食盐水代替水——减缓反应速率，防止产生气泡过快；
②不能用启普发生器——因为反应太剧烈，且生成的 Ca(OH)₂ 会堵塞；
③生成的乙炔气体常含 H₂S、PH₃ 等杂质，有特殊臭味， 需要净化才能得到纯净的乙炔；
④乙炔能使溴水和酸性 KMnO₄ 都褪色。

2.4 芳香烃

苯的结构

苯的分子式：C₆H₆

结构特点（重要）：苯不是单双键交替的结构， 而是6 个碳形成正六边形平面， 每个碳都是 sp² 杂化， 6 个碳各剩 1 个未杂化的 2p 电子，形成一个大 π 键。

证据：苯的 6 个碳碳键完全等同，键长介于单键和双键之间， 所以邻二溴苯只有一种（如果是单双键交替，应该有两种）。
苯的键长数据（说明问题）： C−C 单键：0.154 nm C=C 双键：0.133 nm 苯的碳碳键：0.140 nm ← 介于两者之间，且 6 个键完全相同

苯的化学性质

① 取代反应（主要反应，因为苯环比较稳定） 苯的溴代（需要催化剂 FeBr₃）： C₆H₆ + Br₂ --FeBr₃--> C₆H₅Br + HBr 苯的硝化（浓硫酸催化，50-60 ℃）： C₆H₆ + HNO₃ --浓H₂SO₄, 55℃--> C₆H₅NO₂ + H₂O 苯的磺化（浓硫酸，70-80 ℃）： C₆H₆ + H₂SO₄(浓) → C₆H₅SO₃H + H₂O ② 加成反应（较难发生，需要苛刻条件） 与 H₂ 加成（Ni 催化，加热）： C₆H₆ + 3H₂ --Ni, 加热--> C₆H₁₂（环己烷） ③ 燃烧——火焰明亮并带浓烟（含碳量高）
苯的取代反应容易搞混的几个条件：
·苯的溴代——用液溴（不是溴水！）+ FeBr₃ 作催化剂； 现象是液体呈红棕色，有白雾（HBr）。
苯不能使溴水褪色（它只发生萃取，使溴水层褪色但上层变橙红）， 这是和烯烃的重要区别。
·苯的硝化——用浓硝酸和浓硫酸的混合酸，水浴加热 55 ℃ 左右； 不能直接加热（温度过高会发生多取代，还可能发生爆炸）。
「苯不能使溴水褪色」是选择题常考的点。

苯的同系物

苯的同系物：苯环上的氢被烷基取代得到的产物。 通式：CₙH₂ₙ₋₆（n ≥ 6）

典型代表：甲苯 C₆H₅CH₃
甲苯的性质（重点）： ① 取代反应——取代苯环上的氢（需要催化剂，类似苯） 也可取代甲基上的氢（光照条件下）： C₆H₅CH₃ + Cl₂ --光照--> C₆H₅CH₂Cl + HCl （注意：光照取代侧链，催化取代苯环，条件不同产物不同） ② 能使酸性 KMnO₄ 溶液褪色（苯环上的烷基被氧化成 −COOH） → 这个反应用来区分苯和甲苯 苯不能使酸性 KMnO₄ 褪色，甲苯可以。 ③ 不能使溴水褪色（和苯一样） ④ 与 H₂ 加成（比苯容易些）
「甲苯能使酸性 KMnO₄ 褪色而苯不能」——这是区分它们的关键实验事实。
原因是甲苯的甲基受苯环影响变得活泼，容易被氧化。 这也是「苯环与侧链相互影响」的典型例子。

氧化后甲基变成羧基，所以甲苯被氧化得到苯甲酸 C₆H₅COOH。

另一个考点：苯的同系物中， 只有与苯环直接相连的碳上有氢的（即 α-C 上有 H）， 才能被酸性 KMnO₄ 氧化。所以叔丁基苯 C₆H₅C(CH₃)₃ 不能被氧化。
例 1

如何用化学方法鉴别苯、甲苯和己烯三种无色液体？简述实验步骤和现象。

解：要选两种试剂，分两步鉴别。

第一步，加溴水。

·己烯——与溴发生加成反应，溴水褪色（且不分层）；

·苯和甲苯——不与溴反应，但能萃取溴， 现象是上层（有机层）变橙红色，下层（水层）颜色变浅。

这样就能分出己烯，剩下两种待定。

第二步，加酸性 KMnO₄ 溶液（对剩下两种）。

·甲苯——甲基被氧化，紫色褪去；

·苯——不反应，紫色不褪。

答案：先用溴水区分出己烯，再用酸性 KMnO₄ 区分苯和甲苯。

为什么不能用溴的四氯化碳溶液： 那样苯和甲苯都能萃取而颜色不变，区分不出来。 关键是利用「水层」和「有机层」的分层现象。

本章的核心记忆点：
①通式：烷 CnH2n+2、烯 CnH2n、炔 CnH2n−2、苯 CnH2n−6；
②烯烃和炔烃都能使溴水、酸性 KMnO₄ 褪色，烷烃都不能；
③苯不能使溴水和酸性 KMnO₄ 褪色，但甲苯能使 KMnO₄ 褪色；
④苯的溴代要用液溴 + FeBr₃，不能用溴水；
⑤苯的 6 个碳碳键完全等同，这是「大 π 键」的证据。
