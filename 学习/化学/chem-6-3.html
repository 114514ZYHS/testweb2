第 3 章 烃的衍生物

人教版选择性必修第三册 · 3.1 – 3.5
「衍生物」的意思：烃分子里的氢被其他原子或原子团取代后得到的产物。

取代进来的是什么，就决定了它属于哪一类： 取代成 −X 是卤代烃，−OH 是醇或酚，−CHO 是醛， −COOH 是羧酸，−COO− 是酯。

所以本章的结构非常清楚：一类官能团 = 一节内容。

3.1 卤代烃

结构与性质

官能团：−X（卤素原子） 通式：R−X 物理性质：都不溶于水，可溶于有机溶剂 除少数（如氯甲烷）外，密度一般大于水
化学性质： ① 水解（取代）反应——在 NaOH 水溶液中 R−X + NaOH --水, 加热--> R−OH + NaX 本质是 −X 被 −OH 取代，生成醇 ② 消去反应——在 NaOH 醇溶液中加热 CH₃CH₂Br + NaOH --醇, 加热--> CH₂=CH₂↑ + NaBr + H₂O 本质是脱去 HX，生成碳碳双键 关键区别：NaOH 水溶液 → 水解；NaOH 醇溶液 → 消去
「水溶液还是醇溶液」是卤代烃最核心的考点。
·NaOH 水溶液——主要发生取代（水解），得到醇；
·NaOH 醇溶液——主要发生消去，得到烯烃。

不是所有卤代烃都能消去。
消去反应要求：与卤素相连的碳（α-C）的邻位碳（β-C）上必须有氢。
所以 CH₃Cl（只有一个碳）不能消去； CH₃C(CH₃)₂Br（β-C 上没有氢）也不能消去。
「邻碳有氢」才能消去——这是判断条件。

3.2 醇

结构与分类

官能团：−OH（羟基），连在链状碳上 按羟基数目分：一元醇（乙醇）、二元醇（乙二醇）、三元醇（丙三醇/甘油） 按与羟基相连的碳的类型分： 伯醇 —— 羟基连在「连有 2 个 H 的碳」上，如 CH₃CH₂OH 仲醇 —— 羟基连在「连有 1 个 H 的碳」上 叔醇 —— 羟基连在「不连 H 的碳」上

乙醇的化学性质

① 与金属钠反应（置换，断 O−H 键）： 2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑ 注意：反应比钠与水反应慢，说明乙醇的羟基氢不如水的活泼。 ② 催化氧化（断 O−H 和 α-C 上的 C−H）： 2CH₃CH₂OH + O₂ --Cu, 加热--> 2CH₃CHO + 2H₂O 生成乙醛。这就是「醇→醛」的转化。 ③ 与浓硫酸共热——条件不同产物不同（重点！）： 170 ℃ → 分子内脱水，生成乙烯（消去反应） CH₃CH₂OH --浓H₂SO₄, 170℃--> CH₂=CH₂↑ + H₂O 140 ℃ → 分子间脱水，生成乙醚（取代反应） 2CH₃CH₂OH --浓H₂SO₄, 140℃--> CH₃CH₂OCH₂CH₃ + H₂O ④ 酯化反应（与羧酸，断 O−H）： CH₃CH₂OH + CH₃COOH --浓H₂SO₄, 加热--> CH₃COOC₂H₅ + H₂O
「170 ℃ 和 140 ℃」这个温度区分是本章经典考点。
同一个反应物，温度不同得到完全不同的产物：
·170 ℃——分子内脱水 → 乙烯（消去）
·140 ℃——分子间脱水 → 乙醚（取代）

记忆方法：「高温内（分子内）、低温间（分子间）」。 或者记「17 要烯、14 要醚」。
醇的催化氧化的规律（重要）：
·伯醇（−CH₂OH）→ 氧化成醛（−CHO）
·仲醇（−CHOH−）→ 氧化成酮（−CO−）
·叔醇（−COH，α-C 上没有氢）→ 不能被催化氧化

原因：催化氧化需要脱去 α-C 上的氢， 叔醇的 α-C 上没有氢，所以不能氧化。
「有没有 α-H」决定了能不能氧化，也决定了氧化成醛还是酮。

醇的两个重要反应类型总结

断键位置决定了产物类型： 断 O−H 键 → 与 Na 反应放 H₂；与羧酸酯化 断 C−O 键 → 与 HX 取代生成卤代烃；与浓硫酸 140℃ 分子间脱水 断 O−H + α-C 的 C−H → 催化氧化成醛/酮 断 O−H + β-C 的 C−H → 消去生成烯烃（170℃）
「断哪个键」是有机化学推断题的核心思路。
拿到一道有机反应题，先想「反应发生在哪个位置」， 再想「断的是哪根键」，产物自然就出来了。

这也是为什么浓硫酸的作用要看清： 酯化和 140 ℃ 脱水时它做催化剂和吸水剂； 170 ℃ 消去时它是催化剂和脱水剂。

3.3 酚

苯酚的性质

结构：C₆H₅OH，羟基直接连在苯环上 ① 弱酸性（比碳酸还弱）： C₆H₅OH + NaOH → C₆H₅ONa + H₂O （能反应，说明有酸性） 但：C₆H₅ONa + CO₂ + H₂O → C₆H₅OH + NaHCO₃ （通入 CO₂ 又变回苯酚，说明酸性比碳酸弱） ② 显色反应——遇 FeCl₃ 溶液显紫色 这是鉴别苯酚的特征反应！ ③ 苯环上的取代（比苯容易，可在邻、对位发生） 与溴水反应生成 2,4,6-三溴苯酚白色沉淀 C₆H₅OH + 3Br₂ → C₆H₂Br₃OH↓ + 3HBr 注意：这里用溴水就够了（比苯的溴代容易得多）
苯酚的三个「特殊」要记住：
①显弱酸性——但酸性比碳酸弱。 所以「苯酚钠 + CO₂ → 苯酚 + NaHCO₃」能发生， 这说明苯酚酸性 < 碳酸。 这个比较是常考的；
②遇 FeCl₃ 显紫色——苯酚的专属鉴别反应 （其他酚类也有类似现象，但苯酚最典型）；
③苯环上的取代极其容易——不需要催化剂， 用溴水就能生成三溴苯酚沉淀。 这体现了「羟基对苯环的活化作用」。

3.4 醛

结构与性质

官能团：−CHO（醛基） 典型代表：乙醛 CH₃CHO 醛的两个特征反应（重点）： ① 银镜反应（与银氨溶液） CH₃CHO + 2Ag(NH₃)₂OH --水浴加热--> CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O 现象：试管内壁出现光亮的银镜 ② 与新制 Cu(OH)₂ 反应 CH₃CHO + 2Cu(OH)₂ --加热--> CH₃COOH + Cu₂O↓ + 2H₂O 现象：出现砖红色沉淀（Cu₂O）
两个反应的操作细节（实验题常考）：
银镜反应：
·必须用水浴加热（温度均匀，不能直接加热，否则银镜不均匀）；
·试管要洁净（否则挂不上银）；
·不能振荡；
·银氨溶液要现配现用（放置久了会生成爆炸性物质）。

与新制 Cu(OH)₂ 反应：
·Cu(OH)₂ 要新制（在 NaOH 溶液中滴加少量 CuSO₄）；
·NaOH 必须过量（保证溶液呈碱性）；
·要直接加热煮沸（不是水浴）。

这两个反应都用来检验醛基，是醛的专属反应。
能发生银镜反应 = 含有醛基（−CHO）
这是判断题的常用依据。注意甲酸（HCOOH）和甲酸酯也含醛基结构， 也能发生银镜反应。

检验顺序：如果不确定是「醛」还是「酮」， 用银镜反应或新制 Cu(OH)₂ 检验即可区分—— 醛能反应，酮不能。

3.5 羧酸与酯

羧酸

官能团：−COOH（羧基） 酸性：羧酸 > 碳酸 > 苯酚 （所以羧酸能与 NaHCO₃ 反应放出 CO₂， 而苯酚不能！这是区分羧酸和苯酚的关键） 酯化反应（与醇，需要浓硫酸催化并吸水）： CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O 同位素标记的关键结论： 用 ¹⁸O 标记乙醇（C₂H₅¹⁸OH）做这个反应， 标记出现在酯中，不在水中。 说明：酸脱羟基，醇脱氢。
「酸脱羟基、醇脱氢」这句话解释了酯化反应的断键方式：
CH₃COOH 断掉 −OH，C₂H₅OH 断掉 −H， 所以水中的氧全部来自羧酸，酯中的氧来自醇。

这是用同位素示踪法证明的，是化学史上经典的实验设计， 也是常考的推理题素材。

酯化反应的特点：可逆反应（用 ⇌ 表示）， 所以要不断移走产物或用过量的某一种反应物来提高产率。

酯

官能团：−COO−（酯基） 水解反应——酯的典型反应，分两种情况： ① 酸性水解（稀硫酸催化，可逆）： CH₃COOC₂H₅ + H₂O ⇌ CH₃COOH + C₂H₅OH 得到羧酸和醇 ② 碱性水解（皂化反应）（NaOH，不可逆，进行到底）： CH₃COOC₂H₅ + NaOH → CH₃COONa + C₂H₅OH 得到羧酸钠和醇 为什么碱性水解更彻底：生成的羧酸被 NaOH 中和， 浓度降低，平衡一直向右移动。
酯的鉴别与检验：
·气味——低级酯有芳香气味（水果香）；
·不溶于水，密度比水小，浮在水面；
·水解产物可以进一步检验： 检测水解后是否有羧酸生成，或是否有醇生成。

一个常见考点：酯水解后的产物中， 如果含有醛基结构（如甲酸酯 HCOOR）， 那这个酯也能发生银镜反应。
例 1

某有机物 A 的分子式为 C₂H₄O₂。它能与 NaHCO₃ 溶液反应放出 CO₂ 气体， 也能与乙醇发生酯化反应。推断 A 的结构并写出相关反应。

解：

第一步，由「能与 NaHCO₃ 放 CO₂」判断官能团。

能与 NaHCO₃ 反应说明酸性比碳酸强， 所以含有 −COOH（羧基）。（苯酚不能，这是个关键区分点）

第二步，确定结构。

C₂H₄O₂ 含 1 个 −COOH（占 C₁H₁O₂）， 剩下 C₁H₃ ——即甲基。

所以 A 是 乙酸 CH₃COOH。

第三步，写反应。

与 NaHCO₃：

CH₃COOH + NaHCO₃ → CH₃COONa + H₂O + CO₂↑

与乙醇酯化：

CH₃COOH + C₂H₅OH --浓H₂SO₄, 加热--> CH₃COOC₂H₅ + H₂O

答案：A 为 乙酸 CH₃COOH。

3.6 有机反应类型总结

取代反应： 烷烃卤代、苯环卤代/硝化/磺化、卤代烃水解、醇分子间脱水、 酯化、酯的水解 加成反应： 烯烃/炔烃与卤素、H₂、HX、H₂O 加成 苯环与 H₂ 加成 消去反应： 卤代烃在醇溶液中脱 HX 醇在浓硫酸中 170 ℃ 分子内脱水 氧化反应： 燃烧、烯烃/炔烃使酸性 KMnO₄ 褪色、 醇的催化氧化、醛的银镜反应和与新制 Cu(OH)₂ 反应 还原反应： 与 H₂ 加成（烯烃、炔烃、苯环、醛、酮） 聚合反应： 加聚（烯烃、炔烃、含 C=C 的化合物） 缩聚（含两个官能团的单体，如生成聚酯、聚酰胺）
本章的核心记忆点：
①卤代烃：水溶液水解、醇溶液消去；消去要求邻碳有氢；
②乙醇：170 ℃ 生成乙烯、140 ℃ 生成乙醚；
③醇的氧化：伯醇→醛、仲醇→酮、叔醇不反应；
④苯酚：遇 FeCl₃ 显紫色、酸性比碳酸弱；
⑤醛：银镜反应、新制 Cu(OH)₂ 砖红色沉淀；
⑥酯化：酸脱羟基醇脱氢（¹⁸O 示踪证明）；
⑦酸性排序：羧酸 > 碳酸 > 苯酚。
