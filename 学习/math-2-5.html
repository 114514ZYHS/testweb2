第 5 章 一元函数的导数及其应用

人教 A 版选择性必修第二册 · 5.1 – 5.3
先建立直觉：导数干的事情，用一句话说就是——研究一个量「瞬时」的变化快慢。

初中一次函数 y = kx + b 的变化率是恒定的，就是 k。但现实里大部分变化不是匀速的： 车在加速、股价在波动、细菌繁殖会越来越快。导数就是用来描述「某一瞬间变化有多快」的工具。

5.1 导数的概念及其意义

5.1.1 从平均变化率到瞬时变化率

先看一段区间上的平均变化。

平均变化率：函数 f(x) 从 x₁ 到 x₂ 的平均变化率为 Δy / Δx = [f(x₂) − f(x₁)] / (x₂ − x₁) 它的几何意义是：函数图像上两点连线（割线）的斜率。

但「平均」不够用。比如一段路 100 公里开了 2 小时，平均速度 50 km/h，可你中途可能飙到 120，也可能停着不动。平均速度没法描述某一刻的真实速度。

解决办法是：让 x₂ 不断逼近 x₁。

瞬时变化率（导数）：当 Δx 无限趋近于 0 时，如果 Δy/Δx 无限趋近于某个确定的值， 就称这个值为函数 f(x) 在 x = x₀ 处的导数，记作 f′(x₀) = lim(Δx→0) [f(x₀ + Δx) − f(x₀)] / Δx
几何意义（必须记住）：f′(x₀) 是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

割线 → 切线 的过程，就是「两点 → 逼近到一点」的过程。 导数 = 切线斜率 = 瞬时变化率，这三句话说的是同一件事。

5.1.2 导数的几何意义与切线方程

求曲线在某点处的切线方程，标准两步：

  1. 求导得 f′(x)，代入 x₀ 得斜率 k = f′(x₀)；
  2. 用点斜式写出：y − f(x₀) = f′(x₀)(x − x₀)。
例 1

求曲线 f(x) = x² 在点 (1, 1) 处的切线方程。

解：先求 f′(1)。

f′(1) = lim(Δx→0) [(1+Δx)² − 1²] / Δx = lim(Δx→0) (2Δx + Δx²) / Δx = lim(Δx→0) (2 + Δx) = 2

所以切线斜率 k = 2，切点为 (1, 1)。

切线方程：y − 1 = 2(x − 1)，即 y = 2x − 1。

一个高频易错题：「求过点 P 的切线」和「求在点 P 处的切线」是两回事。
「在点 P 处」——P 就是切点，直接用 P 的横坐标求斜率。
「过点 P」——P 只保证在切线上，不一定是切点，要设切点坐标 (t, f(t)) 去解方程。

导函数

如果 f(x) 在区间上每一点都可导，那么每个 x 都对应一个导数值 f′(x)，这样就得到了一个新函数，叫导函数（通常简称导数），记作 f′(x) 或 y′。

5.2 导数的运算

特别记住这两个「自己等于自己导数」的：e^x 的导数还是 e^x； ln x 的导数是 1/x。这两个在后面的题目里出现频率极高。

运算法则

和差： [f(x) ± g(x)]′ = f′(x) ± g′(x)

常数倍： [k·f(x)]′ = k·f′(x)

乘法： [f(x)·g(x)]′ = f′(x)g(x) + f(x)g′(x)

除法： [f(x)/g(x)]′ = [f′(x)g(x) − f(x)g′(x)] / [g(x)]²
最常见的错误：乘法法则不是「导数乘导数」！
(f·g)′ ≠ f′·g′，这一点和加减法完全不一样，很多人在这里丢分。
例 2

求下列函数的导数：

（1）f(x) = x³ + 2x² − 5x + 3

解：逐项求导。f′(x) = 3x² + 4x − 5

（2）g(x) = x·e^x

解：用乘法法则。g′(x) = 1·e^x + x·e^x = (1 + x)e^x

（3）h(x) = ln x / x

解：用除法法则。h′(x) = [(1/x)·x − ln x·1] / x² = (1 − ln x) / x²

答案：3x² + 4x − 5；(1+x)e^x；(1 − ln x)/x²

5.3 导数在研究函数中的应用

5.3.1 单调性

定理：在区间 (a, b) 内，
如果 f′(x) > 0，那么 f(x) 在这个区间上单调递增；
如果 f′(x) < 0，那么 f(x) 在这个区间上单调递减。

怎么理解：导数就是切线斜率。斜率为正，曲线在往上走；斜率为负，曲线在往下走。就这么直白。

求单调区间的标准步骤：

  1. 确定定义域（这一步最容易被漏掉）；
  2. 求 f′(x)；
  3. 令 f′(x) = 0，求出根；
  4. 用这些根把定义域分成若干区间；
  5. 在每个区间上判断 f′(x) 的符号；
  6. 写出单调区间。
例 3

求函数 f(x) = x³ − 3x 的单调区间。

解：定义域为 R。

f′(x) = 3x² − 3 = 3(x − 1)(x + 1)

令 f′(x) = 0，得 x = 1 或 x = −1。

这两个根把 R 分成三段：

  • (−∞, −1)：取 x = −2，f′(−2) = 3·4 − 3 = 9 > 0，递增
  • (−1, 1)：取 x = 0，f′(0) = −3 < 0，递减
  • (1, +∞)：取 x = 2，f′(2) = 9 > 0，递增

所以递增区间为 (−∞, −1) 和 (1, +∞)，递减区间为 (−1, 1)。

注意：这里用「和」连接，不能用并集符号「∪」。因为函数在两个区间上是分开递增的，不能合并成一个区间。

5.3.2 极值与最值

极小值：如果 f′(x₀) = 0，且在 x₀ 左侧 f′(x) < 0、右侧 f′(x) > 0， 那么 f(x₀) 是极小值（左降右升，是个「谷底」）。

极大值：如果在 x₀ 左侧 f′(x) > 0、右侧 f′(x) < 0， 那么 f(x₀) 是极大值（左升右降，是个「山顶」）。
必须分清「极值」和「最值」：
极值是局部概念——只在某个小范围里比周围大或小。
最值是整体概念——在整个区间上最大或最小。

一个函数可以有多个极大值，但最大值只有一个。 极大值不一定是最大值，这是常考的陷阱。

求闭区间 [a, b] 上最值的方法：

  1. 求 f′(x)，令 f′(x) = 0 求出所有根；
  2. 把落在 [a, b] 内的根代回求函数值；
  3. 再把两个端点 a、b 的函数值也求出来；
  4. 所有这些值里，最大的就是最大值，最小的就是最小值。

关键：端点的值必须算，很容易漏。

例 4

求函数 f(x) = x³ − 3x 在区间 [0, 3] 上的最大值和最小值。

解：由例 3 已知 f′(x) = 3(x − 1)(x + 1)，令 f′(x) = 0 得 x = 1 或 x = −1。

在区间 [0, 3] 内的只有 x = 1（−1 不在区间内，舍去）。

计算各点函数值：

  • f(0) = 0 − 0 = 0
  • f(1) = 1 − 3 = −2
  • f(3) = 27 − 9 = 18

比较这三个值：最大是 18，最小是 −2。

答：最大值为 f(3) = 18，最小值为 f(1) = −2。

体会一下：这里 x = 1 是极小值点，恰好也是最小值点；但最大值出现在端点 x = 3，而不是任何极值点。 这就是为什么端点必须算。

5.3.3 由单调性反求参数

这是高考解答题的常见考法：已知 f(x) 在某区间上单调，求参数范围。

思路：把「单调递增」翻译成 f′(x) ≥ 0 在该区间恒成立， 然后转化为求最值或分离参数的问题。
例 5

已知 f(x) = x³ − ax 在 [1, +∞) 上单调递增，求 a 的取值范围。

解：f′(x) = 3x² − a。

由题设，需在 [1, +∞) 上恒有 f′(x) ≥ 0，即

3x² − a ≥ 0 对一切 x ≥ 1 恒成立。

分离参数：a ≤ 3x² 对一切 x ≥ 1 恒成立。

也就是说，a 要小于等于 3x² 在 x ≥ 1 上的最小值。

函数 3x² 在 [1, +∞) 上单调递增，所以最小值在 x = 1 处取得，为 3×1² = 3。

所以 a ≤ 3，即 a 的取值范围是 (−∞, 3]。

注意等号：题目说的是「单调递增」（不是「严格递增」），所以允许 f′(x) = 0 在个别点成立，因此取 ≤ 而不是 <。

本章知识结构

把这一章的逻辑串起来看：

  • 平均变化率（割线斜率）→ 让 Δx 趋近于 0 → 瞬时变化率（切线斜率）= 导数
  • 导数是一个函数，可以计算，有公式和法则
  • 导数的符号决定原函数的增减（正增负减）
  • 导数为 0 的变号点，往往是极值点
  • 结合端点，就能求最值
  • 反过来，知道单调性也能反推参数
学这一章最容易踩的五个坑：
① 求导前忘了先写定义域
② 把 (f·g)′ 当成 f′·g′
③ 单调区间用并集符号连接
④ 求最值时漏算端点
⑤ 混淆「极值」和「最值」
