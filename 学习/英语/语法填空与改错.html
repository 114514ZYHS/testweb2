语法填空与短文改错

有提示词 / 无提示词 · 改错的十个考点

这两个题型都属于「规则题」—— 它们的考点是有限的、可穷举的。 只要把「什么位置考什么」总结清楚， 正确率可以稳定在 80% 以上。

它们的共同逻辑是：先判断「考什么」，再决定「怎么填」。
一、语法填空：解题总框架

第一步：判断是「有提示词」还是「无提示词」

这一步极其关键，因为两类空格的考点完全不同。

有提示词
考点在「词形变化」上。
涉及：动词的时态 / 语态 / 非谓语、 名词单复数、形容词副词比较级、 词性转换（派生）。
无提示词
考点在「虚词」上。
主要是：冠词、介词、连词、代词、 关系词、情态动词。
二、有提示词的四种情况

情况一：提示词是动词

这是出现频率最高的一类，判断流程如下：

第一步，看这个动词在句中是不是谓语。

如果句中已经有谓语，那这个动词就是非谓语—— 要用 to do / doing / done。

如果句中还没有谓语，那它就要做谓语—— 要考虑时态和语态。

第二步（若是谓语），定时态。 看句中或上下文的时间标志词。

第三步（若是谓语），定语态。 看主语是动作的发出者还是承受者。

第四步（若有多个谓语），用并列或从属关系判断。

判断「是不是谓语」有个快捷方法： 看这个空所在的句子，有没有其他的谓语动词。
比如：He ______ (read) a book when I came in. ——句中有 came 这个谓语， 但这个空所在的主句本身还没有谓语， 所以这里要填谓语（was reading）。

而 ______ (read) a book, he didn't hear me. ——句中已经有谓语 didn't hear， 所以这里填非谓语（Reading）。

情况二：提示词是名词

主要考单复数和所有格。

判断依据： 前面有 many, few, several, two, three 等 → 复数； 前面有 a, an, one, each, every → 单数。

还有一些固定用法： one of the + 复数名词、 a variety of + 复数名词。

情况三：提示词是形容词或副词

三种可能：比较级 / 最高级 / 词性转换。

句中有 than， 或前面有 much, far, even, a lot → 比较级。

前面有 the，且句意表示「最……」→ 最高级。

该词在句中作主语、宾语或需要修饰名词 → 可能要换成名词形式。

情况四：需要词性转换

这类题的判断方法是「看它在句中充当什么成分」：

作主语或宾语 → 用名词；

作定语修饰名词，或作表语 → 用形容词；

修饰动词、形容词或整句 → 用副词。

常见的前后缀要熟悉：

名词后缀：-tion, -sion, -ment, -ness, -ity, -ance, -ence, -er, -or, -ist, -ism

形容词后缀：-ful, -less, -ous, -ive, -able, -ible, -al, -ic, -ish, -y

副词后缀：-ly

否定前缀：un-, in-, im-, il-, ir-, dis-, non-, mis-

几个容易混的后缀：
-ful（充满……的，如 useful）vs -less（没有……的，如 useless）；
-able（能……的，被动意味）vs -ive（有……性质的，主动意味）。

另外注意：-ly 结尾的词不一定是副词。 friendly, lovely, lonely, likely, daily, weekly 都是形容词。
三、无提示词的三种情况

情况一：填冠词

空格后面是名词，且这个名词是泛指的单数可数名词 → 填 a / an。

空格后面是名词，且是特指 → 填 the。

名词前已有 this, my, some 等限定词 → 不填。

情况二：填介词

这主要靠固定搭配的积累。常见的判断依据有：

名词前 → 考虑 in, on, at, of, for, with。

动词后 → 看该动词的固定搭配 （depend on, result in, result from, be used to）。

形容词后 → 看搭配 （good at, interested in, proud of, afraid of, ready for）。

情况三：填连词 / 关系词 / 代词

这一步要判断前后两句是什么关系：

并列关系 → and

转折关系 → but, yet, however

因果关系 → so, for, therefore

选择关系 → or

如果空格引导的是从句，还要判断从句类型：

修饰名词 → 定语从句，用关系词；

作主语/宾语/表语/同位语 → 名词性从句， 用 that / what / whether / who / how 等；

作状语 → 状语从句， 用 when / because / although / if 等。

无提示词空格的一个实用判断顺序：
第一步看空格后面是不是名词 → 是，考虑冠词或介词；
第二步看空格前后是不是两个句子 → 是，考虑连词或关系词；
第三步看句子是否缺主语或宾语 → 是，考虑代词。

按这个顺序排除，大部分空格都能定位。
例 1

语法填空：

The old man, ______ (wear) a pair of glasses, sat by the window ______ (read) a newspaper.

答案：wearing；reading

第一个空（wearing）：

句子的谓语是 sat， 所以 wear 必须是非谓语。

逻辑主语是 the old man， 他是「戴眼镜」这个动作的发出者（主动）， 且「戴眼镜」与「坐」是同时的状态， 所以用现在分词 wearing。

第二个空（reading）：

同样，谓语已经是 sat， 所以这里是非谓语。

逻辑主语还是 the old man， 他是「读报纸」的发出者（主动）， 且「读报纸」是伴随「坐」发生的动作， 所以用现在分词 reading。

要点：这两个空都是主动 + 同时， 所以都用 doing。 如果题目改成「the old man, ______ (wear) glasses by his grandson)」， 那就是被动，要用 worn。

例 2

语法填空：

______ is known to all, the earth moves around the sun.

答案：As

分析：

第一步：空格后是一个完整的句子 （the earth moves around the sun）， 且空格与这个句子一起构成了整个句子的前置部分。

第二步：is known to all 缺主语，所以需要填一个能作主语的词。

第三步：这是非限制性定语从句， as 指代后面整个主句的内容， 表示「正如」。

所以填 As （首字母大写，因为是句首）。

为什么不是 It 或 That？ It is known to all 也可以成立， 但那样后面就需要 that 引导一句话， 而题目中只有一个空，且空格前没有任何词—— 所以只能用 As 引导非限制性定语从句。

四、短文改错

十个考点（按出现频率排序）

1. 动词的时态与语态
时态不一致、主动被动用错。 这是最高频的一类。
2. 名词的单复数
该用复数用了单数，或反之。 注意 information 这类不可数名词。
3. 冠词
该加没加、该删没删、a / an / the 用错。
4. 主谓一致
主语是单数但谓语用了复数形式。
5. 介词
固定搭配中的介词用错、多余的介词、缺失的介词。
6. 代词
指代不一致（性别、单复数）、 人称代词与物主代词混用、反身代词用错。
7. 形容词与副词
该用副词用了形容词（修饰动词时）、 比较级用错。
8. 连词
逻辑关系错误（该转折用了并列）、 because 与 so 连用。
9. 非谓语动词
to do / doing / done 用错。
10. 词语搭配与拼写
固定搭配用错、拼写错误。

改错的四个操作要求

其一，改动要最小化。 每题只能改一处，且通常只改一个词。 不要重写整句。

其二，符号要写对。 增词用「∧」，删词用「\」，改词用「—」划掉再写新的。

其三，不能改人名、地名。

其四，行行有错，但每行只错一处。 这个规律能帮助定位—— 如果某一行你觉得没问题， 那说明你可能漏看了（或者这一行确实是对的）。

统计规律：短文改错的错误分布大致是 「增 1 个、删 1 个、改 8 个」—— 也就是说，绝大多数是「改词」， 只有一两个是「增词」或「删词」。

这个规律能帮你判断：如果某一行你判断需要「删掉一个词」， 但那已经是你删的第三个词了， 就要回头重新检查——很可能判断错了。

做题顺序

第一步，通读全文，把握大意和时态基调。

第二步，逐行检查。 按「动词 → 名词 → 冠词 → 代词 → 介词 → 连词 → 形容词副词 → 非谓语」的顺序扫一遍。

第三步，复查。 看改动是否落在上面列出的十个考点范围内—— 如果某个改动不属于这十类，很可能改错了。

例 3

改错：I am looking forward to hear from you soon.

答案：hear → hearing

病因：look forward to 中的 to 是介词， 后面要接动名词，不能接动词原形。

属于哪个考点：属于第 9 类「非谓语动词」， 准确说是「介词 + doing」这一条。

补充：属于同一类的短语还有 be used to（习惯于）, devote oneself to, object to, stick to, be accustomed to, get down to。 这些都是「to + doing」， 但 be used to do （被用来做）里的 to 是不定式符号，接动词原形—— 这两个必须区分清楚。

五、两个题型的共同点

其一，都考「基础规则」。 不会出偏难怪题，所以基础扎实就能拿高分。

其二，都可以通过「总结清单」提高。 做完题把错点按十个考点归类， 积累一段时间后就能发现自己的薄弱点。

其三，都要「先判断类型」。 语法填空要先判断有没有提示词， 改错要先判断属于哪个考点。 「归类」是这两类题的核心动作。

其四，都要复查。 语法填空填完后要把整句读一遍， 改错改完后要复查是否每行只错一处。

最后一条建议：这两个题型是「投入产出比」最高的。 它们不像阅读那样依赖语感， 也不像写作那样依赖积累， 只要把规则记牢就能稳定得分。 如果英语成绩想快速提升，从这两个题型入手最实际。
