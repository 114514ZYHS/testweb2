虚拟语气 · 情态动词 · 特殊结构

虚拟 · 情态 · 主谓一致 · 倒装 · 强调 · 独立成分

这一页收拢语法体系里剩下的几个专题。 它们的特点是规则成块、边界清晰—— 只要把表格记住，几乎不会错。

不过这几个点都属于「考到就是送分，记不牢就是丢分」的类型， 建议按表格逐条过。
一、虚拟语气

if 条件句的三种虚拟

与现在事实相反：

从句：did（be 用 were）　主句：would / could / might / should + do

If I were you, I would accept it.

与过去事实相反：

从句：had done　主句：would / could / might / should + have done

If he had studied harder, he would have passed the exam.

与将来事实相反：

从句：did / were to do / should do　主句：would / could / might / should + do

If it should rain tomorrow, the sports meeting would be put off.

记忆口诀：「现在过去都往前推一格」——
与现在相反 → 从句用过去式； 与过去相反 → 从句用过去完成式； 与将来相反 → 从句用过去式或 were to / should。

主句永远是「would / could / might / should + 动词原形」， 只有与过去相反时才加 have done。

特别注意：虚拟语气的从句中， be 动词一律用 were （包括 If I were you）， 不用 was。

混合虚拟

当从句与主句所指的时间不同时，各自按各自的时间处理。

If you had followed my advice (过去), you would be better now (现在).

从句是与过去相反（用 had done）， 主句是与现在相反（用 would do）。 这种「一句两时间」的题是高考的高频考点。

省略 if 的倒装

当从句中有 had / were / should 时， 可以省略 if，把这三个词提到主语之前。

If he had come → Had he come

If I were you → Were I you

If it should rain → Should it rain

倒装的三个信号词就是 had / were / should—— 只有这三个能用这种倒装。 不能写 Did he come 或 Was I you 之外的错误形式。

另外，倒装后不能再加 if， If had he come 是双重错误。

wish 后的虚拟

wish 后面的宾语从句要用虚拟语气：

与现在相反——用一般过去时： I wish I were younger.

与过去相反——用过去完成时： I wish I had studied harder.

与将来相反——用 would / could + do： I wish it would stop raining.

其他常用虚拟结构

would rather 后—— 接过去式表示现在或将来，接过去完成式表示过去。

as if / as though 后—— 与 wish 的规则相同。 但如果是很可能发生的事，也可以用陈述语气。

It's (high) time 后—— 用过去式或 should + do。

It's high time that we left / should leave.

suggest / advise / propose / recommend / demand / require / request / insist / order / command 等表示「建议、要求、命令」的动词后—— 从句用 (should) + do，should 可省略。

He suggested that we (should) start at once.
重要陷阱：suggest 作「暗示、表明」讲时， insist 作「坚持说」讲时， 后面的从句不用虚拟语气，用陈述语气。

对比：
He suggested that we should go early. （建议 → 虚拟）
His pale face suggested that he was ill. （表明 → 陈述）

虚拟语气在从句中的应用

主语从句——It is important / necessary / essential / strange / natural that ... (should) do

表语从句 / 同位语从句——跟在 suggestion, advice, proposal, order, request, requirement, idea 等名词后， 从句用 (should) + do。

His suggestion is that we (should) set off early.

二、情态动词

基本情态动词的含义

can / could
能力、许可、可能性。
could 语气更委婉， 也表示过去的能力。
may / might
许可、推测（可能性比 can 小）。
may 可以表示祝愿： May you succeed!
must
必须（主观）、一定（肯定推测）。
否定时用 needn't 或 don't have to， 不是 mustn't （那是「禁止」）。
shall
用于第一人称表将来； 用于第二、三人称表命令、警告、承诺。
should
应该。
也用于「竟然」表示意外： It's strange that he should say so.
will / would
意志、习惯（would 表过去习惯）。
need
需要。既可作情态动词也可作实义动词。
情态：Need I go?
实义：Do I need to go?
dare
敢。同样两用。
情态：Dare he go?
实义：Does he dare to go?

must 表推测的三种强度

must——「一定」（可能性最大， 只用于肯定句）。

can——「可能」（多用于疑问句和否定句）。

may / might——「也许」（可能性较低）。

不能用于肯定推测的是 can， 不能说 He can be at home. （表示「他可能在家」时应用 may / might）。 但在疑问句中只能用 can： Can he be at home?

否定推测中： can't 表示「不可能」（语气很强）， may not 表示「可能不」。

情态动词 + have done（对过去的推测）

must have done—— 「一定做过」（对过去的肯定推测）。

can't / couldn't have done—— 「不可能做过」（对过去的否定推测）。

may / might have done—— 「也许做过」。

should / ought to have done—— 「本该做而没做」（含责备）。

shouldn't have done—— 「本不该做却做了」。

needn't have done—— 「本不必做却做了」。

could have done—— 「本来能够做（却没做）」。

needn't have done 与 didn't need to do 的区别：
needn't have done——做了但没必要；
didn't need to do——没做，因为没必要。

举例：
You needn't have bought it. （你买了，但没必要买）
You didn't need to buy it. （你没买，因为不需要买）
三、主谓一致

三条基本原则

语法一致——主语是单数，谓语用单数；主语是复数，谓语用复数。

意义一致——谓语取决于主语的实际意义， 不一定看形式（如 The family are having dinner. （强调家庭成员）vs The family is large.（作为一个整体））。

就近一致——谓语与最近的那个主语保持一致。

常见规则

其一，each, every, either, neither, one, nobody, anybody, everybody, somebody, nothing, anything 作主语时，谓语用单数。

其二，both, few, several, many 作主语时用复数。

其三，either...or, neither...nor, not only...but also, there be 用就近一致。

其四，with, together with, along with, as well as, besides, including 连接的成分 不影响主语数——谓语仍与前面的主语一致。

The teacher, together with his students, is going to the museum.

其五，不定式、动名词、主语从句作主语时，谓语用单数。

其六，时间、距离、金钱、重量等作为整体时，谓语用单数。

Ten years is a long time.

其七，the number of（……的数量） 用单数；a number of（许多） 用复数。

the number of 与 a number of 是超高频考点：
The number of students is 500. （学生的数量是 500）
A number of students are here. （许多学生在这里）

记忆方法：the number 的中心词是 number（单数）； a number of 相当于 many，修饰复数名词。
四、倒装

部分倒装（助动词提前）

其一，否定词位于句首。 never, seldom, hardly, rarely, scarcely, little, nowhere, not only, not until, no sooner, in no way, under no circumstances。

Never have I seen such a beautiful view.

Not only did he read the book, but he also remembered what he had read.

其二，only 修饰状语位于句首。

Only then did I realize my mistake.

注意：only 修饰主语时不倒装。 Only he knows the answer.（不倒装）

其三，so / neither / nor 表示「也一样」。

He likes music. So do I.

She can't swim. Neither can I.

其四，虚拟条件句省略 if。（见前面虚拟语气一节）

其五，as / though 引导让步状语从句。（见状语从句一节）

完全倒装（谓语整体提前）

其一，here / there / now / then / up / down / in / out 等副词位于句首，且主语是名词。

Here comes the bus.

但如果主语是代词，则不倒装： Here it comes.

其二，表示地点的介词短语位于句首。

On the wall hangs a picture.

其三，表语位于句首。

Gone are the days when we were young.

倒装题的判断顺序：
第一步，看句首是不是否定词或 only、so—— 是，则部分倒装；
第二步，看句首是不是方位副词或地点短语—— 是，且主语是名词，则完全倒装；
第三步，检查主语是代词时是否误用了倒装—— 这是最常见的失分点。
五、强调句

基本形式

It is / was + 被强调部分 + that / who + 其余部分

I met him in the park yesterday.

强调主语：It was I that / who met him in the park yesterday.

强调宾语：It was him that I met in the park yesterday.

强调地点：It was in the park that I met him yesterday.

强调时间：It was yesterday that I met him in the park.

如何区分强调句与定语从句

把 It is / was 和 that / who 去掉， 如果剩下的部分仍然是一个完整、通顺的句子， 那就是强调句。

It was in the park that I met him. → 去掉后：In the park I met him. （完整，是强调句）

It is a park that is famous. → 去掉后：A park is famous. （虽然也算完整，但 a park 是被修饰的名词，这里是定语从句）

更可靠的区分方法：看 that 在从句中作不作成分。
强调句——that 不作成分（可视为连接词）；
定语从句——that 作主语或宾语。

另外，强调句不能强调谓语动词。 要强调谓语，用助动词 do / does / did： I do like it.

强调句的特殊形式

强调句的一般疑问句： Was it yesterday that you met him?

强调句的特殊疑问句： Who was it that you met?

not...until 的强调句：

It was not until ... that ...

It was not until he came back that I went to bed.

六、独立成分与插入语

常见的独立成分

副词类：however, therefore, besides, moreover, otherwise, meanwhile

短语类：in fact, in other words, in general, on the contrary, as a result, to be honest, to tell you the truth

不定式短语：to begin with, to sum up, so to speak

分词短语：generally speaking, strictly speaking, judging from

介词短语：besides, apart from, except for

这些独立成分的语法特点是：它们与句子的其他部分没有语法关系， 删除后句子依然完整。

在完形填空和语法填空中，这类词常常是「线索词」—— 看到 however 就知道前后是转折关系， 看到 therefore 就知道前后是因果关系。 留意它们能显著提高做题的准确率。
七、易错点速查

其一，虚拟语气中 be 动词一律用 were。

其二，混合虚拟要分开看从句和主句的时间。

其三，省略 if 的倒装只用 had / were / should 三个词。

其四，suggest 表「暗示」、 insist 表「坚持说」时不用虚拟。

其五，must 的否定回答用 needn't，不是 mustn't。

其六，needn't have done（做了但没必要） 与 didn't need to do（没做，因为没必要）要分清。

其七，the number of 用单数， a number of 用复数。

其八，倒装时主语是代词则完全倒装不成立。

其九，强调句的判断靠「去掉 It is / that 后句子是否完整」。
