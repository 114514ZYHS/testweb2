必修三 电与磁

人教版必修第三册 · 广西高考
必修三把「电」和「磁」这两件事串起来： 电可以生磁，磁也可以生电。这一册是电磁学的入门， 后面的选择性必修二会在此基础上深入。

学这一册的关键是把电场和重力场类比着理解—— 很多概念（场强、电势、势能）结构是一样的， 类比过来能省不少力气。

一、静电场

电荷与库仑定律

电荷守恒：电荷既不能创造也不能消灭，只能转移。 元电荷：e = 1.6×10⁻¹⁹ C（最小电荷量） 库仑定律：F = k·q₁q₂ / r² （k = 9.0×10⁹ N·m²/C²，适用于真空中的点电荷）
库仑定律的适用条件必须记住：
①真空中；②点电荷（带电体间的距离远大于自身大小）。
两个靠得很近的带电球体不能直接用这个公式。

电场强度

定义式：E = F / q （对任何电场都适用） 点电荷场强：E = kQ / r² （只适用于点电荷产生的电场） 匀强电场：E = U / d （d 是沿电场方向的距离）
E = F/q 和 E = kQ/r² 的区别（常考）：
E = F/q 是定义式——用试探电荷去「测」场强， 它反映的是电场本身的性质，与试探电荷无关。
E = kQ/r² 是决定式——只对点电荷的场成立， 它说明场强由场源电荷 Q 和距离 r 决定。

电场线与电势

电场线的三个性质：
①电场线越密，场强越大；
②沿电场线方向，电势逐渐降低；
③电场线不相交（否则一点会有两个场强方向）。

另外：正电荷受力方向沿电场线，负电荷受力方向逆电场线。
电势差：U = W / q 电势能与电势的关系：Ep = qφ 做功与电势能：W = −ΔEp = qU
这一块最容易混的是「电势」「电势能」「电场强度」三者：
·场强 E 描述场的「强弱和方向」，是矢量；
·电势 φ 描述场的「能的性质」，是标量，有零点（通常取无穷远或大地为零）；
·电势能 Ep 是电荷在电场中具有的能量，与电荷正负有关。

「E 大」和「φ 高」没有必然关系——这是选择题最爱的陷阱。 比如两个等量同种电荷的连线中点，E = 0 但 φ 很高。

二、电容器

电容定义式：C = Q / U （C 由电容器本身决定，与 Q、U 无关） 平行板电容器：C = εS / (4πkd) 储存的能量：E = ½QU = ½CU²
平行板电容器的两类动态分析（重点题型）：

① 始终与电源相连（U 不变）：
·d 增大 → C 减小 → Q = CU 减小；
·E = U/d，d 增大则 E 减小。

② 充电后断开电源（Q 不变）：
·d 增大 → C 减小 → U = Q/C 增大；
·E = U/d = Q/(Cd) = 4πkQ/(εS)，与 d 无关， d 增大时 E 不变。
「Q 不变时 E 与 d 无关」这个结论很有意思，值得记住：
因为 C 和 U 都变了，但变化的方式恰好抵消。 所以断开电源后拉开极板，场强不变——很多人会以为场强变小。

三、恒定电流

基本定律

欧姆定律 I = U / R 串联：R = R₁+R₂　　电流处处相等 并联：1/R = 1/R₁+1/R₂　　电压处处相等 电功 W = UIt　　电热 Q = I²Rt 焦耳定律：Q = I²Rt（对任何用电器都适用）
纯电阻 vs 非纯电阻（常考区分点）：
纯电阻电路（电炉、白炽灯）：电功等于电热，W = Q = I²Rt = U²t/R。
非纯电阻（电动机、电解槽）：电功大于电热， W = UIt = I²Rt + 其他形式的能。

所以在非纯电阻电路里，欧姆定律 I = U/R 不再成立， 要改用 I = (U − E反)/R（E反 是反电动势）。
例 1

一台电动机额定电压 U = 220 V，正常工作时电流 I = 5 A，线圈电阻 r = 2 Ω。求电动机的输入功率、发热功率和输出的机械功率。

解：这是非纯电阻电路，要分别算。

输入功率（总功率）：

P入 = UI = 220 × 5 = 1100 W

发热功率（线圈上的热损耗）：

P热 = I²r = 5² × 2 = 50 W

输出机械功率：

P出 = P入 − P热 = 1100 − 50 = 1050 W

答案：输入功率 1100 W，发热 50 W， 输出机械功率 1050 W。

易错点：不能用 P = U²/r 算发热（那会得到 24200 W，荒谬）。 发热只能用 Q = I²rt，因为线圈不是纯电阻。

闭合电路欧姆定律

I = E / (R + r) 路端电压：U = E − Ir （E 是电源电动势，r 是内阻，R 是外电路电阻）
路端电压随外电阻的变化规律：
·R 增大 → I 减小 → Ir 减小 → U 增大（趋近于 E）
·R 减小 → I 增大 → Ir 增大 → U 减小
·断路（R → ∞）时 I = 0，U = E；
·短路（R = 0）时 U = 0，I = E/r（最大电流，很危险）。

四、磁场的基本性质

磁感线

磁感线的特点：
·磁体外部从 N 极指向 S 极，内部从 S 极指向 N 极，形成闭合曲线；
·磁感线越密，磁场越强；
·磁感线不相交。

电流的磁场（安培定则）

直导线：右手握住导线，拇指指向电流方向， 四指弯曲方向就是磁感线环绕方向。 环形电流/通电螺线管：右手握住螺线管，四指指向电流方向， 拇指指向就是螺线管内部的磁场方向（N 极）。
区分两个定则（这是最容易混的地方）：
安培定则（右手螺旋）——用于「电流 → 磁场」，两手都是右手；
左手定则——用于「磁场 + 电流 → 力（安培力/洛伦兹力）」，用左手。

口诀：「电生磁用右手，磁对电的作用力用左手」。

磁通量

Φ = B·S （B 与平面垂直时） 一般情况：Φ = B·S·cosθ （θ 是 B 与平面法线的夹角） 单位：韦伯（Wb），1 Wb = 1 T·m²

电磁感应初步

产生感应电流的条件：穿过闭合回路的磁通量发生变化。

注意两个要点：①回路必须闭合；②磁通量必须变化。
只有磁场不够，只有回路也不够，必须「闭合 + 变化」同时满足。
法拉第电磁感应定律：E = n·ΔΦ/Δt 导体切割磁感线：E = BLv

感应电流的方向由楞次定律或右手定则判断， 详细内容见选择性必修第二册第 2 章。

必修三的复习建议：
这一册的重点是「电路分析」和「场的描述」两大块。
·电路题：先判断是纯电阻还是非纯电阻，再决定用哪个公式；
·场的题：把电场和重力场类比——电势对应高度、电势能对应重力势能、 场强对应重力加速度的「角色」。
类比对了，很多新概念就不需要重新理解一遍。
