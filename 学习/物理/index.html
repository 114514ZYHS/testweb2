物理

人教版 · 必修一至三 · 广西高考
广西物理用人教版。物理这科的特点是模型比公式重要——公式就那些，能不能认出一道题属于哪个模型才是关键。 下面按必修顺序，每块讲清"概念、公式、典型模型"。
必修一 · 运动与力

匀变速直线运动

核心就三个公式，但要用对得先明确"哪些量是已知的"：

v = v₀ + at x = v₀t + ½at² v² = v₀² + 2ax 不涉及时间时用第三个；不涉及末速度时用第二个。

两个常用结论：

  • 中间时刻速度 = 平均速度：v(t/2) = (v₀+v)/2 = x/t。求纸带速度时常用。
  • 逐差法：Δx = aT²。纸带实验求加速度就靠这个，等时间间隔的两段位移差是个定值。

受力分析：按顺序找，别漏别多

受力分析是力学的地基，顺序固定：

  1. 重力——只要有质量就有
  2. 弹力——找接触面，看有没有挤压
  3. 摩擦力——先判断是静还是动，再看方向（与相对运动方向相反，不是与运动方向）
  4. 其他力——拉力、电场力、磁场力等

画完检查两件事：每个力能不能找到施力物体（找不到就是多余的），接触面有没有被漏掉。

牛顿第二定律与两类问题

F合 = ma

所有动力学题都归为两类：

  • 已知力求运动：受力分析 → 求合力 → a → 用运动学公式求 v、x
  • 已知运动求力：运动学 → a → 求合力 → 分析出具体的力

中间那座桥就是加速度 a，两边来回走。

最容易错的三个地方： ①摩擦力方向搞反——是"相对运动"方向的反方向，不是绝对运动方向。传送带上物体和传送带同向运动，摩擦力却可能与运动同向； ②忘了超重失重——加速度向上是超重（支持力大于重力），向下是失重，与速度方向无关； ③整体法隔离法用混——求整体加速度用整体法，求内部相互作用力必须隔离。
必修二 · 曲线运动与能量

平抛运动：拆成两个方向

平抛的本质是水平匀速 + 竖直自由落体，两方向独立计算：

水平：x = v₀t vx = v₀ 竖直：y = ½gt² vy = gt 合速度大小 v = √(v₀² + vy²) 合速度方向 tanθ = vy / v₀

记住"时间由下落高度决定"：t = √(2y/g)，与水平初速度无关。

圆周运动

v = ωr 　　　　T = 2πr/v = 2π/ω 向心加速度 a = v²/r = ω²r 向心力 F = mv²/r = mω²r

向心力不是"新的力"——它是其他力（或合力）指向圆心的那个分量。做题时先做受力分析，再把指向圆心的分力求和。

几个典型模型：

  • 水平面内转弯（汽车转弯、火车转弯）：摩擦力或重力的分力提供向心力
  • 竖直平面内圆周：最高点有最小速度要求（绳模型 v ≥ √(gr)，杆模型 v ≥ 0）
  • 天体运动：万有引力提供向心力，GMm/r² = mv²/r

动能定理与机械能守恒

动能定理：W合 = ΔEk = ½mv² - ½mv₀² 机械能守恒：Ek1 + Ep1 = Ek2 + Ep2 （只有重力或弹力做功时）

两个定理怎么选：

  • 过程中有摩擦、有外力做功 → 用动能定理（它不管过程细节，只看到初末状态）
  • 只有重力或弹力做功 → 用机械能守恒（更简洁）
必修三 · 电与磁

电场

库仑定律 F = kq₁q₂ / r² 场强 E = F/q 　　　点电荷场强 E = kQ / r² 电势差 U = W / q 匀强电场 E = U / d

几个判断要记牢：电场线越密场强越大；沿电场线方向电势降低；正电荷受力方向沿电场线。

恒定电流

欧姆定律 I = U / R 串联：R = R₁+R₂　　电流处处相等 并联：1/R = 1/R₁+1/R₂　　电压处处相等 电功 W = UIt　　电热 Q = I²Rt

纯电阻电路电功等于电热，非纯电阻（电动机、电解槽）电功大于电热。这是常考的区分点。

电磁感应

法拉第定律 E = nΔΦ/Δt 导体切割磁感线 E = BLv 楞次定律：感应电流的磁场总要阻碍磁通量的变化

楞次定律的通俗理解：你往里推，它就往外顶；你往外拉，它就往里拽。判断方向时先看原磁场方向，再看磁通量是增还是减，最后用右手定则定电流方向。

关于做题：物理题不要一上来就套公式。先花三十秒判断"这道题是什么模型"—— 是匀变速、是平抛、是圆周、还是能量守恒。模型认错了，公式再熟也算不出答案。 每道题做完记一句话：这道题的关键判断是什么。积累二十道之后你会发现翻来覆去就那几种。
