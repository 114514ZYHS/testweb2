第 3 章 原子物理与核物理

人教版选择性必修第三册 · 4.1 – 5.5
本章的特点：这一章推导少、记忆多——大量是人名、实验、模型和历史顺序。 但它也是性价比最高的一章，因为这部分的考点固定，背下来就能拿分。

主线是两条：「原子是怎么被认识的」（原子结构史）和 「原子核里发生了什么」（核反应）。

3.1 原子结构的发展史

四个阶段，一条线索

① 道尔顿（1803）——实心球模型
原子是不可再分的实心小球。这是最早的近代原子论。

② 汤姆孙（1897）——发现电子，提出「枣糕模型」
通过阴极射线实验发现电子，证明原子可以再分。 他认为电子像枣子一样嵌在带正电的「面团」里。

③ 卢瑟福（1911）——核式结构模型
依据是α 粒子散射实验。结论：原子中心有一个很小的核， 集中了全部正电荷和几乎全部质量；电子在核外空间绕核运动。

④ 玻尔（1913）——玻尔模型
为了解释氢原子光谱，提出三条假设（见下一节）。

α 粒子散射实验（重点）

实验现象与解释，一一对应：
·绝大多数 α 粒子穿过金箔后方向几乎不变 → 说明原子内部大部分是空的；
·少数 α 粒子发生了较大角度偏转 → 说明遇到了带正电的集中区域（原子核）；
·极少数 α 粒子偏转角度大于 90°（被弹回来） → 说明原子核很小、质量很大、正电荷很集中。

记住这个因果链条，这是必考的。
实验用的是金箔（金可以加工得极薄，且原子序数大，效果明显）。
原子核的尺度：
原子半径数量级 10⁻¹⁰ m
原子核半径数量级 10⁻¹⁵ m
相差 5 个数量级，也就是说核的体积只占原子的极小极小一部分。

3.2 玻尔模型与氢原子光谱

三条假设

① 轨道量子化——电子只能在某些特定的轨道上运动， 在这些轨道上运动时不辐射能量，是稳定的。

② 能量量子化——原子在不同轨道上对应不同的能量，这些能量值是不连续的。

③ 跃迁——电子从能量较高的轨道跃迁到较低轨道时， 辐射出一定频率的光子；反之吸收光子。 hν = E初 − E末 h 是普朗克常量，h ≈ 6.63×10⁻³⁴ J·s ν 是光子的频率

能级与光谱

氢原子的能级： E₁ = −13.6 eV （基态，n=1） E₂ = −3.40 eV （第 1 激发态，n=2） E₃ = −1.51 eV （n=3） 一般公式： Eₙ = E₁ / n² 注意：能级是负值——负号表示电子被束缚。 n 越大，能量越接近零（越接近电离）。
计算跃迁时最常见的错误：忘了用能级差。
要算的是 hν = E高 − E低，而不是直接用某个能级值。

还有一个高频考点——光子与实物粒子的区别：
·光子激发：能量必须恰好等于能级差才能被吸收；
·电子等实物粒子碰撞激发：只需要能量大于或等于能级差就行， 多余的能量变成粒子的动能。
这个区别每年都考，一定要分清。
例 1

处于 n = 3 能级的氢原子（E₃ = −1.51 eV）跃迁到 n = 1 能级（E₁ = −13.6 eV）。 求辐射光子的能量。

解：由 hν = E初 − E末

hν = E₃ − E₁ = (−1.51) − (−13.6)

= −1.51 + 13.6 = 12.09 eV

答案：光子能量为 12.09 eV。

注意符号：两个能级都是负的，相减时负负得正。 如果把它算成 −1.51 − 13.6 = −15.11，就是符号错了。

3.3 天然放射性

三种射线

α 射线——氦核（⁴₂He），带 2 个正电荷。 电离能力最强，穿透能力最弱（一张纸就能挡住）。

β 射线——高速电子流，带 1 个负电荷。 电离和穿透能力都居中（能穿透几毫米铝板）。

γ 射线——光子，不带电。 电离能力最弱，穿透能力最强（能穿透几厘米铅板）。
穿透能力和电离能力的顺序是相反的——这是最好记的地方。
穿透：γ > β > α
电离：α > β > γ

为什么相反：电离本领强，说明它跟物质作用强烈， 能量很快被消耗掉，所以走不远（穿透弱）。

放射性衰变

α 衰变： ᴬ_Z X → ᴬ⁻⁴_(Z−2) Y + ⁴₂He （质量数减 4，电荷数减 2） β 衰变： ᴬ_Z X → ᴬ_(Z+1) Y + ⁰_(−1)e （质量数不变，电荷数加 1） γ 辐射：通常伴随 α 或 β 衰变发生，不改变质量数和电荷数
β 衰变的本质（容易考）：
β 粒子不是核外电子，而是核内一个中子变成一个质子和一个电子时放出的。 ¹₀n → ¹₁p + ⁰_(−1)e 所以 β 衰变后电荷数加 1，因为中子变成了质子。

半衰期

半衰期：放射性元素的原子核有半数发生衰变所需的时间。

两个要点：
①半衰期是统计规律，只对大量原子核有意义，对单个原子核无意义；
②半衰期由核内部本身决定，与温度、压强、化学状态全都无关。
经过 n 个半衰期后，剩下的原子核数： N = N₀ · (1/2)ⁿ 其中 n = t / T（t 是总时间，T 是半衰期）

3.4 核反应与核能

四种核反应类型

① 衰变： 自发放出 α 或 β 粒子 ② 人工转变（卢瑟福发现质子）： ¹⁴₇N + ⁴₂He → ¹⁷₈O + ¹₁H ③ 重核裂变（例）： ²³⁵₉₂U + ¹₀n → ¹⁴¹₅₆Ba + ⁹²₃₆Kr + 3¹₀n ④ 轻核聚变（例）： ²₁H + ³₁H → ⁴₂He + ¹₀n （氘 + 氚 → 氦）
裂变和聚变的关键区别：
裂变需要中子轰击（要有「扳机」），而且会放出更多中子， 可以形成链式反应——这是原子弹和核反应堆的原理。
聚变需要极高温度（几千万度），所以叫热核反应—— 这是氢弹和太阳发光发热的原理。

为什么聚变释放能量更多：因为轻核聚变成中等核时， 平均结合能增加得多，质量亏损的比例更大。

质能方程与质量亏损

爱因斯坦质能方程： E = mc² 质量亏损：Δm = 反应前的总质量 − 反应后的总质量 释放的核能：ΔE = Δm·c²
「质量亏损」不是质量消失了，而是亏损的质量转化成了能量。

实用的换算关系（背下来省时间）： 1 u = 931.5 MeV/c² 也就是说，1 u 的质量亏损，对应释放 931.5 MeV 的能量。 （u 是原子质量单位，1 u ≈ 1.66×10⁻²⁷ kg）
例 2

某核反应中质量亏损 Δm = 0.02 u。求释放的核能是多少 MeV。

解：用换算关系 1 u ↔ 931.5 MeV。

ΔE = 0.02 × 931.5 = 18.63 MeV

答案：释放核能 18.63 MeV。

提示：这类题不需要代入 c² 硬算， 用 931.5 MeV/u 这个换算直接把 u 换成能量就行，快得多。

结合能

结合能：把原子核拆分成单个核子所需要的能量 （反过来，核子结合成核时释放的能量就是它）。

比结合能（平均结合能） = 结合能 / 核子数。
比结合能越大，原子核越稳定。
中等质量的核比结合能最大（最稳定）， 所以重核裂变和轻核聚变都朝中等核方向走，都会释放能量。
本章的记忆重点总结：
①四个模型的顺序（道尔顿→汤姆孙→卢瑟福→玻尔）和各自的依据；
②α 散射实验的三种现象与结论一一对应；
③三种射线的穿透/电离顺序相反；
④β 衰变的本质是中子变质子；
⑤光子激发要恰好匹配，粒子碰撞只要够大；
⑥1 u = 931.5 MeV。

这一章没有复杂计算，把上面六条记住，分数基本就稳了。
