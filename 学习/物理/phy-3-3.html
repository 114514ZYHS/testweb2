第 3 章 光

人教版选择性必修第一册 · 3.1 – 3.5
本章的两条主线：
一条是「光的传播」——反射、折射、全反射，都属于几何光学，靠画图计算。
另一条是「光的本性」——干涉、衍射、偏振，这些现象说明光是一种波。
两条线合起来就是：用几何方法算光路，用波动现象证明光的波动性。

3.1 光的折射

折射定律

n = sinθ₁ / sinθ₂ θ₁：入射角（在真空或空气中） θ₂：折射角（在介质中） n：介质的折射率，永远 ≥ 1
折射率：光从真空射入某种介质时，入射角的正弦与折射角的正弦之比，叫这种介质的折射率。

折射率还可以写成 n = c / v——真空中的光速与介质中光速之比。
所以折射率越大，光在这种介质里跑得越慢。
三个易错点： ①n 一定是真空（或空气）中的角除以介质中的角，两个角的顺序不能反， 否则算出来会小于 1，那就错了； ②角是与法线的夹角，不是与界面的夹角； ③光从空气进入水或玻璃时，折射角小于入射角（光向法线偏折）。

3.2 全反射

发生条件

全反射：光从光密介质射向光疏介质时，如果入射角增大到某一角度， 折射光完全消失，只剩反射光的现象。

两个条件缺一不可：
①光从光密介质射向光疏介质（例如从水/玻璃射向空气）；
②入射角大于或等于临界角。
临界角公式：sinC = 1 / n （n 是光密介质的折射率，所以 n 越大临界角越小）
常见介质的临界角：水约 48.8°，玻璃约 41.8°（具体值取决于玻璃种类）。
全反射的典型应用：光导纤维（通信）、全反射棱镜（潜望镜、自行车尾灯）、 钻石的璀璨闪光（钻石 n 很大，临界角小，光进去后反复全反射）。
例 1

某玻璃的折射率 n = √2。求光从玻璃射向空气时的临界角。

解：由 sinC = 1/n：

sinC = 1/√2 = √2/2

所以 C = 45°

答案：临界角为 45°。也就是说，入射角大于 45° 时会发生全反射。

3.3 光的干涉

双缝干涉

干涉现象：频率相同的两列光波叠加，出现明暗相间的条纹。 这是光具有波动性的直接证据。
相邻亮纹（或暗纹）的间距： Δy = L·λ / d L：双缝到屏的距离 d：两缝之间的距离 λ：光的波长

从这个公式能推出三件事：

  • 波长越长，条纹间距越大——所以红光条纹比紫光宽（红 λ 大）。
  • 缝间距离 d 越小，条纹越宽——所以双缝要做得非常细。
  • 屏越远（L 越大），条纹越宽。

反过来，如果测出了条纹间距 Δy、缝距 d 和距离 L，就能算出光的波长——这就是「用双缝干涉测波长」实验的原理。

薄膜干涉

光照射到薄膜上时，膜的前表面反射的光和后表面反射的光叠加，产生干涉。

  • 肥皂泡、水面油膜的彩色条纹——膜厚不同，各处强弱不同，于是出现彩色。
  • 增透膜——在镜片表面镀一层膜，使反射光相互抵消，增加透过的光。 眼镜、相机镜头上的紫色反光就是它。
  • 检验平面平整度——把标准样板放在被检平面上，看干涉条纹是否弯曲。 条纹弯曲说明该处不平。
干涉和衍射的区别要分清：
干涉是几列波相互叠加（双缝是两列，薄膜是两个表面反射的）。
衍射是一列波绕过障碍物或穿过小孔后自己散开。
两者都是波特有的现象，但成因不同，别混。

3.4 光的衍射与偏振

光的衍射

光通过很小的孔或遇到很小的障碍物时，会偏离直线传播，绕到阴影区域里去，形成明暗条纹。

发生明显衍射的条件：障碍物的尺寸比波长小，或者跟波长差不多。

因为可见光的波长极短（400–760 nm），所以要观察明显的光衍射， 孔或缝必须做得非常小——这就是为什么生活中不容易看到光衍射，但声波衍射（波长长）随处可见。

光的偏振

偏振现象：光波是横波，它的振动方向垂直于传播方向。 如果只让某一特定方向的光振动通过，就得到偏振光。

偏振现象证明了光是横波，这一点很重要，是常考的判断依据。

自然光（如阳光、灯光）在各个方向上振动，是非偏振光。经过偏振片后变成偏振光。

应用：偏振太阳镜（滤掉水面、路面反射的偏振眩光）、摄影用偏振滤镜、 液晶显示器（用偏振控制显示）。

3.5 光的色散与电磁波谱

色散

白光通过三棱镜后分解成七色光，这说明不同颜色的光在同一介质中折射率不同。

从红到紫，频率依次升高、波长依次减小、折射率依次增大： 红 → 橙 → 黄 → 绿 → 青 → 蓝 → 紫 λ 大 ←————————————————→ λ 小 n 小 ←————————————————→ n 大 f 小 ←————————————————→ f 大

由此推出一串结论（考选择题很爱问）：

  • 紫光折射率大 → 在同种介质中紫光速度小、临界角小（更容易全反射）
  • 紫光频率大 → 在双缝干涉中紫光条纹窄
  • 紫光波长短 → 更容易发生明显衍射的是红光
「频率大、折射率大、速度小、临界角小、波长短、条纹窄」——这六个属性是同向变化的。 记住一句「紫光啥都大，除了速度和波长」基本就够了。 做题时只要确定是紫光还是红光，其余属性顺着推。

电磁波谱

把各种电磁波按波长（或频率）排列，就得到电磁波谱。它们本质相同，都是电磁波，只是波长不同。

波长从长到短： 无线电波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线 频率从低到高（按上面同一顺序）

各自的典型用途：

  • 无线电波——通信、广播、雷达
  • 红外线——热效应强，用于遥控、红外测温、夜视仪
  • 紫外线——杀菌消毒、促进维生素 D 合成；过强会伤害皮肤和眼睛
  • X 射线——穿透力强，用于医学透视、检查骨折
  • γ 射线——穿透力最强，用于治疗肿瘤、探测金属缺陷

共同点：都能在真空中传播，速度都是 c = 3.0×10⁸ m/s。

例 2

在双缝干涉实验中，双缝间距 d = 0.2 mm，双缝到屏的距离 L = 1.0 m。用某单色光照射，测得相邻两条亮纹之间的距离为 3.0 mm。求这种光的波长。

解：由 Δy = Lλ/d 得

λ = Δy·d / L

统一单位：Δy = 3.0×10⁻³ m，d = 0.2×10⁻³ m，L = 1.0 m

λ = (3.0×10⁻³ × 0.2×10⁻³) / 1.0 = 6.0×10⁻⁷ m

答案：6.0×10⁻⁷ m，即 600 nm——属于橙光范围，这个结果合理。

本章做题的顺序建议：
①看题目问的是「光路计算」还是「波动现象」——前者画图、用折射定律；后者回忆干涉衍射条件。
②涉及全反射时，先确认是不是从光密射向光疏，算临界角再比大小。
③涉及到颜色对比的题，把「紫光啥都大」那句口诀在心里过一遍。
