第 1 章 分子动理论与气体

人教版选择性必修第三册 · 1.1 – 2.5
本章的主线：前面几章处理的是「一个物体」或「几个物体」， 这一章开始处理大量分子——几万亿亿个，没法一个个算，只能用统计的方法。

抓住这一条：温度是分子平均动能的标志。 温度高不是「每个分子都快」，而是「平均下来快」。

1.1 分子动理论的基本内容

三条基本观点

① 物质由大量分子组成
分子直径数量级约 10⁻¹⁰ m，一般分子质量数量级约 10⁻²⁶ kg。
阿伏伽德罗常数 Nₐ ≈ 6.02×10²³ /mol—— 它是联系宏观量和微观量的桥梁。

② 分子永不停息地做无规则运动
证据是布朗运动和扩散现象。

③ 分子间存在相互作用力
既有引力又有斥力，实际表现出来的是二者的合力。

分子力与分子势能

分子间距离 r 与分子力 F 的关系： r < r₀ ：斥力 > 引力，表现为斥力（F > 0，方向向外） r = r₀ ：引力 = 斥力，合力为零（这是平衡位置） r > r₀ ：引力 > 斥力，表现为引力 r > 10r₀ ：分子力趋近于零（可以忽略） r₀ 的数量级约为 10⁻¹⁰ m
分子势能的规律最容易记混，看这张图就够了：
·r = r₀ 时，分子势能最小（不是零）；
·r < r₀ 时，靠近要克服斥力做功，势能增大；
·r > r₀ 时，远离要克服引力做功，势能也增大。

所以：无论是靠近还是远离 r₀，势能都是增大的。
而分子力在 r = r₀ 处为零——力的零点和势能的最低点在同一位置， 这个对应关系记住就不会错。

1.2 温度与内能

分子热运动的统计规律

温度是分子平均动能的标志。

温度相同的不同物质，分子的平均动能相同。 但因为分子质量不同，平均速率不同—— 质量小的分子跑得快（比如氢气分子就比氧气分子快）。
分子平均动能只与温度有关： 温度升高 → 平均动能增大 温度相同 → 平均动能相同（与物质种类无关）

内能

内能 = 所有分子的动能之和 + 所有分子的势能之和

所以内能由两个因素决定：
①温度——决定分子动能的总和
②体积——决定分子间距离，从而决定分子势能的总和
③（还有物质的量和种类）
这一节最容易错的三句话：
①「温度高的物体内能一定大」——错。还要看物质的量和体积。 一杯 90 ℃ 的水内能可能小于一湖 20 ℃ 的水。
②「温度不变内能就不变」——错。晶体熔化时温度不变，但吸热，内能增大。
③「0 ℃ 的物体内能为零」——错。分子永不停息地运动，内能永远不为零。 只有绝对零度（-273.15 ℃）时分子热运动才趋于停止，而这也是达不到的。

1.3 气体实验定律

三个定律

玻意耳定律（等温）： p₁V₁ = p₂V₂ 查理定律（等容）： p₁/T₁ = p₂/T₂ 盖-吕萨克定律（等压）：V₁/T₁ = V₂/T₂ （T 必须是热力学温度，单位 K）
热力学温度与摄氏温度： T = t + 273.15 近似用 273 也够（高中阶段）。 注意：所有气体定律里的温度必须是热力学温度。 如果题目给的是摄氏度，第一步就是换算。 这是丢分最多的一步。

理想气体状态方程

pV / T = 常量 或写成： p₁V₁ / T₁ = p₂V₂ / T₂ （这个式子把三个定律统一起来了，用它可以代替三个定律）

气体压强的微观解释

气体压强由两个因素决定：
①分子平均动能（温度越高，撞得越狠）
②分子数密度（单位体积内的分子数越多，撞得越频繁）

用这个解释可以理解：温度升高、体积减小时，压强都增大——因为前者让分子撞得狠， 后者让分子撞得频繁。

例 1

一定质量的理想气体，在 27 ℃ 时体积为 2 L，压强为 1.0×10⁵ Pa。 保持压强不变，加热到 127 ℃。求此时气体的体积。

解：这是等压变化，用盖-吕萨克定律。

第一步，温度换成开尔文：

T₁ = 27 + 273 = 300 K

T₂ = 127 + 273 = 400 K

第二步，代入定律：

V₁/T₁ = V₂/T₂

2 / 300 = V₂ / 400

V₂ = 2 × 400 / 300 = 8/3 ≈ 2.67 L

答案：体积变为 约 2.67 L。

如果忘了换开尔文会怎样：直接算成 2×127/27 ≈ 9.4 L， 结果完全离谱。看到温度先换成 K，这一步不能省。

气体题的解题模板（照着走就行）：
①确定研究对象——哪部分气体；
②判断什么不变——是等温、等容还是等压？还是三个都变？
③温度全部换成开尔文；
④列方程——等温用 pV 相等，等容用 p/T 相等，等压用 V/T 相等， 三个都变就用 pV/T 相等；
⑤统一单位——同类的量用同一单位即可（比如都用 L 和 Pa），不必换成国际单位。

1.4 液体与固体

晶体与非晶体

  • 晶体——有规则的几何外形，有固定的熔点。 又分单晶体（物理性质各向异性）和多晶体（各向同性，如各种金属）。
  • 非晶体——无规则外形，没有固定熔点。如玻璃、松香、沥青。

判断依据看两条：有没有固定熔点、物理性质是否各向异性。

液体的表面张力

表面张力：液体表面层里的分子比内部稀疏，分子间表现为引力， 使液面有收缩的趋势。

表现：水滴呈球形（在同样体积下球的表面积最小）、 昆虫能在水面行走、硬币能浮在水面、荷叶上的水珠成珠状。

浸润与毛细现象

  • 浸润——液体与固体接触时，液体附着在固体上（水与玻璃）。 不浸润——液体不附着（水银与玻璃）。
  • 毛细现象——浸润的液体在细管中上升，不浸润的液体下降。 管越细，现象越明显。植物吸水、毛巾吸水、土壤保水都靠它。
关于液晶（常考一个点）：
液晶既有液体的流动性，又有晶体的光学各向异性。
它本身不是晶体也不是液体，是中间态。显示器就用它—— 加电压改变分子排列，从而改变透光度。
注意：液晶不是「液态的晶体」这么简单，它的关键特性是光学性质随电压改变。
本章的核心记忆点：
①温度 = 分子平均动能的标志（与物质种类无关，与质量无关）；
②分子势能在 r = r₀ 处最小；
③气体定律必须先换开尔文；
④气体压强由「平均动能」和「分子数密度」共同决定。
