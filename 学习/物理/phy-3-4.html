第 1 章 磁场

人教版选择性必修第二册 · 1.1 – 1.4
本章主线：必修三学过「电生磁」和「磁生电」的初步概念， 这一章要把磁场对电流和运动电荷的作用算清楚。

核心就三件事：磁感应强度 B 怎么描述磁场、通电导线在磁场里受多大力（安培力）、 运动电荷在磁场里受多大力（洛伦兹力）以及它带来的圆周运动。

1.1 磁感应强度

怎么描述磁场的强弱

磁感应强度 B：把一小段通电导线垂直放入磁场中，它受到的安培力 F 与 电流 I 和导线长度 L 的乘积之比，叫该处的磁感应强度。 B = F / (I·L) （要求导线与磁场方向垂直） B 是矢量，方向规定为小磁针静止时 N 极所指的方向。单位是特斯拉（T）。
注意这个公式的条件：只有导线与磁场垂直时才能用 B = F/(IL)。
如果导线与磁场平行，受力为零，但该处磁场并不为零—— 这一点最容易错，不能因为导线不受力就说那里没磁场。

1.2 安培力

大小

F = BIL （B ⊥ I 时） 一般情况： F = BIL·sinθ 其中 θ 是 B 与 I 的夹角 B ∥ I 时（θ = 0 或 180°）：F = 0

方向：左手定则

左手定则：伸开左手，让磁感线穿入手心， 四指指向电流方向，那么大拇指指向的就是安培力方向。
三个最容易出错的地方： ①分清左右手——判断力用左手，判断感应电流/磁感线用右手。 记忆口诀：「左力右电」； ②受力为零不等于没磁场——平行时 F = 0 但 B 存在； ③安培力方向永远同时垂直于 B 和 I——它垂直于 B 与 I 所确定的那个平面。 所以安培力不可能沿着导线方向。

安培力的应用

  • 电动机——通电线圈在磁场中受力转动
  • 磁电式电流表——线圈受力偏转，偏角与电流成正比
  • 磁悬浮——利用安培力把物体托起
  • 扬声器——音圈受安培力带动纸盆振动发声

1.3 洛伦兹力

定义与大小

洛伦兹力：磁场对运动电荷的作用力。 f = qvB （v ⊥ B 时） 一般情况：f = qvB·sinθ （θ 是 v 与 B 的夹角）
洛伦兹力是安培力的微观本质——安培力是大量定向移动电荷所受洛伦兹力的宏观表现。

方向

正负电荷方向相反，这是最大的坑：
判断时同样用左手定则，四指指向正电荷的运动方向。
如果是负电荷（如电子），四指要指向它运动的反方向。
或者更省事的办法：先按正电荷判断方向，再取反。

洛伦兹力不做功

因为洛伦兹力永远垂直于速度方向，所以它不做功， 不会改变带电粒子的速度大小（即动能不变）， 只会改变速度方向。

这一点是理解「带电粒子在磁场中做匀速圆周运动」的关键—— 速度大小不变、方向时刻改变，正是匀速圆周运动的特征。

1.4 带电粒子在匀强磁场中的运动

核心模型：圆周运动

当带电粒子垂直射入匀强磁场时，洛伦兹力提供向心力，粒子做匀速圆周运动。

洛伦兹力提供向心力：qvB = mv² / r 由此得两个必须记住的公式： 半径 r = mv / (qB) 周期 T = 2πm / (qB)
周期公式里没有 v，也没有 r——这是最重要的结论。
它说明：同一带电粒子在同一磁场中，不管速度多大，绕一圈的时间都一样。
这就是回旋加速器能工作的原理基础：加速器可以固定频率，因为周期不变。
速度大会导致半径变大，但转一圈的时间不变。

解题方法：三步走

  1. 定圆心——圆心在洛伦兹力方向上（即垂直于速度的那条线上）。 常用「两处速度的垂线交点」来找。
  2. 定半径——用 r = mv/(qB)，或者用几何关系（勾股、三角函数）求。
  3. 定圆心角——圆心角 θ 与时间的关系是 t = (θ/2π)·T。 转过多少角度，就用了多少时间。
例 1

质量 m、电荷量 q 的正电荷以速度 v 垂直射入磁感应强度为 B 的匀强磁场。求运动的半径和周期。

解：洛伦兹力提供向心力。

qvB = mv²/r

解得 r = mv / (qB)

周期 T = 2πr/v = 2π(mv/qB)/v = 2πm/(qB)

答案：半径 r = mv/(qB)，周期 T = 2πm/(qB)。

注意：周期表达式中 v 被约掉了，说明周期与速度无关。

例 2

电子质量 m = 9.1×10⁻³¹ kg，电荷量大小 q = 1.6×10⁻¹⁹ C，以 v = 2.0×10⁶ m/s 垂直进入 B = 0.01 T 的匀强磁场。求电子的运动半径。

解：直接代入 r = mv/(qB)：

r = (9.1×10⁻³¹ × 2.0×10⁶) / (1.6×10⁻¹⁹ × 0.01)

分子 = 1.82×10⁻²⁴

分母 = 1.6×10⁻²¹

r = 1.82×10⁻²⁴ / 1.6×10⁻²¹ ≈ 1.14×10⁻³ m

答案：半径约为 1.1×10⁻³ m（约 1.1 mm）。

量级检查：电子质量极小，所以半径也只有毫米级，这个数量级是合理的。

几类常见的几何情形

  • 垂直边界射入——粒子从边界射入又从同一边界射出，圆心在边界上。 圆心角两倍于入射角，这个结论能直接看出时间关系。
  • 速度方向与边界成 θ 角射入——进入后转过的圆心角是 2θ。 出去时的速度方向与边界也成 θ 角（像镜面反射一样，但原理不同）。
  • 圆形磁场区域——如果粒子沿半径方向射入圆形磁场，出射时速度反向延长线也过圆心。 这是常考的对称性。
本章做题的总提醒：
①先画图！一定要在纸上画出圆心的位置，比硬算快得多；
②找圆心靠「半径垂直于速度」这一条性质，速度方向知道了，圆心就在垂线上；
③注意正负电荷的方向判断相反，这是丢分重灾区；
④涉及「恰好不射出边界」这类临界问题，临界条件是轨迹圆与边界相切。
