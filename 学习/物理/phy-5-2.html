第 2 章 热力学定律与能量守恒

人教版选择性必修第三册 · 3.1 – 3.4
本章的地位：前面讲的是「怎么算」，这一章讲的是「哪些过程可能发生、哪些不可能」。

热力学第一定律管能量的守恒，第二定律管过程的方向。 这两条定律是整章的两根柱子。

2.1 热力学第一定律

内容与符号规则

ΔU = W + Q ΔU：内能的变化量 W：外界对系统做的功 Q：系统吸收的热量
符号规定（必须记准，这是唯一的难点）：
W：外界对系统做功取正，系统对外做功取负
Q：系统吸热取正，系统放热取负
ΔU：内能增加取正，内能减少取负
记忆方法：把「对系统有利」的都算正号。
外界给系统做功（+）、给系统热量（+），系统内能就增加（+）。
一句话概括：外面往里送，里面就涨。

四种特殊情形

绝热过程：Q = 0，ΔU = W （外界做功多少，内能就增加多少） 等容过程：W = 0，ΔU = Q （不做功，内能变化全靠吸放热） 等温过程：ΔU = 0，Q = −W （理想气体内能只与温度有关） 等压过程：W = −pΔV （气体膨胀对外做功，取负）
两个关键前提：
①「理想气体内能只与温度有关」——所以等温就意味着 ΔU = 0；
②气体做功公式 W = pΔV 中的体积变化要算「对外」还是「对内」—— 膨胀时 ΔV > 0，气体对外做功，按符号规定应取负。

2.2 热力学第二定律

两种表述

克劳修斯表述（关于热传递）：
热量不能自发地从低温物体传到高温物体。

开尔文表述（关于做功）：
不可能从单一热源吸热，把它全部用来做功，而不引起其他变化。
这两句话一定要看清关键词：
「自发」——热量从低温传到高温是可以的，冰箱、空调就在做， 但需要消耗电能，不是自发的。
「不引起其他变化」——热全部变成功也行（等温膨胀就可以）， 但会引起体积变化，所以不能叫「不引起其他变化」。

所以这两条都不是「绝对不可能」，而是「不能白干」。

第二类永动机为什么不可能

第一类永动机——不消耗能量而能不断做功。违反能量守恒（第一定律）。

第二类永动机——从单一热源吸热全部用来做功，效率 100%。违反第二定律。

区别：第一类是不守恒，第二类是不违背守恒但仍不可能。 第二类永动机不违反能量守恒，这就是它「迷惑」人的地方。

熵与有序无序

熵：描述系统无序程度的物理量。熵越大，越无序。

热力学第二定律的微观意义： 一切自发过程总是从有序走向无序，也就是熵增加的方向。
所以第二定律又叫熵增加原理。

举例：一滴墨水滴进清水会自然散开（有序→无序）， 散开的墨水不会自己聚回一滴（无序→有序不会自发发生）。

2.3 能量守恒定律

能量守恒定律：能量既不会凭空产生，也不会凭空消失， 它只能从一种形式转化为另一种形式，或从一个物体转移到另一个物体， 而能量的总量保持不变。

这是自然界最普遍的规律之一，是十九世纪自然科学的三大发现之一 （另两个是细胞学说、生物进化论）。

永动机的彻底否定

能量守恒否定第一类永动机，热力学第二定律否定第二类永动机。两者合起来，永动机彻底不可能。

2.4 热机效率与能量耗散

热机效率

热机效率：η = W / Q₁ W：对外做的功 Q₁：从高温热源吸收的热量 因为 Q₁ = W + Q₂（Q₂ 是向低温热源放出的热量）， 所以 η = (Q₁ − Q₂) / Q₁ < 1 效率永远小于 100%。
为什么热机效率不可能达到 100%：
因为热机做功必须有一个低温热源把余热排掉。 没有温度差，热机就不能持续工作。
所以必须有一部分热量被浪费掉，这是第二定律的直接结论，不是技术问题。

能量耗散

能量耗散：燃料燃烧产生的内能，一部分用来做功， 另一部分散失到环境中，分散到周围，无法重新收集起来再利用。

注意：能量总量并没有减少（守恒定律仍然成立）， 只是品质降低了——从「可以利用」变成了「无法利用」。 这就是为什么我们要节约能源：不是能量变少了，而是好用的能量变少了。
例 1

一定质量的理想气体，外界对它做了 200 J 的功，同时它向外放出了 80 J 的热量。 求气体内能的变化。

解：由热力学第一定律 ΔU = W + Q。

外界对气体做功：W = +200 J

气体放热：Q = −80 J

ΔU = 200 + (−80) = +120 J

答案：气体内能增加了 120 J。

易错点：放热要取负号。如果写成 +80，就会得到 280 J，错得离谱。

例 2

一定质量的理想气体做等温膨胀，体积从 V 增大到 2V，过程中吸收了 500 J 的热量。 求气体对外做的功和内能的变化。

解：理想气体的内能只与温度有关，等温过程温度不变，所以内能不变。

ΔU = 0

由 ΔU = W + Q：

0 = W + 500

W = −500 J

W 为负，说明外界对气体做负功，即气体对外做功 500 J。

答案：气体对外做功 500 J，内能不变。

物理图像：吸的热全部用来对外做功了，一点没留下（所以内能不变）。 这正好符合「等温过程 ΔU = 0，Q = −W」。

本章做题的两句口诀：
①看到「理想气体 + 等温」，立刻写 ΔU = 0；
②看到「绝热」，立刻写 Q = 0。
这两条能省掉一半的思考时间。

另外要分清：第一定律管「能不能」，第二定律管「顺不顺」。 题目问「这个过程的能量对不对得上」用第一定律， 问「这个过程能不能自发发生」用第二定律。
