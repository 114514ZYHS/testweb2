第 4 章 指数函数与对数函数

人教 A 版必修第一册 · 4.1 – 4.5

这一章是全书最容易学乱的一章，因为指数和对数互为逆运算，两套运算规则容易打结。建议先接受一件事：对数就是为「反过来求指数」而发明的工具，理解了这句话，大半的混乱都能消掉。

4.1 指数

4.1.1 n 次方根与分数指数幂

n 次方根：如果 xⁿ = a，就说 x 是 a 的 n 次方根。

几条规律：
• n 为奇数时，a 的 n 次方根记作 ⁿ√a，正负号与 a 相同（负数也能开奇次方）。
• n 为偶数时，负数没有偶次方根；正数的偶次方根有两个，互为相反数，记作 ±ⁿ√a。
• ⁿ√0 = 0。
两组符号一定分清：
① (ⁿ√a)ⁿ = a —— 先开方再乘方，直接还原。
② ⁿ√(aⁿ) 的值要分奇偶：n 为奇数时等于 a；n 为偶数时等于 |a|。

例：√((−3)²) = √9 = 3，是 3 而不是 −3。这就是取绝对值的原因，很多人在这一步失分。

分数指数幂

规定（其中 a > 0，m、n 为正整数，n > 1）： a^(m/n) = ⁿ√(a^m)    a^(−m/n) = 1 / a^(m/n)    a⁰ = 1 (a ≠ 0)

也就是说：分母是开方的次数，分子是乘方的次数。8^(1/3) = ³√8 = 2。

4.1.2 指数幂的运算性质

当 a > 0，b > 0，r、s 为任意实数时： aʳ · aˢ = a^(r+s)    (aʳ)ˢ = a^(rs)    (ab)ʳ = aʳbʳ
注意适用条件：底数都是正数。这是规定，不是可以商量的。 做化简题时，如果底数可能是负数，要先讨论或加上绝对值。
例 1

计算 8^(2/3) + (1/16)^(−1/2)。

解：

8^(2/3)：先把 8 写成 2³，则 (2³)^(2/3) = 2^(3 × 2/3) = 2² = 4

(1/16)^(−1/2)：先处理负指数，等于 16^(1/2) = √16 = 4

所以原式 = 4 + 4 = 8

4.2 指数函数

定义：形如 y = a^x（a > 0 且 a ≠ 1）的函数叫指数函数。
注意：底数是常数，指数是自变量，和幂函数正好反着。

图像与性质

分两种情况记住：

  • 定义域都是 R，值域都是 (0, +∞)——指数函数永远取不到 0 和负数。
  • 图像都过定点 (0, 1)——因为 a⁰ = 1 对任何合法的 a 都成立。
  • 当 a > 1 时：函数在 R 上单调递增，图像从左往右上升，越来越陡。
  • 当 0 < a < 1 时：函数在 R 上单调递减，图像从左往右下降，趋近于 0 但不相交。
  • x 轴（y = 0）是水平渐近线：图像无限靠近但永远碰不到。
例 2

比较 1.7^2.5 与 1.7^3 的大小。

解：底数相同（都是 1.7），指数不同，用指数函数 y = 1.7ˣ 的单调性。

因为 1.7 > 1，所以 y = 1.7ˣ 在 R 上单调递增。

因为 2.5 < 3，所以 1.7^2.5 < 1.7^3。

例 3（底数小于 1 的情况）

比较 0.6^(−1) 与 0.6^(−2) 的大小。

解：底数 0.6 < 1，所以 y = 0.6ˣ 单调递减。

因为 −1 > −2，指数大的反而函数值小，所以 0.6^(−1) < 0.6^(−2)。

要点：底数小于 1 时，不等号方向要反过来。这是最容易错的地方。

4.3 对数

4.3.1 对数的概念

定义：如果 a^x = N（a > 0 且 a ≠ 1，N > 0）， 那么数 x 叫做以 a 为底 N 的对数，记作 x = log_a N 其中 a 叫底数，N 叫真数。
一句话理解：对数就是在问「底数要几次方才等于这个数」。
log₂ 8 = 3 的意思是：2 的 3 次方等于 8。

指数式与对数式的互化（这是核心）：
a^x = N ⇔ x = log_a N
同一个关系的两种写法，遇到难题就在这两种形式之间来回换。

两个重要限制

  • 真数必须大于 0：N > 0。所以 log₂(−4) 是没有意义的。
  • 底数必须大于 0 且不等于 1：a > 0, a ≠ 1。底数为 1 时任何次方都是 1，没法反推指数；底数为负时结果会跳动。

两个特殊对数（简写约定）

  • 常用对数：以 10 为底，记作 lg N（省略底数 10）。
  • 自然对数：以 e 为底（e ≈ 2.71828，是个无理数），记作 ln N。

三条恒等式

log_a 1 = 0    log_a a = 1    a^(log_a N) = N

第一条：任何数的 0 次方都是 1。第二条：a 的 1 次方是 a。第三条：指数和对数互相抵消。

4.3.2 对数的运算

积的对数： log_a (MN) = log_a M + log_a N

商的对数： log_a (M/N) = log_a M − log_a N

幂的对数： log_a (Mⁿ) = n · log_a M

换底公式： log_a N = log_b N / log_b a
三条最容易记错的：
① 对数的加法对应真数的乘法，不是真数相加！
log_a M + log_a N = log_a(MN)，不是 log_a(M+N)。
② 真数的指数可以提到对数前面当系数，系数也能塞回指数位置。
③ 换底公式的用处：把底数换成好算的数（常用 10 或 e），或者凑成相同底数约掉。
例 4

计算 log₂ 6 − log₂ 3。

解：商的对数公式，log₂ 6 − log₂ 3 = log₂(6/3) = log₂ 2 = 1

例 5

计算 lg 25 + lg 4。

解：积的对数公式（反向用），lg 25 + lg 4 = lg(25 × 4) = lg 100 = 2

思路：先把两个对数并成一个，再看真数是不是整齐的数。25 × 4 = 100，正好是 10²，答案就是 2。

4.4 对数函数

定义：形如 y = log_a x（a > 0 且 a ≠ 1）的函数叫对数函数， 定义域是 (0, +∞)。

图像与性质

  • 定义域 (0, +∞)，值域 R——和指数函数正好互换。
  • 图像都过定点 (1, 0)——因为 log_a 1 = 0。
  • 当 a > 1 时：在 (0, +∞) 上单调递增。
  • 当 0 < a < 1 时：在 (0, +∞) 上单调递减。
  • y 轴是竖直渐近线：图像无限靠近 y 轴，但永远不穿过。
指数函数与对数函数互为反函数。 把 y = aˣ 的图像沿直线 y = x 翻折过去，就得到 y = log_a x 的图像。 所以它们的定义域和值域正好是互换的：
指数函数：定义域 R → 值域 (0, +∞)
对数函数：定义域 (0, +∞) → 值域 R
并且两个图像都过定点，(0,1) 和 (1,0) 互为对称点。

4.4.3 不同函数增长的差异

当 x 很大时，几类函数的增长速度差得很远。从慢到快大致是：

对数函数 < 幂函数 < 指数函数  （当 x → +∞ 时）

也就是说：指数增长最终会远远甩开其他所有函数。 y = 2ˣ 在 x 大到一定程度后，会超过任何多项式函数。这解释了为什么「复利」「病毒传播」这类问题的曲线会那么夸张。

4.5 函数的应用（二）

4.5.1 函数的零点与方程的解

零点：使 f(x) = 0 的实数 x 叫做函数 f(x) 的零点。

三者等价关系（很重要）： f(x) 有零点 ⇔ 方程 f(x) = 0 有解 ⇔ y = f(x) 的图像与 x 轴有交点

零点存在定理

如果函数 f(x) 在闭区间 [a, b] 上的图像是连续不断的一条曲线，且 f(a) · f(b) < 0， 那么 f(x) 在开区间 (a, b) 内至少有一个零点，即存在 c ∈ (a, b) 使 f(c) = 0。
用这个定理要注意：
① f(a)·f(b) < 0 的含义是「两端函数值一正一负」，说明曲线从 x 轴一边穿到了另一边。
② 定理说的是「至少有一个」，不是「只有一个」——可能有好几个零点。
③ 反过来不成立：有零点不一定两端异号（比如曲线只是碰到了 x 轴又弹回去）。 这是个充分条件，不是必要条件。

4.5.2 用二分法求方程的近似解

思路：既然 f(a)·f(b) < 0 说明区间里有零点，那就把区间对半切， 看零点落在那半边，不断缩小范围，直到精度够了为止。

  1. 确定初始区间 [a, b]，满足 f(a)·f(b) < 0；
  2. 取中点 c = (a + b) / 2；
  3. 计算 f(c)：
    • 若 f(c) = 0，c 就是零点，结束；
    • 若 f(a)·f(c) < 0，则零点在 [a, c]，令 b = c；
    • 否则零点在 [c, b]，令 a = c；
  4. 重复第 2、3 步，直到区间长度小于给定精度。

4.5.3 函数模型的应用

几类常见模型的适用场景：

  • 一次函数 y = kx + b——匀速变化。如固定单价的收费。
  • 二次函数 y = ax² + bx + c——先增后减（或反之）。如抛体运动、面积最值。
  • 指数函数 y = a·bˣ——增长（或衰减）速度越来越快。如人口、复利、放射衰变。
  • 对数函数 y = a + b·ln x——增长速度越来越慢。如学习效果的边际递减。
选模型的关键：看增长速度在变快还是变慢。
越来越快 → 指数函数；
越来越慢 → 对数函数；
快慢不变 → 一次函数。
例 6

判断方程 x³ + x − 1 = 0 在区间 (0, 1) 内是否有解。

解：设 f(x) = x³ + x − 1。这是多项式函数，在 R 上连续。

计算两端：f(0) = 0 + 0 − 1 = −1    f(1) = 1 + 1 − 1 = 1

因为 f(0)·f(1) = (−1)×1 = −1 < 0，且函数在 [0, 1] 上连续，

所以由零点存在定理，方程在 (0, 1) 内至少有一个解。

补充：如果想求近似值，可以对 [0, 1] 用二分法。取中点 0.5： f(0.5) = 0.125 + 0.5 − 1 = −0.375 < 0，说明零点在 (0.5, 1) 之间，可以继续缩。

本章小结：四组对照关系必须清楚——
• 指数运算 ↔ 对数运算（互逆）
• 指数函数 ↔ 对数函数（互为反函数，定义域值域互换）
• 底数 > 1 ↔ 底数 < 1（单调性的分水岭，容易搞反）
• 函数零点 ↔ 方程的解 ↔ 图像与 x 轴交点（三位一体）
