典型例题与解析

按章节汇总，重点讲「怎么想」而不只是「答案是什么」
这套题怎么用：先看题干，自己动手做一遍，做不下去再看解析。 解析里每一步前面都写了为什么这么做——审题时看到什么信号，就该联想到哪个方法。 直接背答案是没用的，考试换个数字就废了。

一、集合与常用逻辑用语

例 1　含参数集合的包含关系

已知集合 A = {x | -2 ≤ x ≤ 5}， B = {x | m+1 ≤ x ≤ 2m-1}，若 B ⊆ A，求实数 m 的取值范围。

第一步：先看 B 会不会是空集。这是这类题最大的坑。如果 m+1 > 2m-1， 也就是 m < 2，那么 B 是空集，空集是任何集合的子集，此时 B ⊆ A 自动成立。

第二步：再讨论 B 非空。此时 m ≥ 2，要让 B 整段落在 A 里面， 必须左端不越左、右端不越右：

m+1 ≥ -2　且　2m-1 ≤ 5　且　m ≥ 2

解得 m ≥ -3、m ≤ 3、m ≥ 2， 取交集得 2 ≤ m ≤ 3。

第三步：合并两种情况。第一种 m < 2，第二种 2 ≤ m ≤ 3， 合起来就是：

答案：m ≤ 3

易错点：漏掉「B 为空集」这一支，最后只答出 2 ≤ m ≤ 3，是这里最常见的扣分原因。 只要题目里出现含参的区间，第一反应就该是「它可能是空集吗」。
例 2　由充分条件反求参数

设 p: x > a，q: x > 1。若 p 是 q 的充分不必要条件，求 a 的取值范围。

先把话翻译成集合。「p 是 q 的充分条件」意思是 p 成立就能推出 q 成立， 也就是 {x | x > a} ⊆ {x | x > 1}。口诀是「小范围推大范围」。

画出数轴：右边这个集合从 1 往右，要让左边那一段（从 a 往右）被它包住， 左端点 a 就不能跑到 1 的左边去，所以 a ≥ 1。

再看能不能取等号。题目要的是充分不必要，即两个集合还不能相等。 当 a = 1 时两个集合完全一样，此时 p 与 q 等价，是充要条件，不是「不必要」，要舍掉。

答案：a > 1

易错点：这种题最后一步几乎总要回来查等号。「充分不必要」= 真子集，「必要不充分」= 被包含， 「充要」= 两集合相等。三个说法对应三种等号取舍，写答案前先确认题目要的是哪一种。

二、一元二次函数、方程和不等式

例 3　基本不等式求最小值

已知 x > 0，求 y = x + 4/x 的最小值。

先验三件事（口诀「一正、二定、三相等」）：x > 0 保证各项为正； 两项乘积 x · (4/x) = 4 是常数，满足「定」；最后查等号能不能取到。

y = x + 4/x ≥ 2√(x · 4/x) = 2√4 = 4

等号成立条件是两项相等：x = 4/x，即 x = 2。 而 x = 2 确实在 x > 0 的范围内，等号取得到。

答案：最小值 4，当 x = 2 时取得

例 4　等号取不到的反面教材

已知 x ≥ 3，求 y = x + 4/x 的最小值。

有人照抄上一题，直接写「最小值是 4，当 x = 2 时取得」。这是错的。 因为 x = 2 根本不在 x ≥ 3 的范围里，等号取不到，4 这个值拿不到。

正确做法：改用单调性。设 3 ≤ x₁ < x₂，作差：

f(x₁) - f(x₂) = (x₁ - x₂)(1 - 4/(x₁x₂))

因为 x₁x₂ > 9 > 4，所以 4/(x₁x₂) < 1， 括号内为正；又 x₁ - x₂ < 0，故差值小于 0，函数在 [3, +∞) 上单调递增。 最小值在左端点取到：

y_min = 3 + 4/3 = 13/3

答案：最小值 13/3，当 x = 3 时取得

核心提醒：基本不等式只是求最值的工具之一，不是万能公式。 用它之前必须确认等号能取到；取不到就换单调性，这是出题人最爱的分水岭。
例 5　二次项系数为负的不等式

解不等式 -x² + 2x + 3 ≥ 0。

第一步：把二次项系数调成正的。两边同乘 -1，注意不等号要反向：

x² - 2x - 3 ≤ 0

第二步：因式分解找根。x² - 2x - 3 = (x-3)(x+1)， 两根为 x = 3 与 x = -1。

第三步：看开口方向定区间。现在二次项系数为正，抛物线开口向上， 要 ≤ 0 的部分在两根之间（口诀「小于取中间」）。

答案：-1 ≤ x ≤ 3

易错点：「大于取两边、小于取中间」这条口诀只在二次项系数为正时成立。 系数是负的就必须先乘 -1 调正，乘的时候别忘了把不等号翻个方向。

三、函数的概念与性质

例 6　用定义证明单调性

证明 f(x) = 1/x 在区间 (0, +∞) 上是减函数。

第一步：取值。在区间内任取两点，设 0 < x₁ < x₂。 这是定义法的固定开头，「任意」两个字不能省。

第二步：作差。

f(x₁) - f(x₂) = 1/x₁ - 1/x₂ = (x₂ - x₁) / (x₁x₂)

第三步：判断符号。由 x₁ < x₂ 得分子 x₂ - x₁ > 0； 由 x₁, x₂ > 0 得分母 x₁x₂ > 0。整个差式为正。

第四步：下结论。自变量大反而函数值小，按定义就是减函数。

答案：f(x₁) - f(x₂) > 0 即 f(x₁) > f(x₂)，故 f(x) 在 (0, +∞) 上为减函数

提醒：定义法证单调性就这四步——取值、作差、判号、结论，一步都不能少。 判号通常要靠因式分解，凑成几个「一眼能看出正负」的因子连乘。
例 7　与一次函数结合的最值应用

用长为 20 米的篱笆围一个靠墙的矩形菜园（墙那一侧不用篱笆），问长宽各为多少时面积最大。

第一步：设未知数。设垂直于墙的边长为 x 米，则平行于墙的边长为 20 - 2x 米。

第二步：写定义域。边长都必须是正数，所以 0 < x < 10。 这一步不能丢，后面判断等号能不能取到全靠它。

第三步：列面积函数。

S(x) = x(20 - 2x) = -2x² + 20x = -2(x - 5)² + 50

第四步：在定义域内求最值。这是开口向下的抛物线，顶点 x = 5 正好落在 (0, 10) 内，所以能取到顶点值。

答案：垂直墙的边长 5 米，平行墙的边长 10 米，最大面积 50 平方米

易错点：算出顶点后，一定回头确认顶点在不在定义域里。 如果本题改成篱笆长 12 米，顶点 x = 3 仍在范围内没问题；但若凑出个顶点在范围外的题， 就要改用端点或单调性了。这个套路和导数求最值完全一致。

四、指数函数与对数函数

例 8　底数小于 1 时的不等号反转

比较 0.8^(-0.1) 与 0.8^(-0.2) 的大小。

先判断用哪个函数。两个数底数都是 0.8，指数不同，所以看成同一个指数函数 y = 0.8^x 在不同自变量处的取值。

再看单调性。底数 0 < 0.8 < 1， 指数函数 单调递减：指数越大，函数值反而越小。

比较指数：-0.1 > -0.2，指数大的一方函数值小。

答案：0.8^(-0.1) < 0.8^(-0.2)

易错点：底数大于 1 时同向，底数小于 1 时反向。做题第一件事就是看底数落在哪一段， 千万别条件反射地按「指数大自然就大」来写。
例 9　对数运算律化简

计算 lg 25 + lg 4。

看结构。两个对数相加，同底数，正好对应运算律 log_a M + log_a N = log_a (MN)—— 加法对应真数相乘，这是最容易记反的一条。

lg 25 + lg 4 = lg (25 × 4) = lg 100

而 lg 是以 10 为底，100 = 10²， 所以由定义 lg 100 = 2。

答案：2

例 10　判断零点所在区间

证明方程 x³ + x - 1 = 0 在区间 (0, 1) 内至少有一个实根。

第一步：把方程变成函数。设 f(x) = x³ + x - 1， 那么方程的根就是 f(x) 的零点。

第二步：算区间两端的函数值。

f(0) = 0³ + 0 - 1 = -1 < 0 f(1) = 1³ + 1 - 1 = 1 > 0

第三步：用零点存在定理。f(x) 是多项式函数，在 R 上连续； 且两个端点函数值异号，满足定理条件，所以在 (0, 1) 内至少存在一个零点。

答案：f(0)·f(1) < 0 且 f(x) 连续，由零点存在定理得证

提醒：零点存在定理只是充分条件。 「两端异号 ⇒ 有零点」成立，但反过来「有零点 ⇒ 两端异号」不成立 （比如两端同为正也可能在中间穿过去再回来）。另外它只保证存在，不保证「只有一个」。

五、三角函数

例 11　由正弦值反求余弦值

已知 sin α = 3/5，且 α 是第二象限角，求 cos α 与 tan α。

第一步：用平方关系。由 sin²α + cos²α = 1 得 cos²α = 1 - 9/25 = 16/25，开方得 cos α = ±4/5。

第二步：靠象限定正负。这一步不能跳。α 在第二象限时， x 为负、y 为正，因此余弦为负、正弦为正。sin α = 3/5 为正，与题设吻合； 余弦取负号。

cos α = -4/5

第三步：用商数关系求正切。

tan α = sin α / cos α = (3/5) / (-4/5) = -3/4

答案：cos α = -4/5，tan α = -3/4

易错点：开方后出现的 ± 必须靠象限信息消掉。 如果题目不给象限，就要保留两种情况分类讨论，漏掉一种就是扣分。
例 12　诱导公式的应用

化简 sin(π + α) 与 cos(π/2 + α)。

口诀：奇变偶不变，符号看象限。 拆开看：把角写成 k·(π/2) ± α 的形式—— π 是 π/2 的 2 倍（偶数倍），所以函数名不变； π/2 是 1 倍（奇数倍），所以函数名要变（sin 变 cos）。

再定符号。把 α 当成第一象限的锐角，判断整体角落在哪个象限， 看原函数在该象限的正负：

  • π + α 落在第三象限（π 再加一点），第三象限正弦为负，故 sin(π+α) = -sin α。
  • π/2 + α 落在第二象限，第二象限余弦为负，故 cos(π/2+α) = -sin α。

答案：sin(π+α) = -sin α，cos(π/2+α) = -sin α

提醒：这两条结果只是诱导公式里的两个例子，不用死背。 记住「奇变偶不变，符号看象限」这十个字，任何 k·(π/2) ± α 都能现场推。
例 13　先伸缩后平移的坑

把 y = sin x 的图像先横向缩短为原来的 1/2， 再向左平移 π/3，求所得函数解析式。

第一步：横向伸缩。横向缩短为 1/2，就是把 x 换成 2x：

y = sin 2x

第二步：平移。「左加右减」是在 x 本身上加，不是在整个括号里加。 左移 π/3，就把 x 换成 x + π/3：

y = sin[2(x + π/3)] = sin(2x + 2π/3)

关键提醒：很多人会写成 sin(2x + π/3)， 这是错的——那样等于只平移了 π/6。 原因是 ω = 2 把平移量「压缩」了，先伸缩后平移时，平移量要除以 ω。

答案：y = sin(2x + 2π/3)

两种顺序对比：若改为先平移后伸缩，则先得到 sin(x + π/3)， 再把 x 换成 2x 得 sin(2x + π/3)。两条路的答案不同， 题目说哪种顺序就按哪种来，别混着套。

六、一元函数的导数及其应用

例 14　求切线方程（在点 P 处）

求曲线 y = x² 在点 P(1, 1) 处的切线方程。

第一步：求导。由公式 (x²)' = 2x。

第二步：求切线斜率。导数的几何意义就是切线斜率，把切点横坐标代进去：

k = f'(1) = 2 × 1 = 2

第三步：点斜式写方程。已知斜率 2、过点 (1, 1)：

y - 1 = 2(x - 1)　⟹　y = 2x - 1

答案：y = 2x - 1

易错点：「在点 P 处」与「过点 P」不是一回事。 「在点 P 处」说明 P 就是切点，直接代；「过点 P」只说直线经过 P， P 未必是切点，必须设切点坐标 (t, t²)， 写出切线方程后再代 P 的坐标反解 t，可能解出多个切点、多条切线。
例 15　求单调区间

求函数 f(x) = x³ - 3x 的单调区间。

第一步：求导并令其为零。

f'(x) = 3x² - 3 = 3(x² - 1) = 3(x-1)(x+1)

第二步：解不等式定符号区间。 令 f'(x) > 0：x < -1 或 x > 1； 令 f'(x) < 0：-1 < x < 1。

第三步：按「正增负减」读结论。导数为正就是增函数，导数为负就是减函数。

答案：单调递增区间为 (-∞, -1) 与 (1, +∞)，单调递减区间为 (-1, 1)

易错点：单调区间之间用逗号或「和」连接，绝对不能用并集符号 ∪。 因为函数在 x = -1 到 x = 1 之间是往下走的，两个递增段并不连成一片， 写成并集就从含义上错了。
例 16　闭区间上的最值（端点别忘算）

求函数 f(x) = x³ - 3x 在区间 [0, 3] 上的最大值与最小值。

第一步：找区间内的极值点。由上一题，f'(x) = 3(x-1)(x+1)， 导数为零的点是 x = 1 和 x = -1。但 -1 ∉ [0, 3]，舍去， 区间内只剩 x = 1 这个极值点。

第二步：把候选点全部算出来。候选 = 极值点 + 两个端点：

f(0) = 0 - 0 = 0 f(1) = 1 - 3 = -2 f(3) = 27 - 9 = 18

第三步：比大小。三个数里 18 最大、-2 最小。

答案：最大值 f(3) = 18，最小值 f(1) = -2

易错点：闭区间求最值，端点必须算。 很多人只算导数零点就下结论，结果漏掉端点。本题中最大值恰好在端点 x = 3 取到， 只算极值点就会得出「最大值是 -2」这种荒谬答案。记住公式：最值 = 极值点与端点一起比。
例 17　由单调性反求参数范围

已知 f(x) = x³ - ax 在区间 [1, +∞) 上是增函数，求 a 的取值范围。

第一步：把「增函数」翻译成导数条件。在 [1, +∞) 上递增， 等价于对区间内每个 x 都有 f'(x) ≥ 0。

f'(x) = 3x² - a ≥ 0

第二步：分离参数。把 a 单独挪到一边：

a ≤ 3x²　（对一切 x ≥ 1 恒成立）

第三步：求右边在区间上的最小值。要让 a ≤ 3x² 对区间内所有 x 都成立，a 就得小于等于 3x² 的最小值。 而 3x² 在 x ≥ 1 上递增，最小值在 x = 1 取到，为 3。

答案：a ≤ 3

等号能不能取？这里是「≥ 0」，允许导数为零的孤立点存在， 所以在 a = 3 时 f'(x) = 3x² - 3 只有在 x = 1 处为零，其余地方为正， 函数仍然是增函数。因此等号可以取。但如果题目要求的是「严格递增且导数处处不为零」， 就要重新掂量了——这类等号取舍是判卷的重点。
