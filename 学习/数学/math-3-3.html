第 3 章　圆锥曲线的方程

人教 A 版选择性必修第一册 · 3.1 – 3.3

先建立直觉：椭圆、双曲线、抛物线之所以被统称为「圆锥曲线」， 是因为它们都可以用平面去截一个圆锥面得到—— 截面角度不同，就得到不同的曲线。

但在中学里，我们用的是它们的第二定义（轨迹定义）： 椭圆是「到两定点距离之和为常数」的点的轨迹； 双曲线是「距离之差的绝对值为常数」； 抛物线是「到定点与到定直线距离相等」。 这三句话是全部性质的源头。

3.1 椭圆

定义

平面内到两个定点 F₁、F₂ 的距离之和等于常数 （大于 |F₁F₂|）的点的轨迹叫椭圆。 两定点叫焦点，两焦点间的距离叫焦距（记作 2c）。
定义中的限制条件「大于 |F₁F₂|」必须写。 若这个常数恰好等于 |F₁F₂|，轨迹是一条线段（F₁F₂ 之间的部分）； 若小于 |F₁F₂|，则轨迹不存在。

常数通常记作 2a，所以条件就是 2a > 2c， 即 a > c > 0。这也是为什么椭圆里恒有 b² = a² − c²。

标准方程

焦点在 x 轴上：

x²/a² + y²/b² = 1　（a > b > 0）

焦点 F₁(−c, 0)、F₂(c, 0)。

焦点在 y 轴上：

y²/a² + x²/b² = 1　（a > b > 0）

焦点 F₁(0, −c)、F₂(0, c)。

a 永远代表「大分母」对应的那个量。 判断焦点在哪条轴上，只需看哪个分母大： x² 的分母大 → 焦点在 x 轴；y² 的分母大 → 焦点在 y 轴。 不要死记「a² 在 x 项下面」这种说法，那是只对焦点在 x 轴时成立的。

几何性质

a² = b² + c²（这个关系与双曲线不同，务必区分）
离心率 e = c / a ∈ (0, 1)
长轴长 = 2a，短轴长 = 2b，焦距 = 2c

离心率的几何意义：e 越接近 0，椭圆越圆； e 越接近 1，椭圆越扁。

椭圆的离心率一定小于 1，这也是「椭圆」名称的由来（比 1 小）。 若算出 e ≥ 1，一定是算错了。

顶点：焦点在 x 轴时有四个顶点 (±a, 0) 与 (0, ±b)。 注意 (a, 0) 与 (−a, 0) 是长轴的端点，而焦点 (±c, 0) 在它们之间。

3.2 双曲线

定义

平面内到两个定点 F₁、F₂ 的距离之差的绝对值等于常数 （小于 |F₁F₂| 且大于 0）的点的轨迹叫双曲线。
两个限制条件都不能少：
「绝对值」——不加绝对值，得到的只是双曲线的一支；
「小于 |F₁F₂|」——若大于，轨迹不存在；若等于，轨迹是两条射线。

所以条件是 0 < 常数 < 2c，即 0 < a < c。 由此得双曲线中 b² = c² − a²。

标准方程

x²/a² − y²/b² = 1　（焦点在 x 轴）
y²/a² − x²/b² = 1　（焦点在 y 轴）
双曲线的判断口诀与椭圆相反： 「哪一项前面是正号，焦点就在哪条轴上」， 而不是看分母大小。因为双曲线方程里两项前必然一正一负。

另一个必须记牢的区别：双曲线中 c 最大 （c² = a² + b²）， 而椭圆中 a 最大（a² = b² + c²）。 两者的公式长得像，但谁是「最大者」正好相反，这是最经典的混淆点。

几何性质

c² = a² + b²
离心率 e = c / a ∈ (1, +∞)
渐近线：x²/a² − y²/b² = 1 的渐近线为 y = ±(b/a)x
实轴长 = 2a，虚轴长 = 2b
渐近线公式的速记法：把方程右边的 1 换成 0， 即 x²/a² − y²/b² = 0， 移项开方就得 y = ±(b/a)x。 这个方法不需要背，现场推即可。

双曲线的离心率一定大于 1。 若 e 越接近 1，渐近线越「靠近坐标轴」，双曲线的开口越窄； 若 e 越大，开口越宽。

等轴双曲线

当 a = b 时，双曲线叫等轴双曲线， 此时渐近线为 y = ±x（互相垂直）， 离心率 e = √2。

等轴双曲线可以写成 x² − y² = k（k ≠ 0）这种形式。 答「渐近线互相垂直」或「离心率为 √2」都能反推出是等轴双曲线， 这是常用的一步转化。

3.3 抛物线

定义

平面内与一个定点 F 和一条定直线 l （F 不在 l 上）的距离相等的点的轨迹叫抛物线。 定点 F 叫焦点，定直线 l 叫准线。
定义中「F 不在 l 上」这个条件很重要。 若 F 恰好在 l 上，轨迹将是一条过 F 且垂直于 l 的直线。

四种标准方程

y² = 2px（p > 0）
开口向右。焦点 (p/2, 0)， 准线 x = −p/2。
y² = −2px（p > 0）
开口向左。焦点 (−p/2, 0)， 准线 x = p/2。
x² = 2py（p > 0）
开口向上。焦点 (0, p/2)， 准线 y = −p/2。
x² = −2py（p > 0）
开口向下。焦点 (0, −p/2)， 准线 y = p/2。
抛物线里 p 的含义是「焦点到准线的距离」，这一点务必记牢。 所以焦点坐标是 ±p/2，准线是 ∓p/2， 两者到原点的距离都是 p/2，加起来正好是 p。

判断开口方向：看一次项的符号。 一次项是正号，开口朝该轴的正方向。

抛物线的离心率

e = 1
抛物线的离心率恒为 1， 这正好把三类圆锥曲线统一起来了： 椭圆 0 < e < 1， 抛物线 e = 1， 双曲线 e > 1。 这就是圆锥曲线的统一定义（到焦点与到准线的距离之比等于 e）。

3.4 圆锥曲线的综合

通法：直线与圆锥曲线联立

处理「直线与圆锥曲线相交，求弦长、中点、面积」这类问题的标准流程：

第一步，设直线方程。若直线斜率可能不存在，先讨论。 更稳妥的做法是设 x = my + t 或直接用一般式，避免分类。

第二步，与曲线方程联立，消元得到一元二次方程。

第三步，验证 Δ > 0（保证有两个交点）。

第四步，用韦达定理写出 x₁ + x₂ 与 x₁x₂。

第五步，把所求量（弦长、中点坐标、面积）用 x₁ + x₂ 和 x₁x₂ 表示。

弦长 |AB| = √(1 + k²) · √[(x₁+x₂)² − 4x₁x₂]
中点坐标：((x₁+x₂)/2, (y₁+y₂)/2)
这套「设—联—判—韦—代」五步法是圆锥曲线大题的通用框架， 几乎所有压轴题的解答过程都是它的变形。 核心思想是「设而不求」——不必真的解出 x₁、x₂， 只要知道它们的和与积就够用。

请务必养成写 Δ > 0 的习惯， 很多题目的隐含条件（如「斜率范围」「参数范围」）正是由它提供的。

焦点三角形

对椭圆，设 P 为椭圆上一点， ∠F₁PF₂ = θ， 则焦点三角形的面积

S = b² · tan(θ/2)

对双曲线，对应公式为

S = b² / tan(θ/2)
两个公式一个是「乘 tan」一个是「除 tan」， 正好互为倒数关系。记的时候可以只记椭圆的， 然后记住「双曲线是它的倒数」。 这两个公式能大幅缩短焦点三角形类问题的计算。

抛物线的焦点弦

对抛物线 y² = 2px， 若过焦点的弦 AB 与 x 轴的夹角为 θ，则

|AB| = 2p / sin²θ

特别地，当弦垂直于对称轴（通径）时 θ = 90°， 此时

通径长 = 2p（这是过焦点的最短弦）
还有两条常用的焦点弦性质：
其一，焦点弦两端点横坐标之积为定值 x₁x₂ = p²/4；
其二，以焦点弦为直径的圆与准线相切。
这些「定值」结论在选择题里能直接用，省去大量计算。
例 1

已知椭圆 x²/25 + y²/9 = 1， 求它的焦点坐标、离心率，并判断形状的「扁圆」程度。

解答

因为 x² 的分母 25 大于 y² 的分母 9， 所以焦点在 x 轴上，且

a² = 25, b² = 9

由 a² = b² + c² 得

c² = 25 − 9 = 16，所以 c = 4。

焦点坐标为 (4, 0) 和 (−4, 0)；

离心率 e = c/a = 4/5 = 0.8；

长轴长 2a = 10，短轴长 2b = 6。

因为 e = 0.8 比较接近 1，所以这个椭圆比较扁—— 长轴 10、短轴 6，长短相差明显，视觉上确实扁平。

验算：a > b > 0 成立，且 a > c 成立， 符合椭圆的基本条件。

例 2

已知双曲线 x²/9 − y²/16 = 1， 求它的焦点坐标、渐近线与离心率。

解答

x² 项前面是正号，所以焦点在 x 轴上，且

a² = 9, b² = 16

双曲线中 c² = a² + b² = 9 + 16 = 25， 所以 c = 5。

焦点坐标为 (5, 0) 和 (−5, 0)。

渐近线：把右边的 1 改成 0， x²/9 − y²/16 = 0， 即 y² = (16/9)x²， 所以渐近线为

y = ±(4/3)x

离心率 e = c/a = 5/3 ≈ 1.667。

结论：因为 a = 3, b = 4 不相等， 不是等轴双曲线，所以 e ≠ √2 ≈ 1.414， 与算出的 1.667 一致，逻辑自洽。

易错点速查

其一，椭圆中 a² = b² + c²（a 最大）； 双曲线中 c² = a² + b²（c 最大）。 两者公式形式相似但「谁最大」相反，这是最高频的混淆点。

其二，判断椭圆焦点位置看分母大小（大分母对应 a，焦点在其轴上）； 判断双曲线焦点位置看一次项正负（正的那一项决定焦点所在轴）。 两套判断法不能互换。

其三，椭圆离心率 e < 1， 双曲线 e > 1， 抛物线 e = 1。 如果算出的 e 落在错误的区间，说明前面的参数一定搞错了，要立即回头检查。

其四，双曲线定义中的「绝对值」不能丢， 否则只能得到一支，会漏掉整整一半的曲线。

其五，抛物线定义中要保证定点不在定直线上， 否则轨迹退化为一条直线。

其六，做直线与圆锥曲线的题时， 别忘了写 Δ > 0。 这不仅是得分点，往往也是题目隐含条件的来源。
