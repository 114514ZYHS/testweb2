第 2 章　直线和圆的方程

人教 A 版选择性必修第一册 · 2.1 – 2.5

先建立直觉：这一章做的事情是把几何图形翻译成方程。 一条直线，用「y = kx + b」表示；一个圆，用「(x−a)² + (y−b)² = r²」表示。

一旦有了方程，几何问题就变成了代数问题： 求交点就是解方程组，求距离就是代公式，判断位置关系就是看判别式。 这套方法叫解析几何，是笛卡尔和费马在 17 世纪创立的， 它把「看图」变成了「算数」，是中学数学中最有威力的工具之一。

2.1 直线的倾斜角与斜率

倾斜角

直线向上的方向与 x 轴正方向所成的角叫倾斜角，记作 α， 取值范围是

α ∈ [0°, 180°)
倾斜角的取值范围包含 0° 但不含 180°。 α = 0° 对应水平直线。 若范围里含了 180°，那么水平直线将有两个倾斜角，就不唯一了。

斜率

k = tan α（α ≠ 90°）
过两点 P₁(x₁,y₁)、P₂(x₂,y₂)：k = (y₂ − y₁) / (x₂ − x₁)（x₁ ≠ x₂）
α = 90° 时斜率不存在（不是「斜率为 0」， 也不是「斜率为无穷大」）。很多题目会特意设置竖直直线来考察这一点， 用斜率式设直线方程时必须单独讨论「斜率不存在」的情形， 否则会漏解。这是解析几何最经典的失分点。

2.2 直线的方程

点斜式
y − y₀ = k(x − x₀)
不能表示斜率不存在的直线。
斜截式
y = kx + b
b 是纵截距（可为负）。同样不能表示竖直直线。
两点式
(y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁)
不能表示与坐标轴平行的直线。
截距式
x/a + y/b = 1
不能表示过原点及与坐标轴平行的直线。
一般式
Ax + By + C = 0（A、B 不同时为 0）
能表示所有直线，包括竖直直线。
每种形式都有「不能表示的直线」，这在设方程时必须考虑。 最稳妥的做法是用一般式， 或者「先讨论斜率不存在的情形，再设斜率为 k 求解」。

另一个细节：截距式中的 a、b 是截距，可以是任意实数（含负数）， 不是「距离」。所以「截距相等」不等于「截距的绝对值相等」。

2.3 直线的交点坐标与距离公式

两直线的位置关系

设 l₁: A₁x + B₁y + C₁ = 0， l₂: A₂x + B₂y + C₂ = 0：

相交 ⇔ A₁B₂ − A₂B₁ ≠ 0
平行 ⇔ A₁B₂ − A₂B₁ = 0 且 A₁C₂ − A₂C₁ ≠ 0
重合 ⇔ A₁B₂ − A₂B₁ = 0 且 A₁C₂ − A₂C₁ = 0

若用斜率形式表达，则更直观：

平行 ⇔ k₁ = k₂ 且 b₁ ≠ b₂
垂直 ⇔ k₁ · k₂ = −1（或一条斜率为 0、另一条斜率不存在）

距离公式

两点间距离：|P₁P₂| = √[(x₂−x₁)² + (y₂−y₁)²]
点到直线距离：d = |Ax₀ + By₀ + C| / √(A² + B²)
两平行线间距离：d = |C₁ − C₂| / √(A² + B²)
用两平行线距离公式前，必须先把两方程的 x、y 系数化为相同。 比如 x + y + 1 = 0 与 2x + 2y + 5 = 0， 要先把第二个化成 x + y + 2.5 = 0， 才能代入 |C₁ − C₂| = |1 − 2.5| = 1.5。 直接代入会得到错误结果。

对称问题

点关于点的对称：中点公式反用即可。

点关于直线的对称：设对称点为 P′(x′, y′)，则需满足两个条件——

其一，PP′ 的中点在对称轴上； 其二，PP′ 与对称轴垂直（斜率乘积为 −1）。

联立可解出 P′。这是一个「两方程两未知数」的固定套路。

直线系

过定点 (x₀, y₀) 的直线系：y − y₀ = k(x − x₀)（不含竖直直线）。

过两直线 l₁ = 0、l₂ = 0 交点的直线系：

A₁x + B₁y + C₁ + λ(A₂x + B₂y + C₂) = 0
这个「直线系」技巧在求「过两直线交点且满足某条件的直线」时非常好用， 能避免先求交点坐标的繁琐计算。 但要注意它不包含 l₂ 本身，所以若答案恰好是 l₂，需要单独说明。
例 1

求点 P(2, 3) 到直线 3x + 4y − 5 = 0 的距离。

解答

代入点到直线的距离公式，其中 A = 3, B = 4, C = −5, x₀ = 2, y₀ = 3：

d = |3×2 + 4×3 − 5| / √(3² + 4²)

= |6 + 12 − 5| / √25 = 13 / 5 = 2.6

所以距离为 2.6。

提示：分母 √(A² + B²) = 5 正好是「3-4-5」直角三角形， 这类题经常设计成整数结果，可以用来快速检查自己的计算。

2.4 圆的方程

标准方程

(x − a)² + (y − b)² = r²　（圆心 (a,b)，半径 r > 0）

一般方程

x² + y² + Dx + Ey + F = 0

把它配方可得

(x + D/2)² + (y + E/2)² = (D² + E² − 4F) / 4

所以它是一个圆的充要条件是

D² + E² − 4F > 0

此时圆心为 (−D/2, −E/2)， 半径 r = ½√(D² + E² − 4F)。

「x² + y² + Dx + Ey + F = 0 一定是圆」是错的。 必须满足 D² + E² − 4F > 0； 若等于 0，则是一个点（点圆）； 若小于 0，则没有任何图形。 另外还要注意系数：一般方程要求 x² 与 y² 的系数相等且不为 0， 像 x² + 2y² + … 表示的是椭圆，不是圆。

确定圆的方程：待定系数法

已知圆心用标准方程（两个参数 a、b，加上 r 共三个）； 已知圆上三点用一般方程（三个参数 D、E、F）。

2.5 直线与圆、圆与圆的位置关系

直线与圆

判断方法：比较圆心到直线的距离 d 与半径 r。

d > r：相离（无公共点）
d = r：相切（一个公共点）
d < r：相交（两个公共点）
也可以用「判别式法」：把直线代入圆的方程得到一元二次方程， 看 Δ 的正负。但几何法（用 d 与 r 比较）通常更简单， 因为它避免了开方和判别式计算。只有需要求交点坐标时才用代数法。

弦长公式

弦长 |AB| = 2√(r² − d²)
这是由勾股定理直接得到的（圆心到弦的距离、半径、半弦长构成直角三角形）。 它是解决弦长问题的首选公式，比用两点间距离公式快得多。

如果必须用坐标算，弦长公式还有另一个形式： |AB| = √(1 + k²) · |x₁ − x₂|， 其中 k 是直线斜率，x₁, x₂ 是两交点的横坐标。

切线与切点弦

过圆外一点 P(x₀, y₀) 作圆 x² + y² = r² 的切线， 则两切点连线（切点弦）的方程为

x₀x + y₀y = r²
这个结论的来历是「极线」理论，但中学只需直接使用。 注意区分：过圆上一点的切线方程也是同一个形式 x₀x + y₀y = r²， 所以两者公式相同，只是 P 在圆外时表示的是「切点弦」而非切线。

圆与圆的位置关系

设两圆半径为 r₁、r₂（r₁ ≥ r₂），圆心距为 d：

d > r₁ + r₂：外离
d = r₁ + r₂：外切
|r₁ − r₂| < d < r₁ + r₂：相交
d = |r₁ − r₂|：内切
d < |r₁ − r₂|：内含（含同心圆）

两圆的公共弦：把两圆方程相减， 消去 x² 和 y² 项，得到的直线方程就是公共弦所在直线。

「两圆方程相减得到公共弦」这个技巧非常实用， 省去了求两个交点再连线的麻烦。 原理是：两圆方程都满足的点，必然也满足它们的差； 而这个差是一个一次方程，所以交点都在直线上。
例 2

已知圆 C: x² + y² − 4x + 2y − 4 = 0， 求圆心坐标与半径。

解答

配方：把 x 的项配成完全平方，y 的项也配成完全平方。

x² − 4x + 4 + y² + 2y + 1 = 4 + 4 + 1

即

(x − 2)² + (y + 1)² = 9

所以圆心为 (2, −1)，半径 r = 3。

用一般方程的公式交叉检验： D = −4, E = 2, F = −4， 圆心 (−D/2, −E/2) = (2, −1)，与配方结果一致；

D² + E² − 4F = 16 + 4 + 16 = 36 > 0， 确实是圆，半径 r = ½√36 = 3，一致。

易错点速查

其一，设直线方程时忘记讨论「斜率不存在」，导致漏解。 这是解析几何最常见的失分原因。

其二，判断两直线平行时，用 k₁ = k₂ 还不够，必须再加「不在同一条直线上」， 否则可能是重合。若用一般式则要同时检查两对行列式。

其三，「截距相等」包括「截距都为零」的情形， 此时直线过原点，容易被漏掉。

其四，用点斜式设直线时，要注意所设直线是否可能竖直。 遇到「过某点的切线」这类问题，更要注意「斜率不存在的直线也可能是切线」。

其五，圆的一般方程别忘了检验 D² + E² − 4F > 0。 求出 D、E、F 后要回头检查这个条件， 否则可能解出「不是圆的方程」。
