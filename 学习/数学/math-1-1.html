第 1 章 集合与常用逻辑用语

人教 A 版必修第一册 · 1.1 – 1.5

这是高中数学的第一章，也是整本书的语言基础。它不教你怎么算，而是教你怎么准确地说——把「所有」「存在」「当且仅当」这些话说清楚。

1.1 集合的概念

定义：把一些确定的、不同的对象看成一个整体，这个整体就是一个集合（简称集）， 其中的每个对象叫做这个集合的元素。

元素的三个特性（判断是不是集合就看这三条）：

  • 确定性——一个对象在不在集合里，必须是明确的。所以「我们班个子高的同学」不是集合，「我们班身高超过 175cm 的同学」才是。
  • 互异性——同一个集合里不能有重复元素，{1, 1, 2} 实际就是 {1, 2}。
  • 无序性——{1, 2, 3} 和 {3, 2, 1} 是同一个集合。

元素与集合的关系

只有两种，用专门的符号：

  • a ∈ A —— a 是集合 A 的元素，读作「a 属于 A」
  • a ∉ A —— a 不是集合 A 的元素，读作「a 不属于 A」

常用数集记法（必须记牢）

符号名称说明
N自然数集0, 1, 2, 3, …
N* 或 N₊正整数集1, 2, 3, …（不含 0）
Z整数集…, −2, −1, 0, 1, 2, …
Q有理数集能写成分数形式的数
R实数集数轴上所有点对应的数
极易错：0 是自然数（0 ∈ N），但 0 不是正整数（0 ∉ N*）。 另外 0 ∈ R、0 ∈ Z、0 ∈ Q 都成立。

集合的表示方法

  • 列举法——把元素一一列出，如 {1, 3, 5, 7}。适合元素少的情况。
  • 描述法——写清元素的共同特征，格式是 {x | x 满足的条件}。
    例如 {x | x > 2} 表示所有大于 2 的实数。
  • 区间记法——用括号表示范围：(a, b) 开区间、[a, b] 闭区间、(a, b] 半开半闭。
关于区间的三个要点：
① 无穷大一侧永远是开的：(a, +∞)，不能写成 [a, +∞)。
② 「∞」不是数，只表示趋势，所以不能参与运算。
③ {x | x > 2} 和 (2, +∞) 是同一个集合的两种写法。

1.2 集合间的基本关系

子集：如果集合 A 中任意一个元素都是集合 B 的元素，就说 A 是 B 的子集， 记作 A ⊆ B（读作 A 含于 B，或 B 包含 A）。

真子集：如果 A ⊆ B，且 B 中至少有一个元素不属于 A， 就说 A 是 B 的真子集，记作 A ⊊ B。

相等：如果 A ⊆ B 且 B ⊆ A，则 A = B。
两个必须记住的特殊情况：
① 空集（∅）是任何集合的子集，即 ∅ ⊆ A 对任意集合 A 都成立。
② 任何集合都是它自己的子集，A ⊆ A。

最大的陷阱：讨论子集问题时漏掉 ∅。 题目说「A ⊆ B」，你分情况时如果只考虑了 A 非空，就会丢分。

子集个数的规律

如果一个集合有 n 个元素：

  • 子集个数：2ⁿ 个
  • 真子集个数：2ⁿ − 1 个（去掉它自己）
  • 非空真子集个数：2ⁿ − 2 个（去掉它自己和空集）
例 1

集合 A = {a, b, c} 有多少个子集？多少个真子集？

解：n = 3，所以子集有 2³ = 8 个。

真子集有 2³ − 1 = 7 个。

（可以数一下验证：∅、{a}、{b}、{c}、{a,b}、{a,c}、{b,c}、{a,b,c}，正好 8 个。）

1.3 集合的基本运算

交集：A ∩ B = {x | x ∈ A 且 x ∈ B}——两边的公共部分。

并集：A ∪ B = {x | x ∈ A 或 x ∈ B}——两边的全部（重复的只算一次）。

补集：如果 A 是全集 U 的子集，则 ∁UA = {x | x ∈ U 且 x ∉ A}—— U 里不属于 A 的那些元素。
记法提示：交集符号 ∩ 的形状像「门」，取的是「同时进去」的部分； 并集符号 ∪ 像「碗」，什么都能装。

三个重要性质

  • A ∩ A = A，A ∪ A = A
  • A ∩ ∅ = ∅，A ∪ ∅ = A
  • A ∩ ∁UA = ∅，A ∪ ∁UA = U（A 和它的补集正好把全集分完）
例 2

设 U = {1, 2, 3, 4, 5}，A = {1, 3, 5}，B = {2, 3, 4}。求 A ∩ B、A ∪ B、∁UA。

解：

A 和 B 都有的元素是 3，所以 A ∩ B = {3}

两边的元素全并起来：1, 3, 5, 2, 4，所以 A ∪ B = {1, 2, 3, 4, 5}（正好是 U）

U 里不属于 A 的是 2 和 4，所以 ∁UA = {2, 4}

答案：{3}；{1,2,3,4,5}；{2,4}

例 3（连续型集合，画数轴最稳）

设 A = {x | −1 < x ≤ 3}，B = {x | x > 1}，求 A ∩ B。

解：把两个区间画在数轴上找重叠部分。

A 是 (−1, 3]，B 是 (1, +∞)。两者的公共部分是 1 < x ≤ 3。

所以 A ∩ B = {x | 1 < x ≤ 3}，即 (1, 3]。

要点：端点要小心。x = 1 属于 B（因为 B 是 x > 1），但不属于 A？
不对——A 是 −1 < x ≤ 3，1 确实在 A 里。但 B 要求 x > 1，不含 1， 所以 1 不在交集里，左端取开。

连续型集合的通用方法：画数轴。把每个区间画出来，交集看重叠，并集看覆盖， 补集看「全集里挖掉的部分」。端点用实心点（含）和空心点（不含）标清楚， 端点是最容易出错的地方。

1.4 充分条件与必要条件

设命题「若 p，则 q」：
如果 p 成立能推出 q 成立（记作 p ⇒ q），就说 p 是 q 的充分条件。
如果 q 成立能推出 p 成立（记作 q ⇒ p），就说 p 是 q 的必要条件。
如果既有 p ⇒ q 又有 q ⇒ p，就说 p 是 q 的充要条件，记作 p ⇔ q。
怎么记才不混：
「充分」= 有这个就够了（足够推出对方）
「必要」= 没有这个就不行（少了它对方不成立）

举个例子：「x > 3」是「x > 1」的什么条件？
x > 3 一定能推出 x > 1，所以是充分条件；
但 x > 1 不一定推出 x > 3（比如 x = 2），所以不是必要条件。
结论：充分不必要条件。

四种情况

把两个方向分开验证，就能定出是哪种条件：

  • p ⇒ q 成立，且 q ⇒ p 也成立 → 充要条件
  • p ⇒ q 成立，但 q ⇒ p 不成立 → 充分不必要条件
  • p ⇒ q 不成立，但 q ⇒ p 成立 → 必要不充分条件
  • 两个方向都不成立 → 既不充分也不必要条件

集合视角（判断起来更快）

设 p 对应集合 A，q 对应集合 B：

  • 若 A ⊆ B，则 p 是 q 的充分条件（A 小，B 大，小的能推出大的）
  • 若 A ⊇ B，则 p 是 q 的必要条件
  • 若 A = B，则 p 是 q 的充要条件
一句话记忆：小范围能推出大范围，大范围推不出小范围。 「x > 3」的范围比「x > 1」小，所以前者能推出后者。

1.5 全称量词与存在量词

全称量词：符号 ∀，表示「所有」「任意一个」。 含全称量词的命题叫全称量词命题，如 ∀x ∈ R, x² ≥ 0。

存在量词：符号 ∃，表示「存在」「至少有一个」。 含存在量词的命题叫存在量词命题，如 ∃x ∈ R, x² = 1。

命题的否定（这里是重点）

两条规则：
① 全称命题的否定是存在命题：¬(∀x ∈ M, p(x)) ⇔ ∃x ∈ M, ¬p(x)
② 存在命题的否定是全称命题：¬(∃x ∈ M, p(x)) ⇔ ∀x ∈ M, ¬p(x)

通俗地说：「全都对」的否定是「至少有一个不对」；「存在对的」的否定是「全都不对」。

例 4

写出下列命题的否定，并判断真假：

（1）∀x ∈ R, x² > 0

（2）∃x ∈ R, x² + 1 = 0

解（1）：否定为 ∃x ∈ R, x² ≤ 0。

取 x = 0，则 0² = 0 ≤ 0 成立，所以否定后的命题是真的。

（其实原命题本身就是假的，因为 x = 0 时 x² = 0，不满足 > 0。）

解（2）：否定为 ∀x ∈ R, x² + 1 ≠ 0。

因为对任意实数 x，都有 x² ≥ 0，所以 x² + 1 ≥ 1 > 0，确实不等于 0。

所以否定后的命题是真的。（原命题是假的，因为在实数范围内方程无解。）

关键：否定时量词要变（∀ ↔ ∃），后面的结论也要取反。

最容易犯的错：只改量词忘了改结论，或者只改结论忘了改量词。
以「∀x, x² > 0」为例，正确的否定是「∃x, x² ≤ 0」，不是「∃x, x² > 0」。
注意 > 的否定是 ≤（不是 <），这一点也要留心。
本章小结：这一章是整个高中数学的语言层。集合用来描述范围，逻辑用语用来精确表达条件关系； 以后每一章都会用到它们（尤其是不等式、函数、导数里求参数范围的题）。 「充分必要」和「命题否定」这两块，几乎每年都考。
