第 1 章　空间向量与立体几何

人教 A 版选择性必修第一册 · 1.1 – 1.4

先建立直觉：必修二学立体几何，靠的是「找辅助线、证平行垂直」， 思路灵活但很难标准化。这一章要做的，是把立体几何彻底代数化—— 引入空间直角坐标系后，所有的「垂直」「平行」「夹角」「距离」 都变成了坐标和向量运算，不再依赖图形直觉。

代价是要算，但好处是思路固定、步骤机械、不容易做错。 高考的立体几何大题，绝大多数都可以用这套方法解决。

1.1 空间向量及其运算

基本概念

空间向量的定义与平面向量一样（有大小和方向）， 运算也完全相同：加法、减法、数乘、数量积。 所有在平面内成立的运算律，在空间中同样成立。

唯一的显著差别是：空间中任意两个向量总是共面的 （因为两个向量可以平移到同一个平面内）， 所以「向量的共面」是相对于三个向量而言的。

共面定理

p 与 a、b 共面 ⇔ 存在唯一的有序实数组 (x, y)，使 p = xa + yb

其中要求 a、b 不共线。

这个定理是「用两个基底表示第三个向量」的依据， 与平面向量基本定理的形式完全一致。 在空间中共面定理用来证明「四点共面」： 若 OP→ = x OA→ + y OB→ + z OC→ 且 x + y + z = 1，则 P、A、B、C 四点共面。 这个「系数和为 1」的结论与必修二中三点共线的判定完全平行。

空间向量的坐标运算

设 a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)：

a · b = x₁x₂ + y₁y₂ + z₁z₂
|a| = √(x₁² + y₁² + z₁²)
a ∥ b ⇔ x₁ = λx₂, y₁ = λy₂, z₁ = λz₂（λ 存在）
a ⊥ b ⇔ x₁x₂ + y₁y₂ + z₁z₂ = 0
cos⟨a, b⟩ = (a · b) / (|a|·|b|)
空间情形与平面情形完全平行，只是多了一个 z 分量。 记忆上不需要单独背——把平面公式每一处都「多加一项 z」即可。

1.2 空间向量基本定理

若 a、b、c 三个向量不共面，则对任意向量 p，存在唯一有序实数组 (x, y, z)，使 p = xa + yb + zc

这样的一组 {a, b, c} 叫空间的一个基底， x、y、z 叫 p 在这组基底下的坐标。

特别地，若基底是两两垂直的单位向量 i, j, k，则它们构成标准正交基， 此时的坐标就是空间直角坐标系中的坐标。

1.3 空间向量及其运算的坐标表示

建立空间直角坐标系

过原点 O 作三条互相垂直的数轴，分别叫 x 轴、y 轴、z 轴， 且 x、y、z 轴按右手系规则排列： 右手四指从 x 轴正方向弯向 y 轴正方向时，拇指指向 z 轴正方向。

建立坐标系是解题的第一步，也是最关键的一步。 常用技巧：把坐标原点放在图形中三条两两垂直的线段的公共端点处。 在正方体、长方体、直三棱柱、正四棱锥里， 这个公共点通常选在「底面的一个顶点」或「底面的中心」。

如果题目没有现成的三条两两垂直的线段， 那就需要自己作辅助线（比如「取中点，连中点」来构造垂直）。

坐标公式汇总

已知 A(x₁,y₁,z₁)、B(x₂,y₂,z₂)，则 AB→ = (x₂−x₁, y₂−y₁, z₂−z₁)
|AB→| = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
中点坐标：((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)

1.4 空间向量的应用

法向量

平面的法向量：与平面垂直的非零向量。 一个平面的法向量有无穷多个（都是互相平行的）， 但「方向」只有两种（正、反）。

求法向量的步骤：

其一，在平面内找两个不共线的向量，比如 AB→ 和 AC→。

其二，设法向量 n = (x, y, z)， 列出方程组

n · AB→ = 0　且　n · AC→ = 0

其三，令其中一个分量等于某个方便的值（常用 1），解出另外两个。

解方程组时有一个未知量是自由的， 所以可以令 x = 1（或 y = 1、z = 1）来定出一个特解。 但如果三条方程解出来 x 的系数恒为 0 导致 x 无法取 1 （即 x 分量本身必须为 0），那就改令 y = 1。 另外，法向量不需要是单位向量，取整数值最好算。

用向量证平行

a ∥ b ⇔ 存在 λ 使 a = λb

证线面平行：设直线的方向向量为 d， 平面的法向量为 n，则

d · n = 0（且直线不在平面内）⇔ 直线与平面平行

证面面平行：两个平面的法向量平行，即 n₁ = λn₂。

用向量证垂直

证线线垂直：d₁ · d₂ = 0
证线面垂直：d = λn（方向向量与法向量平行）
证面面垂直：n₁ · n₂ = 0
证线面垂直时用「方向向量与法向量平行」是最省事的做法， 比在平面内找两条相交直线分别证明要快得多。 但要注意检查直线确实与平面相交—— 方向向量平行于法向量只说明「直线垂直于平面」或「直线在平面外」，还需要说明交点存在。

用向量求空间角（重点）

异面直线所成角 θ ∈ (0°, 90°]：cos θ = |cos⟨d₁, d₂⟩| = |d₁·d₂| / (|d₁||d₂|)
线面角 θ ∈ [0°, 90°]：sin θ = |cos⟨d, n⟩| = |d·n| / (|d||n|)
二面角 θ ∈ [0°, 180°]：cos θ = cos⟨n₁, n₂⟩ = (n₁·n₂) / (|n₁||n₂|)（需判断正负）
这三条是立体几何大题的命脉，务必区分清楚：
线线角用 cos，并且要加绝对值（因为取锐角）；
线面角用 sin（不是 cos！），也要加绝对值；
二面角用 cos，但要看图判断是钝角还是锐角， 不能盲目取绝对值。

为什么线面角用 sin？因为方向向量与法向量的夹角 和直线与平面的夹角互余， 所以 cos⟨d, n⟩ = sin θ。 理解了这一点就不会记错。

用向量求距离

点 P 到平面 α 的距离：d = |AP→ · n| / |n|（A 为平面内任一点，n 为法向量）
异面直线间的距离：转化为点面距
例 1

正方体 ABCD-A₁B₁C₁D₁ 的棱长为 2。 建立坐标系求直线 A₁C 与平面 ABCD 所成角的正弦值。

解答

第一步，建系。以 D 为原点， DA 为 x 轴，DC 为 y 轴，DD₁ 为 z 轴，棱长为 2，则

A₁(2, 0, 2)，C(0, 2, 0)

所以 A₁C→ = (0 − 2, 2 − 0, 0 − 2) = (−2, 2, −2)。

第二步，求平面 ABC 的法向量。 底面 ABCD 在 z = 0 平面上，所以法向量为

n = (0, 0, 1)

第三步，套线面角公式。

sin θ = |d · n| / (|d| |n|)

d · n = (−2)(0) + (2)(0) + (−2)(1) = −2

|d| = √(4 + 4 + 4) = 2√3，|n| = 1

所以 sin θ = 2 / (2√3) = 1/√3 = √3/3 ≈ 0.577， 对应角度约 35.3°。

验算：用必修二的几何方法。 A₁C 是体对角线，长为 2√3； A₁ 到底面的距离为 2。所以

sin θ = 2 / (2√3) = √3/3

两种方法结果一致。这也说明了一个好习惯： 能用几何直觉快速验算的题，就用向量算完之后顺手验一遍， 能极大降低计算失误率。

易错点速查

其一，线面角用 sin，二面角用 cos，绝不能混。 这是本章最集中的失分点。

其二，二面角的余弦值可能为负， 不要把结果一律取绝对值——那样会丢掉「钝角二面角」的信息。

其三，求法向量时方程组的解不唯一， 但方向只差一个符号。做题时可以任选一个， 只是要保证后面判断夹角时前后一致（比如都用同一个法向量， 或都换成单位法向量）。

其四，建系时必须说明「三条轴两两垂直」的依据， 不能凭空假设。若图形本身不含三线垂直结构， 要先作辅助线并证明垂直关系。

其五，用向量证明平行时， 「直线不在平面内」这个条件必须补充说明， 否则会犯逻辑漏洞。
