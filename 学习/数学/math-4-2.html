第 7 章　随机变量及其分布

人教 A 版选择性必修第三册 · 7.1 – 7.5

先建立直觉：必修二学的概率是「某个事件发生的可能性」， 但那只是一个数。这一章要做的是更进一步—— 把随机试验的结果用数值表示出来，然后用一个「分布」来描述它。

比如掷两枚骰子，「点数之和」这个量会取 2 到 12 之间的整数值， 每个值对应一个概率。把「取值 + 概率」全部列出来， 就是这个随机变量的分布列。有了分布列， 就能算出它的平均值（期望）和波动程度（方差）。

7.1 条件概率与全概率公式

条件概率

P(B | A) = P(A ∩ B) / P(A)　（P(A) > 0）

读作「在 A 发生的条件下 B 发生的概率」。

条件概率的关键在于「样本空间变了」。 求 P(B|A) 时， 我们只关心 A 发生的情况， 所以分母从「整个样本空间的概率」换成了 P(A)—— 相当于把样本空间缩小到 A。

一个非常常见的错误是把 P(B|A) 与 P(A|B) 混为一谈， 这两者在数值上一般完全不同。 比如「知道一个人戴眼镜，他数学好的概率」 与「知道一个人数学好，他戴眼镜的概率」显然不是一回事。

乘法公式

P(A ∩ B) = P(A) · P(B | A) = P(B) · P(A | B)
若 A、B 相互独立，则 P(B|A) = P(B)， 乘法公式退化为 P(A∩B) = P(A)P(B)。 换句话说，独立性是条件概率的一个特例—— 条件概率不改变 B 的概率，就说明 A 的发生不影响 B。

全概率公式

若 A₁, A₂, …, Aₙ 两两互斥且并为全集，则

P(B) = Σ P(Aᵢ) · P(B | Aᵢ)
全概率公式的思路是「分类讨论」： 把复杂事件 B 按不同的「来源」拆成若干互斥的部分，分别算概率再相加。

课本上最经典的例子是「有三个车间供货， 求抽到次品的概率」——先按「来自哪个车间」分类， 再加权求和。做题时先问自己： 「B 这个结果可以从哪几条路径发生？」 把路径列全，公式自然就出来了。

贝叶斯公式（了解）

P(Aᵢ | B) = P(Aᵢ) · P(B | Aᵢ) / Σ P(Aⱼ) P(B | Aⱼ)

它的作用是「已知结果，反推原因」的概率。 分母正是全概率公式算出的 P(B)。

一个帮助理解的例子：某种疾病的检测准确率是 99%， 但患病率只有 0.1%。如果一个人检测为阳性，他真正患病的概率其实 远低于 99%，大约只有 9% 左右。 原因就在于分母里的「假阳性」数量远大于「真阳性」。 这就是贝叶斯公式揭示的「基础概率忽视」现象， 也是它在医学、法律中极其重要的原因。

7.2 离散型随机变量及其分布列

随机变量

把随机试验的每个结果用一个确定的实数来表示， 这样的变量叫随机变量，通常用 X、Y、ξ 表示。

若随机变量的取值可以一一列举，叫离散型随机变量。

分布列

把随机变量 X 的所有取值及其对应概率列成表格， 就是 X 的分布列，也叫概率分布。

两条基本性质：

Pᵢ ≥ 0（每个概率非负）
Σ Pᵢ = 1（所有概率之和为 1）
「所有概率之和为 1」是检验分布列是否正确的唯一标准。 在考试中，算出分布列后一定要加一遍， 这是最有效的自我纠错手段。

另一个高频细节：求分布列时， 取值范围要写全（比如「从 4 个球中摸 3 个， X 表示取到的红球数」，则 X 可能取 0、1、2、3，不能只写一部分）， 且每个概率都要算对。

两点分布

若 X 只取 0 或 1，且 P(X = 1) = p， P(X = 0) = 1 − p，则称 X 服从两点分布。

E(X) = p，D(X) = p(1 − p)

超几何分布

从含有 M 件次品的 N 件产品中任取 n 件， X 表示取到的次品数，则

P(X = k) = C(M, k) · C(N − M, n − k) / C(N, n)
超几何分布的现实背景是「不放回抽样」。 注意区分：如果样品数量很大而抽样数量相对很小， 超几何分布可以近似为二项分布。

7.3 离散型随机变量的数字特征

均值（数学期望）

E(X) = x₁p₁ + x₂p₂ + … + xₙpₙ

它的现实含义是「加权平均」——以概率为权重。 可以理解为「大量重复试验后，X 的平均水平」。

方差与标准差

D(X) = Σ [xᵢ − E(X)]² · pᵢ
简便公式：D(X) = E(X²) − [E(X)]²
标准差：σ(X) = √D(X)

性质

E(aX + b) = a·E(X) + b
D(aX + b) = a²·D(X)
E(X + Y) = E(X) + E(Y)（无需独立性）
D(X + Y) = D(X) + D(Y)（要求 X、Y 相互独立）
两组性质的特点要记牢：
期望对线性变换是「全程线性」的 （aE(X) + b，常数 b 直接加上去）；
方差只受「伸缩」影响，不受「平移」影响 （a²D(X)，与 b 无关）。
原因还是那句话：方差衡量的是波动，而平移不改变波动。

另外注意：E(X+Y) = E(X) + E(Y) 不需要独立性，这是期望的一个优美性质； 但 D(X+Y) = D(X) + D(Y) 必须有独立性（更一般地要「不相关」）。这个差别经常被考。
例 1

袋中有 3 个红球、2 个白球（共 5 个），从中不放回地摸出 2 个球， X 表示摸到的红球数。求 X 的分布列、E(X) 和 D(X)。

解答

第一步，确定取值范围。摸 2 个球，红球数可能为 0、1、2。

第二步，算各概率。总的取法 C(5,2) = 10。

P(X = 0) = C(3,0)C(2,2)/10 = 1/10

P(X = 1) = C(3,1)C(2,1)/10 = 6/10

P(X = 2) = C(3,2)C(2,0)/10 = 3/10

第三步，验算。1 + 6 + 3 = 10， 即概率之和为 10/10 = 1，正确。

第四步，求期望。

E(X) = 0×(1/10) + 1×(6/10) + 2×(3/10) = 0 + 0.6 + 0.6 = 1.2

第五步，求方差。先算 E(X²)：

E(X²) = 0²×(1/10) + 1²×(6/10) + 2²×(3/10) = 0 + 0.6 + 1.2 = 1.8

D(X) = E(X²) − [E(X)]² = 1.8 − 1.2² = 1.8 − 1.44 = 0.36

所以 D(X) = 0.36，标准差 σ = 0.6。

合理性检查：红球占 3/5 = 0.6， 摸 2 个的期望红球数应为 2 × 0.6 = 1.2，与计算一致。 这是一个快速验证期望的好办法。

7.4 二项分布与超几何分布

二项分布

在 n 次独立重复试验中，每次试验事件发生的概率为 p， X 表示事件发生的次数，则

P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ　（k = 0, 1, …, n）
E(X) = np，D(X) = np(1 − p)
「独立重复试验」有三个要求：
其一，每次试验只有两个结果（成功/失败）；
其二，每次试验成功的概率相同（都是 p）；
其三，各次试验相互独立。

「有放回抽样」符合独立重复的条件，所以用二项分布； 「不放回抽样」用超几何分布。 这是最直接的判据。

两者对照

二项分布
有放回（或独立重复）。
参数只有 n 和 p。
E(X) = np。
超几何分布
不放回。
参数有 N（总数）、M（次品数）、n（抽取数）。
期望也为 n · M/N，但方差公式较复杂，一般不要求记。
一个有趣的结论：超几何分布的期望与二项分布的期望形式相同 （都是「抽取数 × 次品率」）， 这是因为「期望具有线性性，与是否独立无关」。 但两者的方差不同——超几何分布的方差更小， 因为不放回抽样减少了随机性。
例 2

某射击手每次命中目标的概率为 0.8，独立射击 5 次。 求：（1）恰好命中 3 次的概率；（2）命中次数的期望与方差。

解答

设 X 为命中次数。每次射击独立、命中概率相同（0.8）、 只有命中与不命中两个结果，所以 X ~ B(5, 0.8)。

（1）代入二项分布公式：

P(X = 3) = C(5,3) × 0.8³ × 0.2²

= 10 × 0.512 × 0.04 = 0.2048

（2）直接用公式：

E(X) = np = 5 × 0.8 = 4

D(X) = np(1 − p) = 5 × 0.8 × 0.2 = 0.8

标准差 σ = √0.8 ≈ 0.894。

结果解读：射 5 次平均命中 4 次， 波动约为 0.89 次。因为命中率高达 0.8， 平均命中次数自然接近射击次数。

7.5 正态分布

定义与图像

若随机变量 X 的概率密度函数为

f(x) = 1/[σ√(2π)] · e^(−(x−μ)²/(2σ²))

则称 X 服从正态分布，记作 X ~ N(μ, σ²)， 其中 μ 是均值，σ 是标准差（注意 σ² 才是方差）。

图像特征（正态曲线）：

其一，曲线位于 x 轴上方；

其二，关于直线 x = μ 对称；

其三，在 x = μ 处达到最高点；

其四，曲线与 x 轴之间的总面积等于 1；

其五，σ 越大，曲线越矮胖（数据越分散）； σ 越小，曲线越高瘦（数据越集中）。

三个关键概率（必须记住）

P(μ − σ < X < μ + σ) ≈ 0.6827
P(μ − 2σ < X < μ + 2σ) ≈ 0.9545
P(μ − 3σ < X < μ + 3σ) ≈ 0.9973
这三个数要背熟，且能反过来用。
常用推论（由对称性得到）：
P(X > μ) = P(X < μ) = 0.5；
P(X > μ + σ) = (1 − 0.6827)/2 ≈ 0.1587；
P(X > μ + 2σ) ≈ 0.0228。
标准正态分布 N(0, 1) 是 μ = 0, σ = 1 的特例。

正态分布的标准化

若 X ~ N(μ, σ²)，则

Z = (X − μ) / σ ~ N(0, 1)
标准化的思想是「先减去均值（平移），再除以标准差（缩放）」， 把任意的正态分布都变成同一个标准正态分布。 这与「方差的性质」是同一个道理—— 平移不改变形状，缩放才改变。

在实际应用里，标准化的结果叫 Z 分数， 它表示「某个数据距离平均值有几个标准差」。 用它可以在不同量纲的数据之间做公平比较 （比如「语文考了 120 分」和「数学考了 130 分」， 哪个更出色？要看各自的 Z 分数）。
例 3

某地区成年男性的身高服从正态分布 N(170, 5²)（单位：cm）。 求身高在 165 cm 到 175 cm 之间的人数占比。

解答

已知 μ = 170，σ = 5。

区间 [165, 175] 恰好是

[μ − σ, μ + σ] = [170 − 5, 170 + 5] = [165, 175]

这是一个标准的一倍标准差区间，由正态分布的性质得

P(165 < X < 175) ≈ 0.6827

所以占比约为 68.27%。

进一步可以求出：身高超过 180 cm 的人是

P(X > 180) = P(X > μ + 2σ) ≈ (1 − 0.9545)/2 ≈ 0.0228

即约 2.28%。这类「超过 μ + kσ」的问题， 都是先用对称性把区间折到中间，再套三个关键概率。

易错点速查

其一，P(B|A) 与 P(A|B) 是两回事，绝不能互换。

其二，分布列的「取值范围」要写全， 且所有概率之和必须验证等于 1。

其三，D(aX + b) = a²D(X)， 平移项 b 不出现在方差里。写成 aD(X) + b 是错的。

其四，D(X + Y) = D(X) + D(Y) 只在 X、Y 相互独立时成立； 而 E(X + Y) = E(X) + E(Y) 不需要任何条件。

其五，正态分布记作 N(μ, σ²)， 第二个参数是方差不是标准差。 若题目说「标准差为 5」，则应写成 N(μ, 25)。

其六，判断二项分布还是超几何分布， 第一件事是问「放回还是不放回」。
