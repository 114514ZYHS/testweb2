第 3 章 函数的概念与性质

人教 A 版必修第一册 · 3.1 – 3.4

0. 预备：一次函数（初中内容）

教材里没有这一节，但它是理解后面一切函数的基础，必须先说清楚。

定义：形如 y = kx + b（k、b 是常数，k ≠ 0）的函数，叫做一次函数。 当 b = 0 时，y = kx 叫做正比例函数。

图像是一条直线：

  • k 决定倾斜方向和陡峭程度：k > 0 时从左下往右上（y 随 x 增大而增大，单调递增）；k < 0 时从左上往右下（单调递减）。|k| 越大，直线越陡。
  • b 是与 y 轴交点的纵坐标，即直线过点 (0, b)。
为什么后面的章节要用它：二次函数、幂函数、导数，本质上都在研究「函数怎么变化」。 一次函数是最简单的一种变化——变化快慢恒定（每增加 1 个单位，y 固定增加 k 个单位）。 导数要研究的，正是把这种「固定变化率」推广到任意函数上。

3.1 函数的概念及其表示

3.1.1 函数的概念

定义：设 A、B 是非空实数集，如果按照某种确定的对应关系 f， 使对于集合 A 中的任意一个数 x，在集合 B 中都有唯一确定的数 y 和它对应， 那么就称 f : A → B 为从集合 A 到集合 B 的一个函数，记作 y = f(x)，x ∈ A 其中 x 叫自变量，A 叫定义域；与 x 对应的 y 叫函数值， 函数值的集合 {f(x) | x ∈ A} 叫值域。

注意定义里的三个关键词，考试就考这些地方：

  • 任意——A 里每一个 x 都必须有对应，不能漏。
  • 唯一确定——一个 x 只能对应一个 y。一个 y 可以对应多个 x，反过来不行。
  • 非空实数集——定义域和值域都是数集。

常见求定义域的情况

看到某种形式，就对应加一个限制条件：

  • 分式 1/g(x) —— 要求分母 g(x) ≠ 0
  • 偶次根式 √g(x) —— 要求被开方数 g(x) ≥ 0
  • 对数 log_a g(x) —— 要求真数 g(x) > 0，且底数 a > 0 且 a ≠ 1
  • 零次幂 [g(x)]⁰ —— 要求底数 g(x) ≠ 0
  • 正切 tan g(x) —— 要求 g(x) ≠ π/2 + kπ

如果式子里同时出现几种，就要全部满足，取交集。

例 1

求函数 f(x) = √(x+2) / (x-1) 的定义域。

分析：分子是根式，要求 x + 2 ≥ 0；分母不能为零，要求 x − 1 ≠ 0。两个条件同时满足。

解：由 x + 2 ≥ 0 得 x ≥ −2；由 x − 1 ≠ 0 得 x ≠ 1。

所以定义域为 {x | x ≥ −2 且 x ≠ 1}，即 [−2, 1) ∪ (1, +∞)。

3.1.2 函数的表示法

三种表示方法：

  • 解析法——用式子表示，如 y = 2x + 1。最常见。
  • 图像法——用图形表示。能直观看出增减、最值。
  • 列表法——列成表格。适合数据离散的情况。

还有分段函数：在定义域的不同部分用不同式子表示。比如

f(x) = { x + 1 (x < 0); x² (x ≥ 0) }

分段函数是一个函数，不是几个函数，只是分段表达而已。求值时先判断 x 落在哪一段。

例 2

已知上面的分段函数，求 f(−3)、f(2)、f(f(−1))。

解：−3 < 0，用第一段：f(−3) = −3 + 1 = −2。

2 ≥ 0，用第二段：f(2) = 2² = 4。

−1 < 0，f(−1) = −1 + 1 = 0；0 ≥ 0，所以 f(f(−1)) = f(0) = 0² = 0。

答案：−2、4、0。

3.2 函数的基本性质

3.2.1 单调性与最大（小）值

增函数：设函数 f(x) 的定义域为 I，区间 D ⊆ I。 如果对 D 上任意两个自变量 x₁、x₂，当 x₁ < x₂ 时，都有 f(x₁) < f(x₂)， 就说 f(x) 在区间 D 上单调递增，D 叫单调递增区间。

减函数：把条件换成 f(x₁) > f(x₂)，就是单调递减。
最容易错的点：必须是任意两个数都满足，不是存在某两个数满足。 不能用具体数字代进去验证来代替证明——那只能说明「可能」，不能说明「一定」。

证明单调性的标准步骤（这是必考题型）：

  1. 取值：在区间内任取 x₁、x₂，且设 x₁ < x₂。
  2. 作差：计算 f(x₁) − f(x₂)。
  3. 变形：因式分解或通分，化成能判断符号的形式。
  4. 定号：根据 x₁ < x₂ 和区间范围，判断差的正负。
  5. 结论：差 < 0 则递增，差 > 0 则递减。
例 3（经典题型）

证明函数 f(x) = 1/x 在区间 (0, +∞) 上单调递减。

① 取值：任取 x₁, x₂ ∈ (0, +∞)，且 x₁ < x₂。

② 作差：f(x₁) − f(x₂) = 1/x₁ − 1/x₂

③ 变形：通分得 (x₂ − x₁) / (x₁x₂)

④ 定号：因为 x₁ < x₂，所以 x₂ − x₁ > 0；又 x₁, x₂ > 0，所以 x₁x₂ > 0。
因此 (x₂ − x₁)/(x₁x₂) > 0，即 f(x₁) − f(x₂) > 0。

⑤ 结论：由 f(x₁) > f(x₂) 知，f(x) 在 (0, +∞) 上单调递减。

最大（小）值

最大值：如果存在 x₀ ∈ I，使得对任意 x ∈ I 都有 f(x) ≤ f(x₀)， 就说 f(x₀) 是 f(x) 的最大值，记作 ymax = f(x₀)。
最小值：把 ≤ 换成 ≥ 即可。

3.2.2 函数的奇偶性

前提：定义域必须关于原点对称，否则既不是奇函数也不是偶函数。

偶函数：对定义域内任意 x，都有 f(−x) = f(x)。图像关于 y 轴对称。
奇函数：对定义域内任意 x，都有 f(−x) = −f(x)。图像关于 原点对称。
两个常用结论：
① 奇函数如果在 x = 0 处有定义，则 f(0) = 0。
② 奇函数在对称的两个区间上单调性相同；偶函数在对称区间上单调性相反。

3.3 幂函数

定义：一般地，形如 y = x^α（α 为常数）的函数，叫做幂函数。

注意：幂函数的底数是自变量 x，指数是常数。 这跟指数函数 y = a^x（底数是常数、指数是自变量）正好相反，别混。

高中要掌握的五个常用幂函数

函数定义域值域奇偶性单调性（0, +∞ 上）
y = xRR奇递增
y = x²R[0, +∞)偶递增
y = x³RR奇递增
y = x^(1/2)（即 √x）[0, +∞)[0, +∞)非奇非偶递增
y = x^(−1)（即 1/x）{x | x ≠ 0}{y | y ≠ 0}奇递减

图像规律（记这几条就够了）

  • 所有幂函数都过点 (1, 1)——这是它们唯一共同的定点。
  • 如果 α > 0，图像还过原点 (0, 0)，且在 (0, +∞) 上递增。
  • 如果 α < 0，图像不过原点，在 (0, +∞) 上递减，以两坐标轴为渐近线。
  • 在区间 (1, +∞) 上，α 越大，图像越靠上（增长越快）。
例 4

比较大小：(1.5)^(1/2) 与 (1.7)^(1/2)。

分析：两个数的指数相同（都是 1/2），底数不同，这是同一个幂函数 y = x^(1/2) 的两个函数值。

解：函数 y = x^(1/2) 在 (0, +∞) 上单调递增。

因为 1.5 < 1.7，所以 (1.5)^(1/2) < (1.7)^(1/2)。

要点：指数相同、底数不同，用幂函数的单调性比较。

例 5

比较大小：0.8^(2/3) 与 0.8^(3/4)。

分析：这次底数相同（都是 0.8），指数不同，应该用指数函数 y = 0.8^x 的单调性。

解：因为 0 < 0.8 < 1，所以 y = 0.8^x 在 R 上单调递减。

因为 2/3 < 3/4，所以 0.8^(2/3) > 0.8^(3/4)。

要点：底数相同、指数不同，用指数函数的单调性。注意底数小于 1 时是递减，大小关系要反过来。

归纳：比较幂的大小看什么？
① 指数相同、底数不同 → 用幂函数单调性
② 底数相同、指数不同 → 用指数函数单调性
③ 底数和指数都不同 → 找中间量（常用 1 或 0）搭桥
④ 指数是负数 → 先化成正指数，或利用倒数关系

3.4 函数的应用（一）

这一节讲怎么用函数解决实际问题，核心是建立函数模型。一般步骤：

  1. 审题——弄清楚哪些量在变，哪些是固定的。
  2. 设变量——通常设要求的最值为 y，设自变量为 x。
  3. 找关系——根据题意（几何公式、物理规律、经济关系）写出 y 与 x 的关系式。
  4. 定范围——至关重要，x 必须有实际意义（长度不能为负、人数必须是整数等）。
  5. 求最值——用配方、基本不等式或单调性。
  6. 作答——回到实际问题，注明单位。
例 6

用长为 20 米的篱笆围一个矩形菜园，问长、宽各为多少时面积最大？最大面积是多少？

解：设矩形的一边长为 x 米，则邻边长为 (10 − x) 米。

由实际意义，需满足 x > 0 且 10 − x > 0，即 0 < x < 10。

面积 S = x(10 − x) = −x² + 10x = −(x − 5)² + 25

这是开口向下的二次函数，顶点在 x = 5。

因为 5 ∈ (0, 10)，所以当 x = 5 时 S 取最大值 25。

答：围成边长为 5 米的正方形时面积最大，最大面积为 25 平方米。

易错点：如果忘了写 0 < x < 10，就没法判断顶点 5 是否在范围内，得分会受影响。

本章小结：这一章是全书的骨架。后面的指数函数、对数函数、三角函数、导数， 研究的都是「某个具体的函数有什么性质」，用的都是本章这套语言——定义域、值域、单调性、奇偶性。 这一章没打牢，后面全是空中楼阁。
