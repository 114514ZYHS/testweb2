第 6 章　平面向量及其应用

人教 A 版必修第二册 · 6.1 – 6.4

先建立直觉：向量就是一个「有方向的量」。 初中我们学过「速度 5 m/s」——那只说了大小；而「速度 5 m/s 向东」才是完整的， 这就是向量。「向东走 3 公里再向北走 4 公里，离起点多远？」 这类问题的答案必须靠向量算，标量（普通的数）做不到。

6.1 平面向量的概念

定义与表示

既有大小又有方向的量叫做向量。只有大小的量叫数量（标量）。

向量的几何表示是一条有向线段：起点 A、终点 B， 记作 AB→，其长度叫做向量的模，记作 |AB→|。

模为 1 的向量叫单位向量；模为 0 的向量叫零向量，记作 0， 它的方向是任意的（注意不是「没有方向」）。

三种特殊关系

平行（共线）向量
方向相同或相反的非零向量。记作 a ∥ b。
规定：零向量与任意向量平行。
相等向量
长度相等且方向相同。两个条件缺一不可。
向量可以自由平移，起点在哪不影响相等。
相反向量
长度相等、方向相反。a 的相反向量记作 −a。
最常见的错误：「向量相等必须起点、终点都对应相同」是错的。 向量只由「大小 + 方向」确定，与位置无关。只要长度方向一样，画在哪儿都是同一个向量。 另外「两个向量平行」不要求它们在同一条直线上，只要方向共线即可。

6.2 平面向量的运算

加减法：三角形法则与平行四边形法则

加法（首尾相接）：把 b 的起点平移到 a 的终点， 则从 a 的起点指向 b 的终点的向量就是 a + b。

减法（共起点，连终点，指向被减）： a − b 的几何意义是「从 b 的终点指向 a 的终点」。

a − b 表示从 b 的终点指向 a 的终点的向量
减法的方向是最容易记反的地方。口诀：「减号后面的那个是被减对象， 箭头从前一个的终点射出来」。更保险的办法是把它改写成加法： a − b = a + (−b)，然后按加法规则画。

数乘

实数 λ 与向量 a 的乘积 λa 还是一个向量， 它的模是 |λ||a|，方向取决于 λ 的正负： λ > 0 时同向，λ < 0 时反向，λ = 0 时为零向量。

由此得到共线向量定理（非常重要）：

b 与非零向量 a 共线 ⇔ 存在唯一实数 λ，使 b = λa

它是证明「三点共线」「两线平行」的核心工具。

数量积（点积）

a · b = |a||b|cos θ　（θ 为两向量的夹角，取值范围 [0, π]）
a · b = x₁x₂ + y₁y₂　（坐标形式）

由定义直接得到几条必备结论：

|a|² = a · a
a ⊥ b ⇔ a · b = 0
cos θ = (a · b) / (|a||b|)
数量积的结果是一个数（标量），不是一个向量——这是最容易混的概念。 另外「a · b = 0」有两种情况：两向量垂直， 或者其中至少一个是零向量。所以由 a·b = 0 直接推出 a ⊥ b 是不严谨的， 必须先说明 a、b 都是非零向量。

还有一点：数量积不满足结合律， 即 (a·b)·c ≠ a·(b·c)。左边是「数乘向量」，右边是「向量乘数」， 方向都可能不一样。

坐标运算

设 a = (x₁, y₁)，b = (x₂, y₂)，则：

a + b = (x₁ + x₂, y₁ + y₂)
λa = (λx₁, λy₁)
a · b = x₁x₂ + y₁y₂
a ∥ b ⇔ x₁y₂ − x₂y₁ = 0
a ⊥ b ⇔ x₁x₂ + y₁y₂ = 0
平行与垂直的坐标条件结构完全不同，千万别记反：
平行是「交叉相乘相减」（x₁y₂ − x₂y₁ = 0，分母交叉）；
垂直是「对应相乘相加」（x₁x₂ + y₁y₂ = 0）。
一个记忆抓手：垂直和数量积的坐标公式长得一模一样（都是对应相乘相加）， 因为垂直的定义就是「数量积为零」。
例 1

已知 a = (1, 2)，b = (3, −1)， 求 a · b、|a|，以及两向量的夹角余弦值。

解答

a · b = 1×3 + 2×(−1) = 3 − 2 = 1

|a| = √(1² + 2²) = √5 ≈ 2.236， |b| = √(3² + (−1)²) = √10 ≈ 3.162

cos θ = 1 / (√5 × √10) = 1/√50 ≈ 0.141

因为 cos θ > 0 且很接近 0，说明两向量近似垂直，夹角约为 81.9°。 若结果是 0，则恰好垂直；若为负，则夹角为钝角。

向量的模与「极化」技巧

求模的通用方法是先平方，再用数量积展开：

|a + b|² = |a|² + 2a·b + |b|²
|a − b|² = |a|² − 2a·b + |b|²

两式相减可得

a · b = (|a + b|² − |a − b|²) / 4
这个公式叫「极化恒等式」，在处理「已知 |a+b| 和 |a−b| 求数量积」 或者「已知模长求数量积」类问题时极为好用， 能省掉设坐标的繁琐过程。

6.3 平面向量基本定理及坐标表示

基本定理：如果 e₁, e₂ 是同一平面内的两个不共线向量， 那么对该平面内任意一个向量 a， 存在唯一的一对实数 λ₁、λ₂，使

a = λ₁e₁ + λ₂e₂

这一对 (λ₁, λ₂) 就叫 a 在这组基底下的坐标。 所以「建系求坐标」的本质，是先选定一组基底。

定比分点与中点

若 P 是线段 AB 上一点，且 AP→ = t AB→，则 P 是 A、B 的定比分点。

特别地，当 t = 1/2 时，P 是 AB 的中点，此时

OP→ = (OA→ + OB→) / 2

坐标形式即 P((x₁+x₂)/2, (y₁+y₂)/2)。

三点共线的判定

经典结论：若 OC→ = λOA→ + μOB→， 则 A、B、C 三点共线的充要条件是

λ + μ = 1
这个「系数和为 1」的结论几乎每年都考。使用时要注意： 三个向量的起点必须是同一个点（通常是 O）。 如果题干给的向量起点不同，要先用减法把所有向量统一到同一个起点。

6.4 平面向量的应用

用向量证垂直与平行

证垂直：只需证 a · b = 0。 证平行：只需证 a = λb（或坐标交叉相乘为 0）。

向量在三角形与几何中的应用

正弦定理：在 △ABC 中，

a / sin A = b / sin B = c / sin C = 2R（R 为外接圆半径）

余弦定理：

a² = b² + c² − 2bc cos A
这两个定理可以用向量的数量积直接推出—— 把 a = BC→ = AC→ − AB→ 两边平方，展开即得余弦定理。 理解了这个推导，就不必死记，也不会在符号上出错。

用定理的选择原则：已知两边及其夹角，或已知三边 → 用余弦定理； 已知两角及一边，或已知两边及其中一边的对角 → 用正弦定理。 后者要注意可能有两解（「一解、两解、无解」的讨论）。

向量在物理中的应用

力、速度、位移都是向量，合成用向量加法， 做功 W = F · s 用数量积。分解一个力到两个方向， 本质是把该向量用一组基底线性表示。

例 2

已知 |a| = 3，|b| = 4， a · b = −6，求 |a + b|。

解答

先平方：|a + b|² = |a|² + 2a·b + |b|²

= 9 + 2×(−6) + 16 = 9 − 12 + 16 = 13

所以 |a + b| = √13。

顺带可以求夹角：cos θ = −6/(3×4) = −0.5， 所以 θ = 120°。数量积为负说明夹角是钝角—— 这也是检验结果是否合理的一个快速办法。

易错点速查

其一，零向量的方向是任意的，不是「没有方向」，也不是「方向不定所以不算向量」。

其二，|a·b| ≤ |a||b|，等号成立当且仅当两向量共线。 不要把「数量积」和「模的乘积」搞混。

其三，向量没有「除法」。看到 a/b 这种写法， 一律按错误处理。

其四，求夹角时注意范围是 [0°, 180°]， 算出的 cos 值为负时，夹角一定是钝角，不能答锐角。

一句话总结

向量这一章的核心思路是：把几何问题翻译成代数运算。 「平行、垂直、共线、夹角、长度」这五类几何关系， 分别对应「叉积为零、点积为零、λ 表示、cos 公式、平方展开」这五种运算。 把这五组对应关系背熟，几何题就变成了代数计算题。
