第 2 章 一元二次函数、方程和不等式

人教 A 版必修第一册 · 2.1 – 2.3

这一章把三样东西串在一起：二次函数、一元二次方程、一元二次不等式。 它们看着是三块内容，其实是同一个东西的三种问法。

2.1 等式性质与不等式性质

不等式的基本性质

① 对称性： a > b ⇔ b < a

② 传递性： a > b, b > c ⇒ a > c

③ 可加性： a > b ⇒ a + c > b + c

④ 可乘性： a > b, c > 0 ⇒ ac > bc； a > b, c < 0 ⇒ ac < bc
性质 ④ 是整章最容易翻车的地方： 两边同乘（或同除）一个负数，不等号方向必须反过来。
例：3 > 2 成立，两边同乘 −1，得 −3 < −2，不等号反了才对。

如果乘的是一个符号未知的式子，就必须分类讨论——正的一种、负的一种、等于零的一种。

比较大小的两种方法

  • 作差法：算 a − b，看结果的正负。>0 则 a > b，=0 则相等，<0 则 a < b。
    这是最通用的方法。
  • 作商法：算 a/b（要求 b ≠ 0），与 1 比较。适合两边都是正数且结构适合相除的情况。
例 1

已知 a > b > 0，比较 a² 与 ab 的大小。

解：用作差法。

a² − ab = a(a − b)

因为 a > 0（由 a > b > 0 得），且 a − b > 0，

所以 a(a − b) > 0，即 a² > ab。

2.2 基本不等式

基本不等式：如果 a > 0，b > 0，那么 √(ab) ≤ (a + b) / 2 当且仅当 a = b 时，等号成立。

其中 (a + b)/2 叫 a、b 的算术平均数， √(ab) 叫 a、b 的几何平均数。 所以这句话也可以说成：算术平均数不小于几何平均数。

常用变形

a + b ≥ 2√(ab)    ab ≤ ((a + b)/2)²    a² + b² ≥ 2ab

这三个是同一个不等式的不同写法，实际做题时看题目给的是「和」还是「积」，选好用的那个。

用基本不等式求最值，必须同时满足三个条件（简称「一正二定三相等」）：
① 正——各项必须都是正数；
② 定——和或者积必须有一个是定值（常数）；
③ 相等——等号必须能取到（即存在 a = b 的情况）。

三条缺一条，结论就不成立。 很多人只检查前两条，忘了验证第三条。
例 2（经典）

已知 x > 0，求 y = x + 4/x 的最小值。

解：因为 x > 0，所以 4/x > 0，两项都是正的（满足「正」）。

由基本不等式：y = x + 4/x ≥ 2√(x · 4/x) = 2√4 = 4

乘积 x · (4/x) = 4 是定值（满足「定」）。

等号成立的条件是 x = 4/x，即 x² = 4，解得 x = 2（取正根，因为 x > 0）。

x = 2 确实在 x > 0 范围内，等号能取到（满足「相等」）。

所以当 x = 2 时，y 取得最小值 4。

注意：这三条检查必须写出来，不能只写个答案。高考阅卷是看步骤给分的。

例 3（反面教材：等号取不到怎么办）

已知 x ≥ 3，求 y = x + 4/x 的最小值。

错误解法：直接用基本不等式得 y ≥ 4，所以最小值是 4。

错在哪：等号成立要求 x = 2，但题目限定 x ≥ 3，取不到 x = 2！

正确解法：改用单调性。设 f(x) = x + 4/x。

在 [3, +∞) 上，x 增大时 x 增大，而 4/x 减小。需要判断整体增减，用导数最稳（本章还没学，可用定义证明）。

直接计算即可：f(3) = 3 + 4/3 = 13/3 ≈ 4.33，而 f(4) = 4 + 1 = 5，f(5) = 5 + 0.8 = 5.8……

可以看出在 [3, +∞) 上函数是递增的。

所以最小值在 x = 3 处取得，为 13/3。

教训：看到「x 有限制范围」就要警惕，等号可能取不到。这时候要改用函数单调性。

2.3 二次函数与一元二次方程、不等式

三者的统一关系

把二次函数 y = ax² + bx + c（a ≠ 0）的图像画出来，很多问题一眼就清楚：

  • 方程 ax² + bx + c = 0 的根 → 图像与 x 轴交点的横坐标
  • 不等式 ax² + bx + c > 0 的解集 → 图像在 x 轴上方部分对应的 x 范围
  • 不等式 ax² + bx + c < 0 的解集 → 图像在 x 轴下方部分对应的 x 范围

求一元二次不等式解集的标准步骤

  1. 把不等式化为标准形式：右边为 0，且二次项系数为正（若为负，两边同乘 −1 并反转不等号）；
  2. 计算判别式 Δ = b² − 4ac；
  3. 根据 Δ 判断根的情况：

设方程的两根为 x₁、x₂（不妨设 x₁ < x₂），那么对 ax² + bx + c > 0（a > 0 时）：

  • Δ > 0：有两个不同实根，解集是 「两边」——{x | x < x₁ 或 x > x₂}
  • Δ = 0：有一个重根 x₀，解集是 「去掉一点」——{x | x ≠ x₀}
  • Δ < 0：没有实根，图像整体在 x 轴上方，解集是 全体实数 R

如果是 ax² + bx + c < 0（a > 0），就把上面三类结果取补集（注意端点开闭）：

  • Δ > 0：解集是 「中间」——{x | x₁ < x < x₂}
  • Δ = 0：解集是 空集 ∅
  • Δ < 0：解集是 空集 ∅
口诀：「大于取两边，小于取中间」——但这条口诀只在二次项系数为正时成立！
如果二次项系数是负的，先去把系数调正，再用口诀，否则一定错。
例 4

解不等式 x² − 5x + 6 > 0。

解：二次项系数为 1 > 0，已经是标准形式。

先解方程 x² − 5x + 6 = 0，因式分解得 (x − 2)(x − 3) = 0，所以 x₁ = 2，x₂ = 3。

Δ = 25 − 24 = 1 > 0，有两个不同实根。

因为要求 > 0（大于），取两边：

解集为 {x | x < 2 或 x > 3}，即 (−∞, 2) ∪ (3, +∞)

例 5（二次项系数为负的情况）

解不等式 −x² + 2x + 3 ≥ 0。

第一步：把二次项系数变正。两边同乘 −1，不等号反转：

x² − 2x − 3 ≤ 0

第二步：解 x² − 2x − 3 = 0，因式分解 (x − 3)(x + 1) = 0，得 x₁ = −1，x₂ = 3。

第三步：现在要求 ≤ 0（小于），取中间：−1 ≤ x ≤ 3。

解集为 {x | −1 ≤ x ≤ 3}，即 [−1, 3]

如果不先调正系数，直接对着原式用「大于取两边」，就会得到完全相反的答案。这是高频错误。

与函数、方程的联系（重要）

把三者记成一张图：二次函数的图像是一条抛物线，它与 x 轴的关系决定了方程和不等式的一切。

  • 抛物线与 x 轴交两个点 → 方程有两个不等实根，不等式解集「两边」或「中间」
  • 抛物线与 x 轴相切（碰一个点） → 方程有两个相等实根
  • 抛物线与 x 轴不相交 → 方程无实根，不等式要么恒成立要么无解
恒成立问题的套路：若 ax² + bx + c > 0 对一切实数 x 都成立， 当 a > 0 时只需 Δ < 0（抛物线整体在 x 轴上方，碰不到）。
这个思路在后面的导数题里还会大量出现。
本章小结：这一章把「二次」这个主题讲透了——
• 比较大小 → 作差法
• 求最值 → 基本不等式（一正二定三相等），取不到等号就改用单调性
• 解不等式 → 先调正系数，再算 Δ 和根，最后「大于取两边、小于取中间」
• 恒成立 → 转化为抛物线与 x 轴的位置关系
