第 8 章　成对数据的统计分析

人教 A 版选择性必修第三册 · 8.1 – 8.3

先建立直觉：前面几章研究的是「一个变量」的分布。 这一章研究的是两个变量之间的关系—— 比如「身高越高，体重是不是也越重？」 「广告投入越多，销量是不是越好？」

要回答这类问题，需要两个工具： 相关系数（衡量两变量线性关系的强弱） 和一元线性回归模型（用一条直线近似描述这种关系，并做预测）。

8.1 成对数据的相关关系

相关关系的概念

函数关系：两个变量之间是确定的对应关系 （如正方形的面积与边长）。

相关关系：两个变量之间是不确定的关系， 一个变量取值后，另一个变量的取值带有随机性 （如身高与体重），但仍表现出某种趋势。

相关关系与函数关系的分界在于「确定性」。 但要特别注意：有相关关系不等于有因果关系。 一个经典例子是「冰淇淋销量」与「溺水人数」呈正相关， 但吃冰淇淋不会导致溺水——真正的原因是「气温」这个共同变量。 这就是「相关不蕴含因果」，也是统计学最常被误用的一点。

散点图

把成对数据 (xᵢ, yᵢ) 画在平面直角坐标系中， 就得到散点图。它可以直观展示两个变量之间是否有趋势。

两类趋势：

正相关——散点整体呈从左下到右上的趋势， 即 x 增大时 y 总体上也增大。

负相关——散点整体呈从左上到右下的趋势。

再看散点的「聚散程度」： 散点越接近一条直线，相关关系越强； 越分散，相关关系越弱。 所以判断相关性强弱要看两个维度：方向（正/负）和紧密程度。

8.2 样本相关系数

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²]

这个量叫样本相关系数（皮尔逊相关系数），取值范围是

−1 ≤ r ≤ 1

如何解读 r：

其一，符号表示方向—— r > 0 为正相关，r < 0 为负相关。

其二，绝对值表示强弱—— |r| 越接近 1，线性相关越强；越接近 0，线性相关越弱。

其三，当 |r| = 1 时，散点完全落在一条直线上， 此时两个变量是函数关系而不是相关关系。

三个关键阈值的含义（需要记住）：
|r| > 0.75——认为有很强的线性相关；
0.3 < |r| < 0.75——认为有一定的线性相关；
|r| < 0.3——认为线性相关很弱，几乎可以忽略。

另外，r 只衡量「线性」相关的强弱。 如果两个变量是「抛物线性」相关（如 y = x²，x 取 ± 值时 y 相同）， 那么 r 可能接近 0，但它们其实有很强的非线性关系。 这是 r 的一个重要局限。

相关系数的性质

r 与单位无关（把 x 或 y 的单位改掉，r 不变）
r 与原点位置的选择无关（平移不变）
这两条性质说明 r 是一个「标准化的」指标—— 它不依赖数据的量纲和位置。 这正是它的价值所在：可以把「身高与体重」和 「广告费与销售额」这两组完全不同量纲的数据放在一起比较。

8.3 一元线性回归模型及其应用

回归直线方程

当散点有线性趋势时，用一条直线来近似描述：

ŷ = b̂x + â

其中斜率与截距的最小二乘估计公式为

b̂ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
â = ȳ − b̂ x̄
「回归直线一定过样本点的中心 (x̄, ȳ)」——这是最重要的结论， 几乎所有回归题都要用它。

推导很简单：由 â = ȳ − b̂x̄ 移项得 ȳ = b̂x̄ + â， 说明点 (x̄, ȳ) 满足回归方程。

另一个计算技巧：先算 b̂ 再算 â， 不要试图先算 â。因为 â 的公式里含 b̂。

残差与残差分析

残差：eᵢ = yᵢ − ŷᵢ（实际值减去预测值）
残差平方和越小，模型拟合效果越好

残差图：以残差为纵轴、以自变量（或预测值）为横轴画散点图。 若残差随机、均匀地分布在 0 附近， 说明模型合适；若残差呈现明显的规律（如弯曲的带状）， 说明线性模型不适合这些数据。

残差分析是判断「用线性模型是否合适」的关键手段。 一个常见误区是「回归直线拟合得好就一定合适」—— 如果数据本身是曲线趋势，用直线拟合虽然也可能算出 r 较高， 但残差图会显示出明显的系统性偏离， 说明应该考虑非线性模型（如指数模型）。

决定系数 R²

R² = 1 − (残差平方和) / (总偏差平方和)
R² ∈ [0, 1]，越接近 1 说明模型拟合效果越好
在一元线性回归中，有一个重要的关系： R² = r²， 即决定系数等于相关系数的平方。 所以两者提供的信息是一致的（但 R² 只反映「拟合优度」， 不反映方向，因为平方后符号丢失了）。

注意：这个等式只在一元线性回归中成立。 多元回归中 R² 与 r 就没有这种简单关系了。
例 1

已知 5 组数据的 x̄ = 3， ȳ = 8，且求得 b̂ = 1.5。 求回归直线方程，并预测当 x = 6 时 y 的值。

解答

第一步，求截距。由回归直线过样本中心点 (x̄, ȳ)：

â = ȳ − b̂x̄ = 8 − 1.5 × 3 = 8 − 4.5 = 3.5

第二步，写出方程。

ŷ = 1.5x + 3.5

第三步，代入预测。当 x = 6 时：

ŷ = 1.5 × 6 + 3.5 = 9 + 3.5 = 12.5

所以预测值为 12.5。

验算：把 x = x̄ = 3 代回方程， 应得到 ŷ = ȳ = 8： 1.5 × 3 + 3.5 = 8，吻合。

补充说明：斜率 b̂ = 1.5 的含义是 「x 每增加 1 个单位，y 平均增加 1.5 个单位」。 答题时要能说出斜率的实际意义，这是回归题的标准得分点。

非线性回归的处理

当散点呈曲线趋势时，可以通过变量替换转化为线性回归。

常见情形：

指数型 y = a·e^(bx)： 两边取对数得 ln y = ln a + bx， 令 Y = ln y，则 Y = bx + ln a 变成线性。

幂函数型 y = a·x^b： 两边取对数得 ln y = ln a + b ln x， 令 Y = ln y、X = ln x， 则 Y = bX + ln a 变成线性。

反比例型 y = a + b/x： 令 X = 1/x， 则 y = a + bX 变成线性。

做变换时要注意：变换之后，回归方程里的变量是新变量。 所以「对 ln y 与 x 做回归」得到的方程， 是对 (x, ln y) 这组数据的最优拟合， 而不是对 (x, y) 的最优拟合。

另外，「取对数」这个手段之所以有效， 是因为很多自然现象本身是指数增长或衰减的 （如细菌繁殖、放射性衰变、复利）， 取对数正好把乘法关系变成了加法关系。

统计案例的一般流程

第一步，确定研究对象，收集成对数据。

第二步，画散点图，观察是否有相关趋势、是线性还是非线性。

第三步，计算相关系数 r，判断线性相关的强弱。

第四步，若线性相关较强，求回归方程；否则考虑变量替换。

第五步，做残差分析，检验模型是否合适。

第六步，用模型做预测，但要说明适用范围和不确定性。

第六步是实际应用中最容易被忽视的。 回归预测只在样本数据的范围内较为可靠—— 这叫「内插可靠，外推危险」。 比如用「过去 5 年的数据」拟合出的直线， 去预测「20 年后的情况」，可信度非常低。 答题时若能指出这一点，是加分项。

易错点速查

其一，相关关系不等于因果关系。 不要因为「r 很大」就断言「x 导致 y」。

其二，r 只衡量线性相关。 r 接近 0 不代表两个变量没关系， 可能是有很强的非线性关系。

其三，回归直线一定过 (x̄, ȳ)， 这是计算 â 的唯一依据，也是检验结果是否正确的最快方法。

其四，斜率与截距都要说明实际意义， 不能只给数字。这是回归题的标准得分点。

其五，一元线性回归中 R² = r²， 但不要把这个关系套到多元回归上。

其六，「回归」这个词本身并不表示因果， 它只表示「用一条线去逼近数据的平均趋势」。 「回归」的字面意思来自高尔顿研究身高遗传时发现的 「子代身高向平均值回归」的现象。
