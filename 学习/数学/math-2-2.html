第 7 章　复数

人教 A 版必修第二册 · 7.1 – 7.3

先建立直觉：初中我们学过「负数没有平方根」。 复数做的事情就是把这个限制拆掉——规定一个新的数 i， 让它满足 i² = −1。 一旦有了 i，任何负数都能开平方了，方程 x² = −1 也就有了根。

这不是「造一个假数」，而是把数系再扩大一次—— 从自然数到整数、到有理数、到实数，每次扩大都是为了「让某种运算总有解」。 复数就是这一步。

7.1 复数的概念

代数形式

形如 a + bi（a、b ∈ R）的数叫复数。 其中 a 叫实部，b 叫虚部，i 叫虚数单位，满足 i² = −1。

全体复数构成的集合叫复数集，记作 C。 实数集 R 是 C 的真子集，即 R ⊂ C。这条链是 N ⊂ Z ⊂ Q ⊂ R ⊂ C。

分类

设 z = a + bi：

b = 0 时，z 是实数。
b ≠ 0 时，z 是虚数。其中若 a = 0 且 b ≠ 0，则 z 是纯虚数。

判断纯虚数要求两个条件同时成立：实部为零，且虚部不为零。 只写「实部为零」是错的——因为当实部和虚部都为零时， 0 + 0i 是实数 0，不是纯虚数。 这是最常见的失分点。

相等与几何意义

a + bi = c + di ⇔ a = c 且 b = d

这个「实部对实部、虚部对虚部」的对应关系， 是解复数方程、求参数值的基本工具。

几何意义：复数 z = a + bi 与复平面内的点 Z(a, b) 一一对应，也与向量 OZ→ 一一对应。 x 轴叫实轴，y 轴叫虚轴（注意虚轴不包括原点， 因为原点上的点表示实数 0）。

共轭复数：实部相同、虚部互为相反数，即 z̄ = a − bi。几何上是关于实轴对称。

复数的模：|z| = √(a² + b²)， 就是对应向量的长度，也是点 Z 到原点的距离。

7.2 复数的四则运算

加减法

实部与实部相加减，虚部与虚部相加减：

(a + bi) ± (c + di) = (a ± c) + (b ± d)i

几何意义与向量加减法完全一致。

乘法

按多项式乘法展开，然后利用 i² = −1 化简：

(a + bi)(c + di) = (ac − bd) + (ad + bc)i
乘法结果不用死背，现场展开即可： (a+bi)(c+di) = ac + adi + bci + bdi²， 把 i² 换成 −1 就得到上式。 硬背公式反而容易记错中间的符号。

除法（关键技巧：分母实数化）

方法：分子分母同乘分母的共轭复数，把分母变成实数。

(a + bi)/(c + di) = (a + bi)(c − di) / (c² + d²)
分母实数化的原理是「(c+di)(c−di) = c² + d²」， 结果一定是个非负实数（因为 c² + d² = |z|² ≥ 0）。 这与初中「分母有理化时乘共轭根式」是同一个套路。

i 的幂的周期性

i¹ = i,　i² = −1,　i³ = −i,　i⁴ = 1

周期为 4。所以计算 iⁿ 时， 只需把 n 除以 4 看余数：余 0 得 1，余 1 得 i，余 2 得 −1，余 3 得 −i。

几个常用性质

z · z̄ = |z|²
|z₁ · z₂| = |z₁| · |z₂|
|z₁ / z₂| = |z₁| / |z₂|
z̄ 的共轭是 z（共轭的共轭复原）
z · z̄ = |z|² 是求模、化简的重要跳板。 比如要算 |z|，可以先算 z · z̄ 再开方， 往往比直接求根号简单。
例 1

计算 z = (1 + 2i) / (1 − i)，并求 |z|。

解答

分母实数化，分子分母同乘 1 + i：

z = (1 + 2i)(1 + i) / [(1 − i)(1 + i)]

分子：(1 + 2i)(1 + i) = 1 + i + 2i + 2i² = 1 + 3i − 2 = −1 + 3i

分母：(1 − i)(1 + i) = 1 − i² = 1 + 1 = 2

所以 z = (−1 + 3i)/2 = −0.5 + 1.5i。

模：|z| = √[(−0.5)² + 1.5²] = √(0.25 + 2.25) = √2.5 ≈ 1.581。

验算：也可以用模的性质快速检验—— |1 + 2i| = √5，|1 − i| = √2， 则 |z| = √5/√2 = √2.5 ≈ 1.581，与上面一致。这个技巧能省很多计算。

7.3 复数的三角表示（选学）

复数可以写成

z = r(cos θ + i sin θ)

其中 r = |z| 是模，θ 是辐角（对应向量与 x 轴正方向的夹角）。 当 θ ∈ [0, 2π) 时，θ 叫辐角主值，记作 arg z。

这种表示的最大好处是乘除变得极简单：

模相乘，辐角相加：|z₁z₂| = r₁r₂，arg(z₁z₂) = θ₁ + θ₂
模相除，辐角相减：|z₁/z₂| = r₁/r₂，arg(z₁/z₂) = θ₁ − θ₂
三角形式揭示了一个深刻的直觉：复数乘法在几何上就是「缩放 + 旋转」。 乘以 i 相当于「逆时针转 90°」，因为 i = cos90° + i sin90°。这就解释了为什么 i² = −1——转 90° 两次就是转 180°，即把向量变成相反方向。 理解了这一点，复数的很多性质就变得自然了。

7.4 复数与方程

实系数一元二次方程 ax² + bx + c = 0， 当判别式 Δ = b² − 4ac < 0 时， 在复数范围内仍有两个根，且互为共轭虚数：

x = [−b ± i√(4ac − b²)] / (2a)

这与实根公式的唯一差别是「根号里取了相反数后乘以 i」。

对一般的实系数多项式，有「虚根成对出现」的规律： 如果 a + bi 是方程的根， 那么它的共轭 a − bi 也一定是根。

例 2

已知关于 x 的方程 x² + 2x + m = 0 有虚根， 且其中一个根为 −1 + √2·i，求 m 的值。

解答

方法一（用虚根成对）： 实系数方程的虚根成对出现，所以另一根是 −1 − √2·i。 由韦达定理，两根之积等于常数项除以二次项系数，即

m = (−1 + √2 i)(−1 − √2 i) = (−1)² − (√2 i)² = 1 − 2i² = 1 + 2 = 3

方法二（直接代入）：把 x = −1 + √2 i 代进去， 利用 i² = −1 化简直算，同样得到 m = 3。

验算：Δ = 4 − 4m = 4 − 12 < 0， 确实有虚根，与题设「有虚根」一致。

易错点速查

其一，复数的「两个数不能比较大小」——除了实数以外， 任何两个虚数之间都没有大小关系。看到「若 z₁ > z₂」 直接判断为错或用「两者都是实数」来解读。

其二，|z|² ≠ z²。 左边是实数 a² + b²，右边是复数 (a+bi)²， 一般不是同一个东西。真正成立的是 |z|² = z·z̄。

其三，解复数方程时，若题目说「z 是复数」， 则不能默认 z 是实数，要设 z = a + bi 后 按实部虚部分别建立方程组。

其四，若题目说「z 是纯虚数」， 则可以先设 z = bi（b ≠ 0），少一个未知量，计算更简洁。
