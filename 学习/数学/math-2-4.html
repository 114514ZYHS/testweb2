第 9 章　统计

人教 A 版必修第二册 · 9.1 – 9.3

先建立直觉：统计要解决的核心问题是「用一小部分数据推断整体的情况」。 比如想知道全校两千人的平均身高，不可能一个个量， 只能抽 100 人量，然后推算全体。

这里面有两个环节：怎么抽（保证样本有代表性） 和怎么算（用什么指标描述数据的集中趋势和离散程度）。 抽取方式错了，后面的计算再精确也没用。

9.1 随机抽样

简单随机抽样

从总体中逐个抽取，每个个体被抽到的机会相等，且各次抽取是独立的。 适用于总体容量较小的情况。

两种具体做法：

抽签法——把总体中的每个个体编号，做成签，搅拌均匀后逐个抽取。

随机数法——给每个个体编号，用随机数表或随机数生成器生成号码， 遇到已抽中的号就跳过，直到抽够为止。

简单随机抽样的核心是「每个个体被抽到的概率相等」， 而且在整个抽样过程中，每个个体被抽到的可能性始终一致 （并非「第一次抽中的概率最大」）。这是它的本质特征， 也是判断题最爱考的表述点。

分层随机抽样

当总体由差异明显的几个部分组成时， 先把总体分层，然后在各层内独立地按比例抽取。

某层抽取数 = 样本量 × (该层个体数 / 总体个体数)

适用条件：总体中各部分差异明显，而层内个体差异较小。

分层抽样的价值在于「层内同质、层间异质」。 如果各层差异不大，分层反而没必要； 如果层内差异很大，那说明这一层还得继续细分。 判断「该不该用分层抽样」就看这两点。

一个易错表述：分层抽样是「按比例抽取」， 不是「各层抽同样多」。各层抽同样的数量，那叫「定额抽样」， 会破坏样本的代表性。

获取数据的途径

调查、试验、观察、查询（利用公开的统计资料）。

需要注意的地方有三类：被调查者不愿如实回答（如涉及隐私）、 抽样框不完整（如电话调查漏掉了没电话的人）、 问卷设计有诱导性。这些都是系统性偏差的来源。

9.2 用样本估计总体

频率分布直方图

绘制步骤：求极差（最大值 − 最小值）→ 决定组距与组数 → 分组 → 列频率分布表 → 画直方图。

频率 = 频数 / 样本量
纵轴的值 = 频率 / 组距（不是频率本身）
每个小矩形的面积 = 该组的频率
这是直方图最核心的一点：纵轴是「频率/组距」，不是「频率」。 所以小矩形的面积才等于频率，所有小矩形的面积之和等于 1。

如果题目问「求某个范围内的频率」，就要把对应的小矩形面积加起来 （即「纵坐标 × 组距」再求和）。直接读纵坐标是错的。

百分位数

第 p 百分位数：把数据从小到大排列后， 使得至少有 p% 的数据小于或等于这个数， 且至少有 (100 − p)% 的数据大于或等于这个数。

中位数就是第 50 百分位数。

从频率分布直方图估计百分位数的办法： 从左往右累加面积，找到累计面积达到 p% 的那一组， 再在这一组内按面积比例插值求出具体数值。

教材给出的计算规则是：对于 n 个数据，第 p 百分位数的位置为 i = n × p%，若 i 不是整数则取大于 i 的最小整数对应的数据； 若 i 是整数则取第 i 项与第 i+1 项的平均值。 这个规则与直方图插值的做法结果略有差异， 考试中要看清题目要求哪种方式。

集中趋势：平均数、中位数、众数

平均数
所有数据之和除以个数。
受极端值影响最大，因为它用到了每一个数据。
中位数
排序后处于中间位置的数。
不受极端值影响，稳健性最好。
众数
出现次数最多的数。
可能不唯一，也可能不存在。
平均数的加权形式：x̄ = (x₁f₁ + x₂f₂ + … + xₙfₙ) / (f₁ + f₂ + … + fₙ)
平均数、中位数、众数三者的位置关系可以反映分布的形状：
数据对称时三者大致相等；
右偏（有大的极端值）时，平均数 > 中位数 > 众数；
左偏（有小的极端值）时，平均数 < 中位数 < 众数。
比如「某公司老板年薪很高」，会让全公司平均工资被拉高， 但中位数工资仍然很低——这就是平均数受极端值影响的现实例子。

离散程度：方差与标准差

方差：s² = [(x₁ − x̄)² + (x₂ − x̄)² + … + (xₙ − x̄)²] / n
标准差：s = √(s²)
简便公式：s² = (x₁² + x₂² + … + xₙ²) / n − x̄²
方差的单位是「原数据单位的平方」，标准差的单位与原数据相同。 所以日常说「波动多少」时用标准差更直观。

数据的平移与伸缩对统计量的影响是高频考点： 若把所有数据都加上常数 a，则平均数加 a、方差不变； 若把所有数据都乘以常数 k，则平均数乘 k、方差乘 k²、标准差乘 |k|。 记住「平移不改变波动，只有伸缩才改变」。
例 1

已知一组数据 x₁, x₂, …, x₁₀ 的平均数为 5，方差为 4。 令 yᵢ = 2xᵢ + 3，求新数据 y 的平均数与方差。

解答

平均数：ȳ = 2x̄ + 3 = 2×5 + 3 = 13。

方差：平移不影响波动，只有乘以 2 会起作用，且方差乘 2² = 4，所以

s_y² = 4 × 4 = 16，标准差 s_y = 4。

要点：加 3 这一步对标准差毫无影响。 若题目改问「新数据的标准差」，答案就是 4， 不要写成 2×2 + 3 = 7 这种错误结果。

频率分布直方图中三个统计量的估计

众数——取最高矩形的底边中点。

中位数——使左右两侧面积各为 0.5 的那个分界点。

平均数——用每个小矩形的底边中点值 × 该组频率，再求和。

直方图求得的这三个量都是估计值， 因为原始数据已经被「归组」了，组内的具体分布信息丢失了。 所以严格来说应写「估计众数为……」，但实际答题时通常直接写数值即可。

9.3 统计案例：公司员工的肥胖情况调查分析

这是一节综合应用课，涉及的过程是：确定调查对象 → 收集数据 → 整理数据（分组、画直方图）→ 计算统计量 → 分析并得出结论。

要注意的分析要点：

其一，结论要区分「相关」与「因果」。 统计数据能显示「两个指标同时变化」， 但不能自动证明「一个导致了另一个」。

其二，样本的代表性决定了结论能否推广。 如果样本只来自某一个车间，就不能推及全公司。

其三，报告应给出原始数据、处理方法和分析结论三部分， 让人能够复核。这是统计工作诚信性的基本要求。

易错点速查

其一，直方图的纵轴是「频率/组距」，不是频率。面积才等于频率。

其二，方差和标准差都恒非负，最小值为 0 （当且仅当所有数据相等时取到 0）。

其三，「平均数相等的两组数据，波动一定相同」是错的。 平均数只描述集中趋势，波动要靠方差描述。

其四，百分位数与中位数一样，不要求数据本身在数据集中出现过。 比如 5 个数的第 25 百分位数可能是两个数的平均值， 这个值可能不在原数据里。
