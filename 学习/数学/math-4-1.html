第 6 章　计数原理

人教 A 版选择性必修第三册 · 6.1 – 6.3

先建立直觉：计数原理要解决的问题是「有多少种可能」。 比如「从 5 个人里选 3 个人去开会，有多少种选法？」 这看起来是小学问题，但当数量变大、限制变多时， 就需要系统的方法。

整个这一章的核心就两件事：判断「要分步还是分类」（加法与乘法原理）， 以及判断「讲究顺序还是不讲究」（排列与组合）。 把这两个判断做对，剩下的只是套公式。

6.1 分类加法计数原理与分步乘法计数原理

分类加法计数原理

完成一件事有 n 类不同的方案，各类方案之间互相独立、任选其一即可完成， 第 i 类中有 mᵢ 种方法，则总方法数为 N = m₁ + m₂ + … + mₙ。

分步乘法计数原理

完成一件事需要分成 n 个步骤，各步骤依次进行、缺一不可， 第 i 步有 mᵢ 种方法，则总方法数为 N = m₁ × m₂ × … × mₙ。
判断「分类」还是「分步」，只看一个问题： 「做完这一步，事情完成了吗？」
做完了 → 分类（用加法）；
没做完、还得继续 → 分步（用乘法）。

一个经典的记法：「分类相加，分步相乘」。 但更重要的是理解背后的逻辑：分类是「或」的关系（走 A 路或 B 路都能到）， 分步是「且」的关系（必须先 A 后 B 才能到）。
做题时最常犯的错误是「分类标准不统一」， 导致某些情况被重复计算或遗漏。 标准做法是：先确定一个明确、不交叉、不遗漏的分类维度， 比如「按是否含某个元素分类」「按首位数字是否为 0 分类」。 如果发现自己分类时都说不清「这一类的共同特征是什么」， 那说明分类标准有问题。

6.2 排列与组合

排列（讲究顺序）

A(n, m) = n! / (n − m)! = n(n−1)(n−2)…(n−m+1)

从 n 个不同元素中取出 m 个，按照一定的顺序排成一列。

组合（不讲究顺序）

C(n, m) = A(n, m) / m! = n! / [m!(n − m)!]

从 n 个不同元素中取出 m 个，不管顺序组成一组。

两者的关系

A(n, m) = C(n, m) × m!
这个等式的含义很直观：「先选出 m 个人，再给这 m 个人排队」， 合起来就等于「直接排 m 个人」。 这就解释了为什么组合数比排列数小一个 m! 倍。

怎么判断题意是排列还是组合？ 关键看「交换两个元素的顺序，结果算不算变化」。
「选 3 人当班长、副班长、学习委员」——职务不同，顺序有意义 → 排列；
「选 3 人参加座谈会」——都是参会人员，顺序无意义 → 组合。

重要性质

C(n, m) = C(n, n − m)（对称性）
C(n, m) + C(n, m−1) = C(n+1, m)（递推公式）
C(n, 0) = C(n, n) = 1
对称性的现实含义：「从 n 个里选出 m 个」与「从 n 个里留下 n−m 个」是同一件事。 这个性质在化简计算时非常有用——算 C(10, 8) 不如算 C(10, 2) = 45 快。

排列组合的常见模型

相邻问题：捆绑法
要求某几个元素必须相邻时， 把它们「捆成一捆」当成一个元素，再整体排列， 最后乘上内部排列数。
不相邻问题：插空法
要求某几个元素不能相邻时， 先排其他元素，再把不相邻的元素「插」进已有的空隙中。
特殊元素（位置）优先法
有特殊要求的位置（如「首位不能是 0」） 优先安排，避免后续重复讨论。
正难则反：间接法
直接算「至少……」「不全是……」很麻烦时， 用「总数减去对立情形」。
例 1

从 5 名男生和 4 名女生中选出 3 人参加活动。 要求（1）任意选 3 人；（2）恰好有 2 名男生、1 名女生； （3）至少有 1 名女生。分别求选法数。

解答

（1）从 9 人中任选 3 人，不讲究顺序，用组合：

C(9, 3) = 84

（2）分两步：先从 5 名男生中选 2 人，再从 4 名女生中选 1 人。

C(5, 2) × C(4, 1) = 10 × 4 = 40

（3）用间接法。「至少有 1 名女生」的对立面是「全是男生」：

C(5, 3) = 10

所以

84 − 10 = 74 种。

也可以正面分类：1 女 2 男 + 2 女 1 男 + 3 女，即

C(4,1)C(5,2) + C(4,2)C(5,1) + C(4,3) = 40 + 30 + 4 = 74

两种方法结果一致。这说明「至少」类问题用间接法更省事， 但用正面分类可以交叉验算，考试时值得做一次验证。

6.3 二项式定理

(a + b)ⁿ = C(n,0)aⁿ + C(n,1)aⁿ⁻¹b + … + C(n,k)aⁿ⁻ᵏbᵏ + … + C(n,n)bⁿ

展开式中的第 k+1 项（通项）为

T(k+1) = C(n, k) · aⁿ⁻ᵏ · bᵏ
「第 k+1 项」这个下标最容易出错。 因为项数从 1 开始数，而组合数的下角标 k 从 0 开始， 所以「求第 4 项」就要令 k = 3。 做题时建议先写出通项公式，再明确 k 的取值， 不要凭感觉直接代入。

二项式系数的性质

C(n,0) + C(n,1) + … + C(n,n) = 2ⁿ（所有系数之和）
C(n,0) + C(n,2) + C(n,4) + … = C(n,1) + C(n,3) + … = 2ⁿ⁻¹

即奇数项系数之和等于偶数项系数之和，都等于 2ⁿ⁻¹。

最大系数：若 n 为偶数，中间一项（第 n/2 + 1 项）的 二项式系数最大；若 n 为奇数，中间两项（第 (n+1)/2 项与第 (n+3)/2 项）的二项式系数最大。

「二项式系数最大」与「系数最大」是两回事。这是最集中的混淆点：
二项式系数指 C(n, k) 本身，只看三角形对称性即可判断；
项系数是 C(n,k)·aⁿ⁻ᵏ·bᵏ 这个完整数值， 当 a、b 不是 1 时，两者最大位置可能不同。
求「系数最大项」的正确做法是：设第 k+1 项系数 ≥ 第 k 项系数， 且 ≥ 第 k+2 项系数，解这个不等式组。
例 2

求 (1 + 2x)⁶ 的展开式中 x³ 的系数。

解答

写出通项。这里 a = 1，b = 2x，所以

T(k+1) = C(6, k) · 1⁶⁻ᵏ · (2x)ᵏ = C(6, k) · 2ᵏ · xᵏ

要求 x³ 的系数，令 k = 3，代入得

C(6, 3) · 2³ = 20 × 8 = 160

所以 x³ 的系数为 160。

验证：用另一种思路。 (1+2x)⁶ 中取 x³， 意味着在 6 个括号中选 3 个取 2x、另外 3 个取 1。 选法有 C(6,3) = 20 种， 每种贡献 2³ = 8，所以合计 20 × 8 = 160，与公式法一致。

注意：题目问的是「系数」（带 2 的幂），不是「二项式系数」（只数组合）。 若问 x³ 的二项式系数，答案就是 20。

赋值法

求「各项系数之和」时，直接令 x = 1； 求「常数项与奇次项系数之差」时，令 x = −1。

比如对 (1 + 2x)⁶：

令 x = 1 得系数之和 = 3⁶ = 729
令 x = −1 得交错和 = (−1)⁶ = 1
「赋值法」是求系数和问题的万能手段。 注意要区分「系数之和」与「二项式系数之和」：
系数之和——令 x = 1 代进去算；
二项式系数之和——恒等于 2ⁿ，不需要赋值。
对 (1+2x)⁶，系数之和是 3⁶ = 729， 而二项式系数之和是 2⁶ = 64，两者差别很大。

易错点速查

其一，「分类相加、分步相乘」不能凭语感判断， 要真的问自己「这一步做完，事情完成了吗」。

其二，排列与组合的区分要看「交换顺序是否改变结果」， 不要看到「选」就默认是组合。

其三，通项中 k 从 0 开始计数， 「第几项」与「k 的值」差 1，这是最常见的计算失误源。

其四，「二项式系数」与「项的系数」含义不同， 读题时要看清问的是哪个。

其五，分类时务必检查「不重不漏」。 一个实用的自检方法：把所有分类的数目加起来， 看是否等于「不加任何限制时的总数」（若应该相等的话）。
