第 8 章　立体几何初步

人教 A 版必修第二册 · 8.1 – 8.6

先建立直觉：平面几何研究「纸上的图形」， 立体几何研究「空间里的物体」。关键差别在于多了一个维度—— 在平面内两条直线的关系只有「相交 / 平行」两种， 而在空间中还多了第三种：异面（既不平行也不相交，比如房间天花板上的一条边和地面上与它不平行的一条边）。

这一章的目标是：认识常见几何体的形状，会算它们的表面积与体积， 并初步掌握空间中的平行与垂直关系。

8.1 基本立体图形

多面体与旋转体

棱柱
两个底面平行且全等，侧面都是平行四边形。
按底面形状分三棱柱、四棱柱……； 直棱柱的侧棱垂直于底面，正棱柱是底面为正多边形的直棱柱。
棱锥
一个底面，侧面都是三角形，且有公共顶点。
正棱锥是底面为正多边形且顶点在底面中心的正上方。 此时侧面是全等的等腰三角形，斜高相等。
棱台
用平行于底面的平面截棱锥，底面与截面之间的部分。 上下底面相似但不全等（若全等就成了棱柱）。
圆柱 / 圆锥 / 圆台
分别由矩形绕一边、直角三角形绕一直角边、 直角梯形绕垂直于底边的腰旋转得到。
球
半圆绕直径旋转得到。任意方向的截面都是圆； 过球心的截面叫大圆。
组合体
由简单几何体拼接、挖去或截去而成。 求表面积体积时，要判断哪些面「被遮挡」了。

表面积公式

圆柱：S侧 = 2πrl，S全 = 2πrl + 2πr²
圆锥：S侧 = πrl，S全 = πrl + πr²
圆台：S侧 = π(r₁ + r₂)l
球：S = 4πR²

体积公式

柱体：V = S底 · h
锥体：V = (1/3) S底 · h
台体：V = (1/3) h (S上 + √(S上·S下) + S下)
球：V = (4/3) πR³
一个必须记死的关系：锥体体积是同底同高的柱体的三分之一； 球的体积公式带 4/3，表面积公式带 4（没有分母）。 球的这两个公式最容易互相写错。

另一个常用结论：球的内接正方体（正方体顶点都在球面上）中， 球的直径等于正方体的体对角线，即 2R = √3·a（a 为棱长）。

8.2 直观图

斜二测画法的三条规则：

其一，在已知图形中取互相垂直的 x 轴、y 轴， 画直观图时把它们画成夹角为 45°（或 135°）的两条轴。

其二，平行于 x 轴的线段，长度保持不变； 平行于 y 轴的线段，长度变为原来的一半。

其三，平行于 z 轴的线段（在空间图形中），长度也保持不变。

「横不变、纵减半」是斜二测的核心。 由它可推出一个常考结论：水平放置的平面图形 画成斜二测直观图后，面积变为原来的 √2/4 倍。这是一个固定的比例，直接套用能省去推导。

8.3 – 8.4 点、直线、平面的位置关系

基本事实（公理）

基本事实 1：过不在一条直线上的三个点，有且只有一个平面。

基本事实 2：如果一条直线上的两点在一个平面内， 那么这条直线在此平面内。

基本事实 3：如果两个不重合的平面有一个公共点， 那么它们有且只有一条过该点的公共直线。

由基本事实 1 可以得到两条推论： 经过两条相交直线，有且只有一个平面； 经过两条平行直线，有且只有一个平面。

空间中直线与直线的位置关系

相交
在同一平面内，有且仅有一个公共点。
平行
在同一平面内，没有公共点。
基本事实 4：平行于同一条直线的两条直线互相平行 （平行的传递性，是平面内平行的推广）。
异面
不同在任何一个平面内，没有公共点。
判定异面的常用手段：「连结平面内一点与平面外一点的直线， 和平面内不经过该点的直线，是异面直线」——这是一条可以直接引用的结论。

异面直线所成的角：把其中一条平移到与另一条相交， 所成锐角（或直角）就叫异面直线所成的角，取值范围 (0°, 90°]。 若为 90°，则称异面垂直。

「过直线外一点有且只有一条直线与已知直线平行」在空间中成立； 但「过直线外一点有且只有一条直线与已知直线垂直」不成立—— 在空间中有无穷多条。这是从平面迁移到空间时最容易出错的一个直觉。

直线与平面的位置关系

三种：直线在平面内（有无数个公共点）、 直线与平面相交（有且只有一个公共点）、 直线与平面平行（没有公共点）。

直线与平面垂直的定义：直线与平面内的任意一条直线都垂直。 （注意是「任意」而不是「无数」——只说无数条是不够的， 平面内可以有无数条都与它垂直的平行线。）

8.5 平行关系的判定与性质

线面平行的判定

平面外的一条直线与平面内的一条直线平行 ⇒ 该直线与平面平行

符号化表述：a ⊄ α，b ⊂ α，a ∥ b ⇒ a ∥ α。

关键：三个条件缺一不可——「平面外」「平面内」「两线平行」。 少了「平面外」就变成直线在平面内了。

线面平行的性质

一条直线与一个平面平行，则过该直线的任一平面与此平面的交线与该直线平行

符号化：a ∥ α，a ⊂ β，α ∩ β = b ⇒ a ∥ b。

判定与性质的区别是这一章的思维核心：
判定是「由线线平行推出线面平行」（往大推）；
性质是「由线面平行推出线线平行」（往小推）。
做题时先想清楚「我手里有什么、我要证什么」， 就知道该用判定还是性质。这个「线线 ↔ 线面 ↔ 面面」的转化链条是立体几何的主线。

面面平行

判定：一个平面内的两条相交直线与另一个平面平行， 则这两个平面平行。（必须是「相交」的两条，平行的两条不行。）

性质：两个平面平行，则其中任一平面内的直线平行于另一平面； 且夹在两平行平面间的平行线段相等。

8.6 垂直关系的判定与性质

线面垂直的判定

一条直线与平面内两条相交直线都垂直 ⇒ 该直线垂直于这个平面

符号化：m ⊂ α，n ⊂ α，m ∩ n = A，l ⊥ m，l ⊥ n ⇒ l ⊥ α。

同样要求「相交」两条直线。如果只与两条平行直线垂直， 完全不能推出线面垂直——这是最经典的错误。 另外，证明垂直时通常的套路是：先找平面内两条相交直线， 再分别证它们与目标直线垂直。

线面垂直的性质

垂直于同一平面的两条直线互相平行

面面垂直

判定（面面垂直的判定定理）：一个平面过另一个平面的垂线， 则这两个平面互相垂直。

符号化：l ⊥ α，l ⊂ β ⇒ β ⊥ α。

性质：两个平面垂直，则一个平面内垂直于交线的直线 与另一个平面垂直。

面面垂直的性质定理中，「垂直于交线」这几个字必须写。 只写「一个平面内的直线垂直于另一个平面」是漏了条件的错误表述。 这条性质是「作辅助线」的经典依据：在两个垂直平面中， 先找到交线，再从一点向交线作垂线，就能得到一条垂直于另一个平面的直线。

三种角的计算

异面直线所成角
平移法。范围 (0°, 90°]。 常用「中位线平移」「平行四边形平移」。
直线与平面所成角
找直线在平面内的射影， 直线与其射影所成的锐角即为所求。范围 [0°, 90°]。
二面角
从棱上任取一点， 在两个半平面内分别作垂直于棱的射线，所成的角即二面角。 范围 [0°, 180°]。
例 1

正方体 ABCD-A₁B₁C₁D₁ 的棱长为 a，求： （1）异面直线 AC 与 BC₁ 所成角；（2）直线 AC₁ 与平面 ABCD 所成角的余弦值。

解答

（1）平移：连 B₁C₁、AB₁。因为 BC₁ ∥ AD₁， 所以 AC 与 BC₁ 所成角等于 AC 与 AD₁ 所成角，即 ∠CAD₁。

在正方体中，AC = AD₁ = CD₁ = √2·a（都是面对角线）， 所以 △ACD₁ 是等边三角形，得

∠CAD₁ = 60°。

（2）因为 CC₁ ⊥ 平面 ABCD， 所以 C 是 C₁ 在底面内的射影，∠C₁AC 就是所求角。

AC = √2·a，AC₁ = √3·a（体对角线，等于 √3 倍棱长），

所以 cos∠C₁AC = AC / AC₁ = √2·a / (√3·a) = √2/√3 = √6/3 ≈ 0.816， 对应角约 35.3°。

这两个数据很有用，建议记住：正方体的面对角线是 √2·a，体对角线是 √3·a。 很多立体几何题一旦用上它们，计算量会大幅下降。

易错点速查

其一，「垂直于同一直线的两条直线平行」在空间中不成立 （三维中可以异面垂直）。平面内的结论不能无条件搬到空间。

其二，线面平行的判定中，直线必须在平面外。 题目若只说「直线 a 平行于平面 α 内的直线 b」，不说明位置关系， 是不能推 a ∥ α 的。

其三，二面角的取值范围是 [0°, 180°]， 它可以等于 180°（两个半平面在一个平面内）， 这与异面直线所成角必须取锐角不同。

其四，证明题中每一步都要引用依据（定理、定义或公理）， 只写结论不写理由是立体几何最普遍的扣分原因。
